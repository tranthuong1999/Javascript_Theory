Mục 3 — Breakpoints
breakpoint là điểm trong code mà trình debug sẽ tự động tạm dừng chương trình khi chạy đến đó.

function multiply(a, b) {
  let result = a * b;
  let finalResult = result + 10;

  return finalResult;
}

console.log(multiply(3, 4));

Đặt breakpoint: let finalResult = result + 10;
Breakpoint tại một dòng
    ↓
Code phía trước đã chạy
    ↓
Code tại dòng đang dừng chưa chạy

Mục 4 — The command debugger

function hello(name) {
  let phrase = `Hello, ${name}!`;

  debugger

  console.log(phrase);
}

hello("Martin");

Khi chạy đoạn code trên:
1. Hàm hello("Martin") được gọi.
2. Biến phrase được tạo với giá trị "Hello, Martin!".
3. Chương trình tạm dừng tại debugger.
4. Bạn có thể kiểm tra giá trị name và phrase trong DevTools.
5. Sau khi nhấn Resume, chương trình tiếp tục chạy console.log(phrase).

Mục 5 — Pause and look around
5.1. Ba khu vực cần biết
5.2. Thử với code thực tế

Scope → Xem giá trị biến hiện tại
Watch → Theo dõi giá trị biểu thức
Call Stack → Xem đường đi qua các hàm
5 kiến thức quan trọng cần nhớ
| Công cụ         | Công dụng                             |
| --------------- | ------------------------------------- |
| `Sources`       | Xem mã nguồn và đặt breakpoint        |
| `Console`       | Chạy lệnh JavaScript, xem kết quả     |
| Breakpoint      | Tạm dừng tại một dòng code            |
| `debugger;`     | Tạo điểm dừng ngay trong code         |
| `console.log()` | In thông tin để theo dõi chương trình |
