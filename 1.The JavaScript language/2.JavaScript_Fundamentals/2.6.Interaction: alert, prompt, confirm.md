1.1. alert là gì?
alert() hiển thị thông báo cho người dùng và chờ họ nhấn OK.

ALERT

1. Cú pháp:
   alert(message);

2. Công dụng:
   Hiển thị thông báo và chờ người dùng nhấn OK.

3. Modal window:
   Tạm dừng việc thực thi script cho đến khi đóng hộp thoại.

Ví dụ:
   alert("Hello!");

Lưu ý:
   Giao diện và vị trí hộp thoại do trình duyệt quyết định.

Đoạn code sau có tác dụng gì?

alert("Welcome!");
console.log("Hello");

A. In Hello trước, sau đó hiện thông báo.

B. Hiện thông báo trước; sau khi đóng hộp thoại, mới chạy console.log.

C. Chỉ hiện thông báo, không chạy console.log.

D. Báo lỗi vì alert không nhận chuỗi.

2.1. prompt() là gì?
prompt() hiển thị hộp thoại yêu cầu người dùng nhập dữ liệu. Hàm này trả về nội dung đã nhập dưới dạng chuỗi (string).
PROMPT
1. Cú pháp:
   prompt(title, defaultValue);

2. Giá trị trả về:
   - Nhập dữ liệu + OK → string
   - Để trống + OK → ""
   - Cancel hoặc Esc → null

3. Ví dụ:
   const name = prompt("Your name?", "");
   console.log(name);

4. Lưu ý:
   Dữ liệu nhập vào là string, kể cả khi nhập số.

*********************************************************************************
Mục 3 — confirm()
confirm() hiển thị hộp thoại xác nhận với hai lựa chọn OK và Cancel.
CONFIRM

1. Cú pháp:
   confirm(question);

2. Giá trị trả về:
   - OK → true
   - Cancel hoặc Esc → false

3. Ví dụ:
   const answer = confirm("Continue?");
   console.log(answer);

4. Phân biệt:
   alert()   → hiển thị thông báo
   prompt()  → nhập dữ liệu, trả về string hoặc null
   confirm() → xác nhận, trả về boolean
*********************************************************************************
| Hàm                      | Chức năng            | Giá trị trả về       |
| ------------------------ | -------------------- | -------------------- |
| `alert(message)`         | Hiển thị thông báo   | `undefined`          |
| `prompt(title, default)` | Yêu cầu nhập dữ liệu | `string` hoặc `null` |
| `confirm(question)`      | Yêu cầu xác nhận     | `true` hoặc `false`  |
