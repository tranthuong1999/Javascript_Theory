* Mục 1 — Arrow function là gì?
1.1. Khái niệm
Arrow function là cách viết ngắn gọn của Function expression sử dung ký hiệu =>

* Mục 2 — Arrow function với một tham số
1 tham số  → n => n * 2
2 tham số  → (a, b) => a + b
0 tham số  → () => "Hello"

* Mục 3 — Arrow function không có tham số
Nếu không có tham số, bắt buộc phải viết cặp ngoặc rỗng () trước =>

* Mục 4 — Dùng Arrow Function thay Function Expression
  Arrow function có thể sử dụng tương tự như Funtion Expression

* Mục 6 — Tổng kết Arrow functions, the basics
  
  // 1. Nhiều tham số, một biểu thức
const sum = (a, b) => a + b;

// 2. Một tham số, có thể bỏ ngoặc
const double = n => n * 2;

// 3. Không có tham số, bắt buộc có ()
const sayHi = () => "Hello";

// 4. Nhiều câu lệnh, dùng {} và return
const multiply = (a, b) => {
  const result = a * b;
  return result;
};
