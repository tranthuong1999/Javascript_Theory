1.2. Cách viết mới: Function Expression
JS cho phép tạo hàm rồi gán hàm đó cho 1 biến

let sayHi = function() {
    console.log("Hello");
};

sayHi();
Giải thích từng phần:
- function() { ... }: tạo một hàm không có tên.
- let sayHi = ...: gán giá trị hàm cho biến sayHi.
- sayHi(): gọi hàm thông qua biến đang giữ hàm đó.
  Hàm được tạo bên phải phép gán = , được gọi là function expresssion

  | Function Declaration               | Function Expression                                  |
  | ---------------------------------- | ---------------------------------------------------- |
  | `function sayHi() { ... }`         | `let sayHi = function() { ... };`                    |
  | Khai báo hàm trực tiếp             | Tạo hàm trong một biểu thức rồi gán cho biến         |
  | Có tên `sayHi` trong phần khai báo | Hàm không có tên riêng; biến `sayHi` giữ giá trị hàm |

Mục 3 — Callback functions (Hàm callback)
Callback là 1 hàm được truyền vào 1 hàm khác dưới dạng 1 tham số , để hàm nhận hàm đó có thể gọi khi cần
function showMessage() {
    console.log("Hello!");
}

function process(callback) {
    callback();
}

process(showMessage);
Kết quả : Hello!
* * * * CHú ý:
process(showMessage);   // Truyền hàm
process(showMessage());   // Gọi hàm trước rồi truyền kết quả trả về
3.2. Ví dụ gần với bài gốc: ask(question, yes, no)
function ask(question, yes, no) {
    if (confirm(question)) {
        yes();
    } else {
        no();
    }
}

function showOk() {
    alert("You agreed.");
}

function showCancel() {
    alert("You canceled the execution.");
}

ask("Do you agree?", showOk, showCancel);
Bài tập thực hành:
function processUser(name, onSuccess, onError) {
    if (name) {
        onSuccess(name);
    } else {
        onError();
    }
}

function showSuccess(name) {
    console.log("Welcome, " + name);
}

function showError() {
    console.log("Name is missing");
}

processUser("Martin", showSuccess, showError);
processUser("", showSuccess, showError);
Chú ý :
callback : gọi hàm
callback(): gọi hàm và nhận giá trị trả về
callback(value): gọi hàm với đối số value

Mục 4 — Function Expression vs Function Declaration
1. Phân biệt cú pháp
2. Khác biệt quan trọng nhất: thời điểm sử dụng
Fuction declarion và function expression
Chú ý : Function expression không sử dụng được trước khi biến chứa hàm khởi tạo 
3. Phạm vi khi khai báo bên trong if
Functio declarito được khai báo trong khối {} trong stric mode chỉ khả dụng bên trong khối đó

if (true) {
  function welcome() {
    console.log("Welcome");
  }

  welcome(); // Welcome
}

welcome(); // ReferenceError trong strict mode

Nếu muốn chọn hàm dựa vào điều kiện và sử dụng nó bên ngoài if có thể dụng FE

let welcome;

if (true) {
  welcome = function() {
    console.log("Welcome");
  };
}

welcome(); // Welcome
4. Nên dùng kiểu nào?
Function Declaration: lựa chọn mặc định khi khái báo 1 hàm thông thường , dễ đọc và có thể gọi trước khi khai báo
Function Expression : phù hợp ki cần gán hàm có điều kiện , truyền hàm làm giá trị mặc định hoặc cb

Bài tập thực hành:
console.log(add(2, 3));

function add(a, b) {
  return a + b;
}

const multiply = function(a, b) {
  return a * b;
};

console.log(multiply(2, 3));

Function Declaration
├── function name() {}
├── Có thể gọi trước dòng khai báo
└── Hàm được khởi tạo trước khi thực thi câu lệnh thông thường

Function Expression
├── const name = function() {}
├── Chỉ sử dụng sau khi biến được khởi tạo
└── Với const/let: truy cập trước khai báo gây ReferenceError
