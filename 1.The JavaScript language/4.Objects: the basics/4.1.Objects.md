Mục 1 — Literals and properties
1. Object là gì?
Object là kiểu dữ liệu dùng để lưu  thông tin dưới dạng cặp key-value;
Thay vi tạo biến riêng lẻ cho người dùng:
const name = "John";
const age = 30;
const isAdmin = true;
Ta có thể nhóm chúng thành object:
const user = {
  name: "John",
  age: 30,
  isAdmin: true,
};
2. Tạo object
Có 2 cách tạo object :
const user1 = {};             // Object literal
const user2 = new Object();   // Object constructor
3. Đọc, thêm, sửa và xóa property
const user = {
  name: "John",
  age: 30,
};

// Đọc
console.log(user.name); // "John"

// Thêm
user.isAdmin = true;

// Sửa
user.age = 31;

// Xóa
delete user.age;

console.log(user);
// { name: "John", isAdmin: true }
4. Truy cập property bằng dấu chấm
const user = {
  name: "John",
  "likes birds": true,
};

Mục 1 — Literals and properties

Object:
- Lưu dữ liệu theo cặp key-value.
- Tạo object: {} hoặc new Object().
- Đọc property: obj.key
- Thêm/sửa property: obj.key = value
- Xóa property: delete obj.key
- Tên property có khoảng trắng phải đặt trong dấu nháy.

Ví dụ:
const user = { name: "John", age: 30 };
user.age = 31;
user.isAdmin = true;
delete user.age;

2. Truy cập bằng tên property lưu trong biến
const user = {
  name: "Martin",

const key = "name";

console.log(user[key]); // "Martin"
3. Ghi nhớ để lưu vào VS Code
Mục 2 — Square brackets

Dấu chấm:
obj.key
→ Truy cập property có tên cố định là "key".

Dấu ngoặc vuông:
obj[key]
→ Lấy giá trị biến key làm tên property.

Dùng [] khi:
- Tên property chứa khoảng trắng.
- Tên property nằm trong biến.
- Cần truy cập property động.

Ví dụ:
const key = "name";
obj[key];   // Đọc property "name"
obj.key;    // Đọc property "key"

Mục 3 — Computed properties
1. Computed properties là gì?
Mục 3 — Computed properties

Computed property:
const obj = {
  [expression]: value,
};

- JavaScript tính expression trước khi tạo property.
- [fruit] lấy giá trị biến fruit làm tên property.
- [fruit + "Computers"] dùng kết quả biểu thức làm tên property.

Phân biệt:
{ fruit: 5 }   → key là "fruit"
{ [fruit]: 5 } → key là giá trị của biến fruit

Mục 4 — Property value shorthand

Khi tên property trùng tên biến, có thể viết ngắn:

const name = "Martin";

const user = {
  name,          // tương đương name: name
  age: 27,       // property thông thường
};

Ghi nhớ:
- name: name → viết đầy đủ
- name       → viết rút gọn
- Hai cách cho kết quả giống nhau.

Mục 5 — Property names limitations
Những giới hạn về tên thuộc tính trong object
1. Tên thuộc tính có thể là từ khóa
   const user = {
  let: 1,
  const: 2,
  return: 3,
};

console.log(user.let);    // 1
console.log(user.return); // 3
2. Tên thuộc tính có thể là chuỗi bất kỳ
const user = {
  "first name": "Martin",
  "my-address": "Hanoi",
  "1": "one",
};
3. Một số lưu ý về tên thuộc tính
const obj = {
  "0": "zero",
  "1": "one",
};

console.log(obj["0"]); // "zero"

Mục 5 — Property names limitations

- Tên property có thể là từ khóa: let, const, return.
- Tên có dấu cách hoặc ký tự đặc biệt nên đặt trong dấu nháy.
- Truy cập property có tên đặc biệt bằng obj["property name"].
- Key kiểu số được chuyển thành chuỗi.

Ví dụ:
const obj = {
  "first name": "Martin",
  1: "one",
};

obj["first name"]; // "Martin"
obj[1];            // "one"

Mục 6 — Property existence test (in)
1. Vấn đề với undefined
const user = {
  name: "Martin",
  age: undefined,
};

console.log(user.name !== undefined); // true
console.log(user.city !== undefined); // false
console.log(user.age !== undefined);  // false
Nhưng có vấn đề: age thực sự tồn tại, dù giá trị của nó là undefined.
2. Dùng toán tử in
"propertyName" in object
const user = {
  name: "Martin",
  age: undefined,
};

console.log("name" in user); // true
console.log("age" in user);  // true
console.log("city" in user); // false

Mục 6 — Property existence test ("in")

Cú pháp:
"propertyName" in object

Kết quả:
- true  → thuộc tính tồn tại
- false → thuộc tính không tồn tại

Lưu ý:
obj.property !== undefined
không phân biệt được thuộc tính không tồn tại
với thuộc tính tồn tại nhưng có giá trị undefined.

Ví dụ:
const user = { age: undefined };

"age" in user;             // true
"city" in user;            // false
user.age !== undefined;    // false

Mục 7 — The for...in loop
1. for...in dùng để làm gì?
Dùng để duyệt qua các key của 1 object
const user = {
  name: "Martin",
  age: 27,
  city: "Hanoi",
};

for (const key in user) {
  console.log(key);
}
2. Lấy cả key và value
const user = {
  name: "Martin",
  age: 27,
};

for (const key in user) {
  console.log(key, user[key]);
}
3. Ghi chú để lưu vào VS Code

Mục 7 — The for...in loop

Cú pháp:
for (const key in object) {
  // xử lý mỗi thuộc tính
}

- key: tên thuộc tính hiện tại.
- object[key]: giá trị của thuộc tính đó.
- object.key: truy cập thuộc tính có tên cố định là "key".

Ví dụ:
const user = { name: "Martin", age: 27 };

for (const key in user) {
  console.log(key, user[key]);
}
