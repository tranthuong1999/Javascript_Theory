3. Nội dung chi tiết
3.1. Host environment
Ban đầu JS được tạo ra để chạy trên trình duyệt  . Sau này , JS được sử dụng trên nhiều nền tảng khác nhau
Tài liệu gọi môi trường mà JavaScript chạy bên trong là Host Enviroment
Ví dụ:
## JavaScript language core

Các tính năng cốt lõi của ngôn ngữ

`Object`, `Array`, `Promise`, `Map`, `Set`

## Browser

`window`

`document`

`navigator`

`location`

## Node.js

`process`

`Buffer`

`fs`

`http`
JavaScript language core cung cấp các tính năng của ngôn ngữ
Host environment cung cấp thêm những object và function đặc thù cho môi trường đó
Ví dụ:
<!-- 
const users = ["John", "Peter"];

console.log(users.length);
 -->
Array và console không nên bị đánh đồng:
- Array : đối tượng thuộc JS language
- console : API do host enviroment cung cấp
Vai trò của window
Trong Browser, có một object gốc tên là window.
Tài liệu chỉ ra window có hai vai trò:
Vai trò 1: Global object
<!-- 
function sayHi() {
  alert("Hello");
}

window.sayHi();
 -->
 sayHi() là hàm toàn cục trong môi trường script thông thường và có thể truy cập thông qua window
 Vai trò 2: Đại diện cho cửa sổ trình duyệt
 <!-- alert(window.innerHeight); -->
 innerHeight cho biết chiều cao vùng hiển thị bên trong cửa sổ trình duyệt
Bổ sung ngoài tài liệu gốc — Case dễ nhầm
Không phải mọi biến khai báo ở phạm vi global đều trở thành property của window.
Ví dụ trong classic script:
<!-- 
var a = 10;
let b = 20;

console.log(window.a); // 10
console.log(window.b); // undefined
 -->
Đây là điểm dễ nhầm khi học global object.
Ngoài ra, trong JavaScript module, cách xử lý global declaration cũng khác classic script.
React:
<!-- 
useEffect(() => {
  console.log(window.innerHeight);
}, []);
 -->
React chạy trên trình duyệt nên có thể truy cập thông qua window
Nhưng nếu dùng Next.js Server Components hoặc SSR , code có thể chạy ở phía server . Khi đó khônng được truy cập 
window trực tiếp trong quá trình render ở phía server

Backend Node.js:
<!-- console.log(process.version); -->
NodeJS có môi trường riêng , không mặc định cung cấp window và document

3.2. DOM (Document Object Model)
DOM là viết tắt của Document Object Model.
DOM biểu diễn toàn bộ nội dung trang web dưới dạng các object có thể được JS thao tác
document là điểm truy cập chính để tương tác nội dung vơi trang web
Ví dụ :
<!-- 
<body>
  <h1>Hello World</h1>
</body>
 -->
JavaScript:
<!-- 
document.body.style.background = "red";

setTimeout(() => {
  document.body.style.background = "";
}, 1000);
 -->
Giải thích :
document : đại diện cho document hiện tại 
document.body : truy cập phần tử body
.style.background: thay đổi màu nền.
setTimeout(): sau 1 giây , đưa background về giá trị mặc định của thuộc tính inline

* Hình dung DOM
| Thành phần | Nội dung       |
| ---------- | -------------- |
| `document` | `html`         |
| `html`     | `head`, `body` |
| `body`     | `h1`           |
| `h1`       | Hello World    |
* DOM không chỉ dùng trong Browser
DOM không chỉ tồn tại trong trình duyệt.
Một số công cụ chạy phía server có thể tải HTML rổi sử dụng DOM để xử lý nội dung . Tuy nhiên , chúng có thể chỉ hỗ trợ 1 phần đặc tả của DOM
Áp dụng trong React:
React thường quản lý việc tạo và cập nhật giao diện thông qua React components, thay vì bạn tự thao tác DOM trực tiếp.
Ví dụ:
<!--function App() {
  return <h1>Hello World</h1>;
} 
-->
Khi cần truy cập DOM eleemnt cụ thể , bạn có thể sử dụng useRef
<!-- 
function App() {
  const inputRef = useRef(null);

  useEffect(() => {
    inputRef.current.focus();
  }, []);

  return <input ref={inputRef} />;
}
 -->
Ở đây:
- useRef giữ tham chiếu đến DOM element
- inputRef.current là DOM object thực tế.
- focus() là phương thức của DOM Element
Ghi nhớ : React k thay thế DOM . React sử dung DOM để hiển thị giao diện trong môi trường browser
Áp dụng trong Backend:
Node.js không mặc định có DOM như Browser
Tuy nhiên, Backend có thể dùng thư viện như jsdom để mô phỏng một môi trường DOM hoặc dùng công cụ xử lý HTML.

3.3. CSSOM for styling
CSSOM là viết tắt của CSS Object Model
Nếu DOM biểu diễn cấu trúc document thì CSSOM biểu diễn css rule và stylesheets dưới dạng object
CSSOM cho phép JavaScript đọc và thay đổi các quy tắc CSS . Nó được sử dụng để kết hợp với DOM khi thao tác style của Document
<!-- document.body.style.background = "red"; -->
Ví dụ này thay đổi trực tiếp của một DOM element
Một cách khác là thao tác với stylesheet và CSS rules thông qua CSSOM
Chúng ta ít khi cần sửa trực tiếp sửa CSS rule bằng JS . Thông thường chỉ cần thêm hoặc xoá css class
<!-- 
document.body.classList.add("active");

document.body.classList.remove("active");
 -->
### **Phân biệt DOM và CSSOM**

| DOM                         | CSSOM                              |
| --------------------------- | ---------------------------------- |
| Biểu diễn cấu trúc document | Biểu diễn CSS rules và stylesheets |
| Quản lý element             | Quản lý style và CSS rules         |
| `document.body`             | `document.styleSheets`             |
Áp dụng trong React
Trong React, bạn thường sử dụng:
<!-- 
function App() {
  const [active, setActive] = useState(false);

  return (
    <button
      className={active ? "active" : ""}
      onClick={() => setActive(!active)}
    >
      Toggle
    </button>
  );
}
 -->
Thay vì tự thao tác CSSOM, bạn thay đổi state để React cập nhật class
3.4. BOM (Browser Object Model)
BOM là viết tắt của Browser Object Model.
BOM đại diện cho những object do Browser cung cấp để làm việc với chức năng của trình duyệt , ngoài nội dung document
Nói đơn giản:
- DOM : thao tác nội dung trang web
- BOM : tương tác với môi trương trình duyệt 
Các object quan trọng trong tài liệu
1. navigator
Cung cấp thông tin về Browser và hệ điều hành.
<!-- 
console.log(navigator.userAgent);

console.log(navigator.platform);
 -->
userAgent : thông tin nhận diện trình duyệt 
platform : thông tin nền tảng
2. location
CHo phép đọc URL hiện tại và chuyển hướng sang URL khác
<!-- console.log(location.href); -->
Chuyển hướng:
<!-- location.href = "https://wikipedia.org"; -->
3. alert, confirm, prompt
Đây là các phương thức thuộc BOM trong cách phân loại của tài liệu 
<!-- alert("Hello"); -->
<!-- const result = confirm("Do you want to continue?");

console.log(result); -->
<!-- 
const name = prompt("Enter your name");
console.log(name);
 -->
Bổ sung ngoài tài liệu gốc — Case dễ nhầm
location và documnet không giống nhau
<!-- document.title = "My Website"; -->
Thay đổi tiêu đề trang.
<!--  
location.href = "https://example.com";
-->

Áp dụng trong React
Bạn có thể dùng BOM để xử lý các chức năng như :
1. Đọc URL hiện tại.
2. Chuyển trang.
3. Kiểm tra thông tin trình duyệt.
4. Hiển thị thông báo.
trong React, thường nên sử dụng router cho điều hướng nội bộ thay vì tuỳ ý gán location.href
Áp dụng trong Backend
Nodejs Không có BOM mặc định 
Ví dụ, location.href không có ý nghĩa trong môi trường server thông thường vì server không có cửa sổ trình duyệt của người dùng

3.5. Summary
| Specification | Nội dung                                                                          |

| CSSOM         | Stylesheets, CSS rules và thao tác style                                          |
| HTML          | Ngôn ngữ HTML, BOM và các chức năng Browser như `setTimeout`, `alert`, `location` |
