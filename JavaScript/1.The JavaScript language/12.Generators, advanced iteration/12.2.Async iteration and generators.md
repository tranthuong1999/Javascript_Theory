4.1. Recall iterables
4.1.1. Nhắc lại Iterable là gì?
Giả sử ta có 1 object:
<!-- 
let range = {
    from: 1,
    to: 5
};
 -->
Chúng ta muốn có thể sử dụng :
<!-- 
for (let value of range) {
    console.log(value);
}
-->
Kết quả mong muốn:  1  2 3 4 5
Nhưng object thông thường không tự động hỗ trợ for...of
Muốn làm được điều đó , chúng ta phải triển khai phương thức đặc biệt
<!-- Symbol.iterator -->
4.1.2. Cách hoạt động của Symbol.iterator
Theo tài liệu gốc, có ba bước:
1. Khi bắt đầu vòng lặp for...of , JS gọi Symbol.iterator.
2. Phương thức này phải trả về 1 object có phương thức next() 
3. Mỗi vòng lặp , JS gọi next() để lấy giá trị tiếp theo
next() trả về object có dạng:
<!-- 
{
    done: false,
    value: 1
}
-->
Trong đó:
- value : gía trị của lần lặp hiện tại 
- done : cho biết quá trình lặp đã kết thúc hay chưa
false: vẫn còn dữ liệu.
true : đã kết thúc

4.1.3. Ví dụ trong tài liệu gốc
<!-- 
let range = {
    from: 1,
    to: 5,

    [Symbol.iterator]() {
        return {
            current: this.from,
            last: this.to,

            next() {
                if (this.current <= this.last) {
                    return {
                        done: false,
                        value: this.current++
                    };
                } else {
                    return { done: true };
                }
            }
        };
    }
};

for (let value of range) {
    console.log(value);
}
-->
Điểm cần hiểu: for...of không trực tiếp đọc from...to . Nó làm việc thông qua iterator được trả về bởi Symbol.iterator.
4.1.4. Bổ sung ngoài tài liệu gốc – dễ nhầm
| Khái niệm       | Ý nghĩa                                                 |
| --------------- | ------------------------------------------------------- |
| Iterable        | Đối tượng có thể được duyệt, cung cấp `Symbol.iterator` |
| Iterator        | Đối tượng cung cấp phương thức `next()`                 |
| Iterator result | Object `{ value, done }` được trả về từ `next()`        |

Một object có next() chưa chắc là Iterable . Muốn dùng trực tiếp với for...of , nó cần đáp ứng giao thức Iterable
Kiểm tra nhanh 4.1
<!-- 
let obj = {
    [Symbol.iterator]() {
        return {
            next() {
                return {
                    value: 10,
                    done: false
                };
            }
        };
    }
};
-->
A. In 10 liên tục vì done luôn là false.

4.2. Async iterables
1. Async iteration là gì?
Asynchronous iteration được sử dụng khi dữ liệu đến 1 cách bất đồng bộ , chẳng hạn:
- Dữ liệu chỉ có sau setTimeout hoặc một khoảng thời gian chờ.
- Dữ liệu cần được lấy từ network request.
- Dữ liệu được tải từng phần (chunk-by-chunk).
Ví dụ: 1 API trả về dữ liệu theo từng trang . CHúng ta cần request haonf thành thì mới có dữ liệu của trang tiếp theo
Khác với Iterable thông thường, Async Iterable cho phép lấy giá trị tiếp theo thông qua Promise
2. Cách tạo Async Iterable
Thay đổi 1: Sử dụng Symbol.asyncIterator
Thay vì:
<!-- 
[Symbol.iterator]() {
    // ...
}
 -->
Sử dụng:
<!-- 
[Symbol.asyncIterator]() {
    // ...
}
 -->
Thay đổi 2: Phương thức next() phải trả về Promise
Có thể sử dung async next() để JS tự động trả về Promise
<!-- 
async next() {
    return {
        done: false,
        value: 1
    };
}
-->
Thay đổi 3: Sử dụng for await...of
<!-- 
for (let value of range) {
    console.log(value);
}
 -->
Sử dụng:
<!-- 
for await (let value of range) {
    console.log(value);
}
-->
3. Ví dụ trong tài liệu gốc: Async range
Ta xây dựng 1 object range trả về các số từ 1 đến 5 , mỗi số cách nhau 1s
<!-- 
let range = {
    from: 1,
    to: 5,

    [Symbol.asyncIterator]() {
        return {
            current: this.from,
            last: this.to,

            async next() {

                await new Promise(resolve =>
                    setTimeout(resolve, 1000)
                );

                if (this.current <= this.last) {
                    return {
                        done: false,
                        value: this.current++
                    };
                } else {
                    return {
                        done: true
                    };
                }
            }
        };
    }
};

(async () => {

    for await (let value of range) {
        console.log(value);
    }

})();
 -->
