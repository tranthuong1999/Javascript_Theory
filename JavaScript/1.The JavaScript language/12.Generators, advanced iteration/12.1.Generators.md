3. Nội dung bài học 
3.1. Generator functions
Regular function trả về giá trị duy nhất hoặc không trả về gì cả
Generator có thể trả về nhiều giá trị , từng giá trị một theo yêu cầu

Genẻator thực sự hữu ích khi làm việc với iterable và tạo luồng dữ liệu 
2. Cú pháp khai báo Generator
Để tạo generator funtion ,sử dụng cú pháp function*
<!-- 
function* generateSequence() {
    yield 1;
    yield 2;
    return 3;
}
-->
Trong đó :
- function*: khai báo Generator function.
- yield : trả về 1 giá trị và tạm dừng việc thực thi 
- return: kết thúc Generator.

3. Gọi Generator function
Đây là điểm khác biệt quan trọng so với regular function.
<!-- 
function* generateSequence() {
    yield 1;
    yield 2;
    return 3;
}

let generator = generateSequence();

console.log(generator);
 -->
Khi gọi generateSequence():
- Code bên trong function chưa chạy
- JS trả về 1 đối tượng đặc biệt gọi là Generator object.
- Generator object quản lý quá trình thực thi của Generator

4. Phương thức next()
Phương thức chính của Generator() là next()
Khi gọi next(), Generator chạy cho đến câu lệnh yield tiếp theo, sau đó tạm dừng
Gía trị trả về của next luôn là object có 2 thuộc tính
| Thuộc tính | Ý nghĩa                                                     |
| ---------- | ----------------------------------------------------------- |
| `value`    | Giá trị được yield hoặc giá trị cuối cùng                   |
| `done`     | `false` nếu Generator chưa kết thúc, `true` nếu đã kết thúc |

Ví dụ:
<!-- 
function* generateSequence() {
    yield 1;
    yield 2;
    return 3;
}

let generator = generateSequence();

console.log(generator.next());
// { value: 1, done: false }

console.log(generator.next());
// { value: 2, done: false }

console.log(generator.next());
// { value: 3, done: true }
 -->
Lần 1: generator.next()
Chạy đến yield 1, trả về { value: 1, done: false }.
Lần 2: generator.next()
Tiếp tục chạy đến yield 2, trả về { value: 2, done: false }.
Lần 3: generator.next()
Tiếp tục chạy đến return 3, trả về { value: 3, done: true }.
Sau khi generator kết thúc , những lần gọi next tiếp theo sẽ trả về object có done : true , value : underdined

5. Vị trí dấu *
Cả hai cách đều hợp lệ:
<!-- function* generateSequence() {} -->
<!-- function *generateSequence() {} -->
Tài liệu khuyến khích cách thứ nhất vì dấu * thể hiện loại function và nên đặt cạnh từ khoá function

Bổ sung ngoài tài liệu gốc – Những case dễ nhầm
Case 1: Gọi Generator không đồng nghĩa với chạy function.
<!-- 
function* test() {
    console.log("A");
    yield 1;
}

const generator = test();

console.log("B");
generator.next();
 -->
Kết quả : B ==> A
test() chỉ tạo ra generator object . Code bên trọng chỉ chạy khi gọi next()

Case 2: yield không giống return.
<!-- 
function* test() {
    yield 1;
    yield 2;
    return 3;
}
-->
yield 1 : trả giá trị và vẫn có thể tiếp tục
yield 2: trả giá trị và vẫn có thể tiếp tục
return 3: kết thuc Generator

Case 3: yield không có giá trị.
<!-- 
function* test() {
    yield;
}

const generator = test();

console.log(generator.next());
// { value: undefined, done: false }
 -->
yield có thể không có giá trị, khi đó value là undefined
<!-- 
function* test() {
    console.log("A");
    yield 1;
    console.log("B");
    return 2;
}

const gen = test();

console.log("C");
console.log(gen.next());
 -->
Giải thích:
1. test() chỉ tạo generator object chưa chạy code bên trong 
2. console.log("C"); chạy trước 
3. gen.next() bắt đầu thực thi Generator
4. In A , sau đó gặp yield 1 và tạm dừng.
5. next() trả về { value : 1 , done : false}

Lưu ý: B chưa được in vì Generator đang tạm dừng tại yield 1

3.2. Generators are iterable
Generator là một interable . Vì vậy chúng có thể sử dụng for of để duyệt qua các giá trị mà Generator tạo ra
1. Sử dụng for...of với Generator
<!-- 
function* generateSequence() {
    yield 1;
    yield 2;
    return 3;
}

let generator = generateSequence();

for (let value of generator) {
    console.log(value);
}
-->
Kết quả:
1 2
Tại sao không có số 3 ?
for...of bỏ qua giá trị cuối cùng khi done : true
Ở ví dụ trên:
<!-- return 3; -->
Tạo kết quả:
<!-- { value: 3, done: true } -->
Do đó , for...of không hiển thị số 3
2. Muốn for...of lấy tất cả giá trị thì sử dụng yield
Nếu muốn hiển thị cả 1 , 2, 3 hãy thay return 3 bằng yield 3
<!-- 
function* generateSequence() {
    yield 1;
    yield 2;
    yield 3;
}

let generator = generateSequence();

for (let value of generator) {
    console.log(value);
}
 -->
Lý do: Cả ba giá trị đều được tạo bởi yield, nên đều có done: false.
3. Sử dụng spread syntax (...)
Vì Generator là iterable nên có thể sử dụng spread syntax để chuyển các giá trị thành 1 mảng
<!-- 
function* generateSequence() {
    yield 1;
    yield 2;
    yield 3;
}

let sequence = [0, ...generateSequence()];

console.log(sequence);
 -->
Kết quả : [0, 1, 2, 3]
Giải thích:
- generateSequence() trả về Generator object 
- ...generateSequence() lấy các giá trị được yield
- Các gía trị được đưa vào mảng sequence
Bổ sung ngoài tài liệu gốc – Những case đặc biệt dễ nhầm
Case 1: Generator chỉ duyệt được 1 lần theo trạng thái hiện tại 
<!-- 
function* generate() {
    yield 1;
    yield 2;
}

const gen = generate();

console.log([...gen]); // [1, 2]
console.log([...gen]); // []
 -->
Sau lần duyệt đầu tiên , Generator đã hoàn thành . Muốn duyệt lại từ đầu , phải tạo Generator object mới 
<!-- 
const gen2 = generate();
console.log([...gen2]); // [1, 2]
 -->
 Case 2: Spread syntax cũng bỏ qua giá trị từ return.
 <!-- 
 function* generate() {
    yield 1;
    yield 2;
    return 3;
}

console.log([...generate()]);
  -->
Kết quả : [1,2]
Không phải [1, 2, 3], vì spread syxtax cũng sử dụng cơ chể iterable và không lấy giá trị kết thúc done : true

Case 3: Không nên duyệt Generator vô hạn mà không có điều kiện dừng.

<!-- 
function* generate() {
    let i = 1;

    while (true) {
        yield i++;
    }
}

for (const value of generate()) {
    console.log(value);

    if (value === 5) {
        break;
    }
}
-->
Generator có thể tạo giá trị vô hạn . Khi sử dụng for...of , cần có break hoặc return để tránh vòng lặp mãi mãi
Bài tập kiểm tra :
<!-- 
function* test() {
    yield 10;
    return 20;
}

const gen = test();

console.log([...gen]);
 -->
Giải thích :
yield 10 trả về 10 với done : false
return 20 kết thúc Generator với done : true
Spread syntax chỉ lấy các giá trị được yiled , bỏ qua giá trị return

3.3. Using generators for iterables
1. Nhắc lại cách tạo iterable bằng Symbol.iterator
Ở bài Iterables, chúng ta đã tạo ra object range có thể duyệt bằng for...of
Code theo tài liệu gốc:
<!-- 
let range = {
    from: 1,
    to: 5,

    [Symbol.iterator]() {
        return {
            current: this.from,
            last: this.to,

            next() {
                if (this.current <= this.last) {
                    return {
                        done: false,
                        value: this.current++
                    };
                } else {
                    return { done: true };
                }
            }
        };
    }
};

console.log([...range]); // [1, 2, 3, 4, 5]
 -->
Giải thích:
- range là iterable object vì có phương thức [Symbol.iterator]().
- Khi for...of hoặc spread syntax sử dụng range, JavaScript gọi [Symbol.iterator]()
- Phương thức này trả về một iterator object.
- Iterator object phải có phương thức next().
- Mỗi lần gọi next(), nó trả về object có value và done.
2. Sử dụng Generator để viết iterable ngắn gọn hơn
<!-- 
let range = {
    from: 1,
    to: 5,

    *[Symbol.iterator]() {
        for (let value = this.from; value <= this.to; value++) {
            yield value;
        }
    }
};

console.log([...range]); // [1, 2, 3, 4, 5]
 -->
Điểm cần chú ý:
<!--  *[Symbol.iterator]() -->
Đây là cú pháp rút gọn của:
<!-- [Symbol.iterator]: function* () {} -->
Thay vì tự viết iterator object và next(), chúng ta chỉ cần dùng vòng lặp for kết hợp với yield.
3. Tại sao cách này hoạt động?


Bổ sung ngoài tài liệu gốc – Case đặc biệt dễ nhầm
Case 1: Generator method vẫn sử dụng được this.
<!-- 
const range = {
    from: 1,
    to: 3,

    *[Symbol.iterator]() {
        yield this.from;
        yield this.to;
    }
};

console.log([...range]); // [1, 3]
 -->
this ở đây tham chiếu đến object range khi phương thức được gọi theo cách thông thường.

Case 2: Không có yield thì không tạo ra phần tử nào.
<!-- 
const range = {
    from: 1,
    to: 3,

    *[Symbol.iterator]() {
        console.log("Iterator started");
    }
};

console.log([...range]); // []
 -->
Generator vẫn chạy nhưng không yield giá trị nào , nên kết quả spread vẫn là mảng rỗng
Case 3: Generator không tự biến object thành iterable.
<!-- 
function* generate() {
    yield 1;
    yield 2;
}

const obj = {
    from: 1,
    to: 2
};
 -->
obj không tự nhiên trờ thành iterable vì chúng ta đã khai báo Generator ở bên ngoài . Muốn for...ò duyệt được obj ,
cần cung cấp [Symbol.iterator] cho nó

3.4. Generator composition.
1 tính năng đặc biệt của Generator : Generator composition.
Nó cho phép kết hợp nhiều generator với nhau bằng cú pháp yield
1. Bài toán đặt ra
Giả sử chúng ta có một Generator tạo ra một dãy số:
<!-- 
function* generateSequence(start, end) {
    for (let i = start; i <= end; i++) {
        yield i;
    }
}
 -->
<!-- 
console.log([...generateSequence(1, 5)]);
// [1, 2, 3, 4, 5]
 -->
Bây giờ muốn tạo một dãy kí tự :
- Chữ số 0..9 (character codes 48–57).
- Chữ in hoa A..Z (character codes 65–90).
- Chữ thường a..z (character codes 97–122).

Thay vì viết lại logic tạo dãy số nhiều lần , chúng ta có thể 

2. Sử dụng yield*
<!-- yield* generator; -->
yield* cho phép  Generator uỷ quyền việc thực thi cho một Generator khác
Ví dụ theo tài liệu gốc:
<!-- 
function* generateSequence(start, end) {
    for (let i = start; i <= end; i++) yield i;
}

function* generatePasswordCodes() {

    // 0..9
    yield* generateSequence(48, 57);

    // A..Z
    yield* generateSequence(65, 90);

    // a..z
    yield* generateSequence(97, 122);

}

let str = '';

for (let code of generatePasswordCodes()) {
    str += String.fromCharCode(code);
}

console.log(str);
 -->
3. yield* hoạt động như thế nào?
<!-- yield* generateSequence(48, 57); -->
Generator bên ngoài sẽ lần lượt lấy các giá trị từ Generator bên trong và chuyển tiếp chúng ra bên ngoài 
Có thể hiểu:
<!-- yield* generateSequence(48, 57); -->
tưng đương với việc viết logic ra bên ngoài 
<!-- 
for (let i = 48; i <= 57; i++) {
    yield i;
}
-->
Tài liệu cũng đưa ra phiên bản viết không sử dụng yield*:
<!-- 
function* generateSequence(start, end) {
    for (let i = start; i <= end; i++) yield i;
}

function* generateAlphaNum() {

    // 0..9
    for (let i = 48; i <= 57; i++) yield i;

    // A..Z
    for (let i = 65; i <= 90; i++) yield i;

    // a..z
    for (let i = 97; i <= 122; i++) yield i;

}

let str = '';

for (let code of generateAlphaNum()) {
    str += String.fromCharCode(code);
}

console.log(str);
 -->
Hai cách cho kết quả giống nhau.
4. Ưu điểm của Generator composition
Theo tài liệu gốc:
- Có thể sử dụng các Generator đã viết 
- Kết hơp các luônf dữ liệu từ nhiều Generator
- Không cần lưu các kết quả trung gian vào 1 mảng
- - Code ngắn gọn và dễ tổ chức hơn.

Bổ sung ngoài tài liệu gốc – Những case đặc biệt dễ nhầm
Case 1: yield và yield* khác nhau
<!-- 
function* child() {
    yield 1;
    yield 2;
}

function* parent() {
    yield child();
}

console.log([...parent()]);
 -->
Kết quả:
<!-- [Generator object] -->
Vì yield child() trả về chính Generator object.
Nếu đổi thành:
<!-- 
function* parent() {
    yield* child();
}

console.log([...parent()]);
 -->
[1, 2]
Vì yield* chuyển tiếp từng giá trị Generator bên trong

Case 2: yield* cũng có thể nhận iterable khác Generator
<!-- 
function* test() {
    yield* [10, 20, 30];
}

console.log([...test()]);
 -->
yield* có thể duyệt 1 iterable , không chỉ Generator
Case 3: Generator bên trong kết thúc bằng return
<!-- 
function* child() {
    yield 1;
    return 100;
}

function* parent() {
    const result = yield* child();

    console.log("Result:", result);
}

console.log([...parent()]);
 -->
Điểm cần nhớ:
- yield 1 được chuyển ra bên ngoài
- Giá trị return 100 không được chuyển tiếp như 1 phần tử iterable
- Tuy nhiên, giá trị return của Generator con trở thành kết quả của biểu thức yield*.
<!-- 
function* child() {
    yield 10;
    yield 20;
}

function* parent() {
    yield 1;
    yield* child();
    yield 2;
}

console.log([...parent()]);
 -->
[1, 10, 20, 2]
Giải thích:
1. yield 1 → tạo giá trị 1.
2. yield* child() => chuyển tiếp lần lượt 10 và 20 từ Generator con
3. Generator con hoàn thành => Generator cha tiếp tục.
4. yield 2 → tạo giá trị 2.

Phân biệt cần nhớ:
- yield child() => trả về Generator object.
- yield* child() => chuyển tiếp các giá trị từ Generator con

3.5. "yield" is a two-way street
Đây là phần quan trọng của Generator. Từ đầu bài đến giờ, chúng ta mới sử dụng yield để đưa dữ liệu từ Generator ra bên ngoài.
Nhưng thực tế , yield có thể hoạt động theo 2 chiều
1. Trả kết quả từ Generator ra code bên ngoài
2. Nhận dữ liệu từ code bên ngoài truyền vào Generator

1. Truyền dữ liệu vào Generator bằng next(value)
<!-- 
function* gen() {
    // Pass a question to the outer code and wait for an answer
    let result = yield "2 + 2 = ?";

    alert(result);
}

let generator = gen();

let question = generator.next().value;

generator.next(4);
 -->
Bước 1: 
<!-- let question = generator.next().value; -->
next() bắt đầu chạy Generator.
Chạy đến yield "2 + 2 = ?".
Generator tạm dừng.
Giá trị "2 + 2 = ?" được trả ra bên ngoài.
Biến question nhận giá trị đó.
Bước 2:
<!-- generator.next(4); -->
Truyền giá trị 4 vào Generator.
Giá trị 4 trở thành kết quả của biểu thức yield.
Biến result nhận 4.
alert(result) hiển thị 4.
2. Lưu ý quan trọng về lần gọi next() đầu tiên
Lần gọi generator.next() đầu tiên luôn uôn phải được gọi mà không có argument.
<!-- 
function* gen() {
    let result = yield "Question";
    console.log(result);
}

let generator = gen();

generator.next(100);
 -->
Giá trị 100 bị bỏ qua.
Lý do : Genẻator chưa bắt đầu chạy , chưa có biểu thức yield nào để nhận giá trị 
Phải thực hiện:
<!-- 
generator.next();     // Bắt đầu Generator
generator.next(100);  // Truyền 100 vào yield
 -->
3. Có thể mất thời gian trước khi truyền dữ liệu
Code bên ngoài có thể không bắt buộc phải gọi next(value) ngay lập tức.
Tài liệu đưa ví dụ:
<!-- // resume the generator after some time
setTimeout(() => generator.next(4), 1000); -->
Generator vẫn giữ trạng thái tạm dưungf tại yield và chờ được tiếp tục
4. Ví dụ trao đổi dữ liệu nhiều lần
<!-- 
function* gen() {
    let ask1 = yield "2 + 2 = ?";

    alert(ask1); // 4

    let ask2 = yield "3 * 3 = ?"

    alert(ask2); // 9
}

let generator = gen();

alert(generator.next().value);    // "2 + 2 = ?"

alert(generator.next(4).value);   // "3 * 3 = ?"

alert(generator.next(9).done);    // true
 -->
| Lệnh                | Kết quả                                           |
| ------------------- | ------------------------------------------------- |
| `generator.next()`  | Trả về câu hỏi `2 + 2 = ?`                        |
| `generator.next(4)` | `ask1 = 4`, sau đó trả về câu hỏi `3 * 3 = ?`     |
| `generator.next(9)` | `ask2 = 9`, chạy đến cuối function, `done = true` |

Tài liệu ví cách hoạt động này giống trò chơi Ping-Pong:
- next(value) truyền dữ liệu vào Generator.
- yield trả dữ liệu ra ngoài.
- Hai bên tiếp tục trao đổi qua mỗi lần gọi.

Bổ sung ngoài tài liệu gốc – Những case đặc biệt dễ nhầm

Case 1: Giá trị truyền vào next() là kết quả của yield trước đó.
<!-- 
function* test() {
    let a = yield 10;
    let b = yield 20;

    return a + b;
}

const gen = test();

console.log(gen.next());
console.log(gen.next(5));
console.log(gen.next(7));
 -->
{ value: 10, done: false }
{ value: 20, done: false }
{ value: 12, done: true }
Giải thích :
next() đầu tiên trả 10.
next(5) khiến a = 5.
next(7) khiến b = 7.
return a + b trả 12.

Case 2: next() không truyền giá trị
<!-- 
function* test() {
    let result = yield 10;
    console.log(result);
}

const gen = test();

gen.next();
gen.next();
 -->
Vì next() thứ hai không truyền argument nên kết quả của biểu thức yiled là undefined

Case 3: Phân biệt giá trị trả về của next() và giá trị truyền vào next(value).
<!-- 
function* test() {
    let result = yield 10;
    return result;
}

const gen = test();

console.log(gen.next(100));
console.log(gen.next(200));
 -->
Kết quả :
<!-- 
{ value: 10, done: false }
{ value: 200, done: true }
 -->
100 bị bỏ qua vì đây là lần gọi đầu tiên. 200 được truyền vào biểu thức yield và trở thành result.

Bài tập thực hành :
<!-- 
function* test() {
    let a = yield 10;
    let b = yield 20;

    return a + b;
}
 -->
gen.next() → yield 10, trả về 10.
gen.next(3) → a = 3, tiếp tục đến yield 20.
gen.next(7) → b = 7, thực hiện return 3 + 7 = 10.

3.6. generator.throw
1. Ý tưởng chính
Ở phần trước, ta đã biết code bên ngòai có thể truyền giá trị vào Generator thông qua
<!-- generator.next(value); -->
Nhưng ngoài việc truyền giá trị, code bên ngoài còn có thể ném 1 lỗi vào bên trong Generator bằng 
<!-- generator.throw(error); -->
Lỗi được ném đúng vào vị trí yiled mà Generator đang tạm dùng 
2. Ví dụ trong tài liệu gốc
<!-- 
function* gen() {
    try {
        let result = yield "2 + 2 = ?";

        alert("The execution does not reach here");
    } catch(e) {
        alert(e);
    }
}

let generator = gen();

let question = generator.next().value;

generator.throw(
    new Error("The answer is not found in my database")
);
 -->
Diễn biến từng bước:
1. gen() tạo Generator nhưng chưa chạy nội dung hàm.
2. generator.next() bắt đầu chạy và dừng tại yield.
3. question nhận giá trị "2 + 2 = ?".
4. generator.throw(error) ném lỗi vào vị trí yield.
5. Lỗi được bắt bởi catch(e) bên trong Generator.
6. Dòng alert("The execution does not reach here") không được thực thi.
Kết quả: lỗi được xử lý bên trong catch.
3. Nếu Generator không bắt lỗi thì sao?
Nếu không có try...catch bên trong Generator, lỗi sẽ thoát ra ngoài nơi gọi generator.throw().
<!-- 
function* generate() {
    let result = yield "2 + 2 = ?";
}

let generator = generate();

let question = generator.next().value;

try {
    generator.throw(
        new Error("Answer not found")
    );
} catch(e) {
    console.log(e.message);
}
-->
4. Bổ sung ngoài tài liệu gốc – trường hợp dễ nhầm
throw() không giống next():
| Phương thức    | Tác dụng                                                  |
| -------------- | --------------------------------------------------------- |
| `next(value)`  | Tiếp tục Generator và truyền giá trị vào `yield` trước đó |
| `throw(error)` | Tiếp tục Generator bằng cách ném lỗi tại `yield` trước đó |

Lưu ý : Generator phải tạm dùng 1 yiled thì lỗi mới được ném vào vị trí đó như ví dụ trên

3.7. generator.return
1. Ý tưởng chính
generator.return(value) kết thúc quá trinhf thưc thi Generator và trả về giá trị được truyền vào
Cú pháp:
<!-- generator.return(value); -->
2. Ví dụ trong tài liệu gốc
<!-- 
function* gen() {
    yield 1;
    yield 2;
    yield 3;
}

const g = gen();

g.next();        // { value: 1, done: false }
g.return('foo'); // { value: "foo", done: true }
g.next();        // { value: undefined, done: true }
 -->
Phân tích:
1. g.next() chạy đến yield 1, Generator tạm dừng
2. g.return('foo') kết thúc Generator ngay tại thời điểm đó
3. Kết quả trả về là { value: "foo", done: true}
4. Gọi g.next() sau khi đã kết thúc sẽ nhận { value: undefined, done: true }.

Điểm quan trọng: yield 2 và yield 3 không được thực thi.
3. Gọi return() khi Generator đã hoàn thành
generator.return() trên một Generator đã hoàn thành , nó sẽ trả về giá trị được truyền vào
<!-- 
function* gen() {
    yield 1;
}

const g = gen();

g.next();              // { value: 1, done: false }
g.next();              // { value: undefined, done: true }
g.return("finished");  // { value: "finished", done: true }
 -->
4. Khi nào sử dụng?
Chúng ta thường không sử dung generator.return() vì phần lớn trường hợp muốn lấy tất cả các gía trị được Generator trả ra
Tuy nhiên, nó hữu ích khi muốn dừng Generator trong một điều kiện cụ thể.
5. Bổ sung ngoài tài liệu gốc – dễ nhầm
Phân biệt ba phương thức:

| Phương thức     | Ý nghĩa                                  |
| --------------- | ---------------------------------------- |
| `next(value)`   | Tiếp tục thực thi Generator              |
| `throw(error)`  | Ném lỗi vào vị trí `yield` đang tạm dừng |
| `return(value)` | Kết thúc Generator và trả về giá trị     |

6. Kiểm tra nhanh
<!-- 
function* gen() {
    yield "A";
    yield "B";
    yield "C";
}

const g = gen();

console.log(g.next());
console.log(g.return("STOP"));
console.log(g.next());
 -->

3.8. Summary – Tổng kết Generators
Các kiến thức chính theo bài:
| Kiến thức   | Nội dung cần nhớ                                               |
| ----------- | -------------------------------------------------------------- |
| `function*` | Khai báo Generator function                                    |
| `yield`     | Trả giá trị ra ngoài và tạm dừng thực thi                      |
| `.next()`   | Tiếp tục Generator, có thể truyền giá trị vào `yield` trước đó |
| `for...of`  | Duyệt các giá trị Generator tạo ra                             |
| `yield*`    | Ủy quyền cho một Generator hoặc iterable khác                  |
| `.throw()`  | Ném lỗi vào vị trí `yield` đang tạm dừng                       |
| `.return()` | Kết thúc Generator và trả về giá trị                           |
Ba điều dễ nhầm cần nhớ:
1. Gọi generator fucntion chưa thực thi thân hàm , phải gọi next mới bắt đầu
2. return tạo kết quả done: true , nên giá trị này không được for...of hoặc spread thu thập
3. .next(value) truyền giá trị vào yiled trước đó , đối số của lần .next() đầu tiên bị bỏ qua
