1.2. Caching decorator
Ở mục 1.1 chúng ta thấy cách caching hoạt động . Tuy nhiên có 1 số vấn đề :
Nếu có 5 function cần caching , chúng ta phải viết logic kiểm tra và lưu cache 5 lần
Decorator giúp chúng ta giải quyết vấn đề này bằng cách bọc 1 function khác để bổ sung chức năng mà không cần sửa gốc code
Ví dụ:
<!-- 
function slow(x) {
    console.log(`Called with ${x}`);
    return x;
}

function cachingDecorator(func) {
    let cache = new Map();

    return function(x) {
        if (cache.has(x)) {
            return cache.get(x);
        }

        let result = func(x);

        cache.set(x, result);

        return result;
    };
}

slow = cachingDecorator(slow);

console.log(slow(1));
console.log(slow(1));
console.log(slow(2));
 -->
Phân tích cách hoạt động
Bước 1 : Truyền function gốc vào decorator
<!-- slow = cachingDecorator(slow); -->
Bước 2: cachingDecorator() tạo một Map để lưu cache
Bước 3: Decorator trả về 1 function mới (wrapper function).
Bước 4:Biến slow được gắn cho function này
Từ đó, mỗi lần gọi slow(1):
- Nếu đã có cache => trả về kết quả cũ
- Nếu chưa có => gọi funcion gốc func(x) , lưu kết quả trả về
Điểm quan trọng: Function slow ban đầu không bị thay đổi nội dung. Chúng ta chỉ bọc nó bằng một function mới để bổ sung caching.
<!-- 
function multiply(x) {
    console.log("Calculating...");
    return x * 2;
}

multiply = cachingDecorator(multiply);

console.log(multiply(5));
console.log(multiply(5));
console.log(multiply(10));
console.log(multiply(5));
 -->

<!--

}

2. Using func.call for the context
2.1. Vấn đề mất this khi dùng wrapper
Decorator dùng một wrapper function để bọc 1 function gốc
Tuy nhiên, có 1 vấn đề : wrapper có thể làm mất giá trị this của function gốc
Xét ví dụ:
<!-- 
let user = {
  name: "Martin",

  sayHi() {
    console.log(`Hello, ${this.name}`);
  }
};

user.sayHi(); // Hello, Martin
 -->
Khi gọi user.sayHi(), JavaScript xác định this là user.
Bây giờ thử bọc function bằng Decorator
Bài tập nhỏ :
<!-- 
let user = {
  name: "Alex",

  sayHi() {
    console.log(this.name);
  }
};

function wrap(func) {
  return function() {
    func();
  };
}

user.sayHi = wrap(user.sayHi);

user.sayHi();
 -->
 Nghĩa là this đang là undefined , nhưng code cố trình truy cập this.name
 Diễn biến khi chạy code:
 <!-- 
 user.sayHi = wrap(user.sayHi);
user.sayHi();
  -->
1. user.sayHi() gọi wrapper với this = user
2. Wrapper gọi func() mà không truyền context.
3. sayHi() chạy với this = undefined.
4. Truy cập this.name gây lỗi.
   
2.2. func.call(context, ...args)
Để giải quyết vấn đề mất this , JS cung cấp phương thức call
Cú pháp:
<!-- func.call(context, arg1, arg2, ...); -->
Trong đó:
-func : function cần gọi
context : gía trị this mà function nhận được 
arg1, arg2, ...:các argument truyền vào funcion
Ví dụ cơ bản:

<!-- 
function sayHi() {
  console.log(`Hello, ${this.name}`);
}

let user = {
  name: "Martin"
};

sayHi.call(user);
 -->
Ở đây, call(user) có nghĩa là gọi sayHi() với this = user.
Áp dụng vào Decorator
<!-- 
function wrap(func) {
  return function() {
    return func.call(this);
  };
}

let user = {
  name: "Alex",

  sayHi() {
    console.log(`Hello, ${this.name}`);
  }
};

user.sayHi = wrap(user.sayHi);

user.sayHi(); // Hello, Alex
 -->
Điểm quan trọng nằm ở : func.call(this);
this bên trong wrapper là user , vì wrapper được gọi bằng user.sayHi()
func.call(this) truyền chính user đó và function gốc
Vì vậy ,this trong sayHi lại là user
<!-- 
function introduce(age) {
  console.log(`${this.name} is ${age} years old`);
}

const user = {
  name: "Martin"
};

introduce.call(user, 26);
 -->
 call vửa cho phép gọi function ,vừa cho phép chỉ định this , đồng thời truyền argument riêng lẻ
 2.3. Truyền this cho function gốc
 Trong Decorator, ta thường không biết function gốc cần bao nhiêu argument . Vì vậy wrapper cần chuyển tiếp toàn bộ argument nhận được 
 <!-- 
 function wrap(func) {
  return function(...args) {
    return func.call(this, ...args);
  };
}
  -->
...args : thu thập tất cả argument nhận được 
this: giữ context của wrapper
func.call(this, ...args) : gọi function gốc với đúng context và argument
Bài tập nhỏ:

<!-- 
function multiply(a, b) {
  return a * b * this.factor;
}

const calculator = {
  factor: 2
};

function wrap(func) {
  return function(...args) {
    return func.call(this, ...args);
  };
}

calculator.multiply = wrap(multiply);

console.log(calculator.multiply(3, 4));
 -->
2.4. Call forwarding - chuyển tiếp lời gọi
<!-- 
function wrapper(...args) {
  return func.call(this, ...args);
}
 -->
 Wrapper chuyển tiếp:
- Context (this) của lời gọi ban đầu
- Toàn bộ arguments.
- Giá trị trả về functio gốc(return)

5. Borrowing a method
5.1. Vấn đề với arguments.join()
Argument là array like objetc không phải thực sự là array
<!-- 
function showArguments() {
  console.log(arguments);
  console.log(arguments.join(", "));
}

showArguments("A", "B", "C");
 -->
TypeError: arguments.join is not a function
Tại sao?
Vì arguments không có phương thức join . Phương thức join thuộc về array
<!-- 
const arr = ["A", "B", "C"];

console.log(arr.join(", ")); // A, B, C
 -->
Ý tưởng : Borrowing a method
JS cho phép ta dùng call hoặc apply để gọi với 1 phương thức this tuỳ ý
<!-- 
function showArguments() {
  console.log([].join.call(arguments, ", "));
}

showArguments("A", "B", "C");
 -->
Giải thích:
- [].join: lấy phương thức join từ Array.
- .call(arguments, ", "): gọi join với this = arguments.
- ", ": dấu phân cách giữa các phần tử.

5.2. Mượn phương thức của Array

Ví dụ, mượn Array.prototype.slice():
<!-- 
function showArguments() {
  const args = Array.prototype.slice.call(arguments);

  console.log(args);

}

showArguments("A", "B", "C");
 -->
 Ở đây:
- Array.prototype.slice: lấy phương thức slice từ Array.
- .call(arguments): gọi slice() với this là arguments
- slice() taọ ra 1 array mới chứa các phần tử tương ứng

Cách viết ngắn gọn hơn : [].slice().call(arguments)
5.3. [].join.call(arguments)

6. Decorators and function properties
6.1. Decorator ảnh hưởng đến properties
Trong JS, function cũng là 1 object . Vì vậy , function có thể chứa các thuộc tính riêng
Ví dụ :
<!-- 
function sayHi() {
  console.log("Hello");
}

sayHi.counter = 0;

console.log(sayHi.counter); // 0
 -->
Bây giờ , ta sử dụng Decorator để ọc function
<!-- 
function decorator(func) {
  return function() {
    return func.apply(this, arguments);
  };
}

function sayHi() {
  console.log("Hello");
}

sayHi.counter = 0;

sayHi = decorator(sayHi);

console.log(sayHi.counter); // undefined
 -->
 Bài tập nhỏ :
 <!-- 
 function original() {}

original.version = "1.0";

function wrap(func) {
  return function() {
    return func.apply(this, arguments);
  };
}

const wrapped = wrap(original);

console.log(original.version);
console.log(wrapped.version);
 -->

Điểm cần nhớ: Decorator có thể giữ nguyên cách gọi function nhưng không tự động giữ lại các properties của function gốc.
6.2. Bảo toàn properties bằng Proxy
JS Proxy được giới thiệu như 1 cách để tạo wrapper mà vẫn truy cập được các properties của function gốc
<!-- 
function original() {
  console.log("Hello");
}

original.version = "1.0";

const wrapped = new Proxy(original, {
  apply(target, thisArg, args) {
    console.log("Before");
    return target.apply(thisArg, args);
  }
});

wrapped();
console.log(wrapped.version);
 -->
Phân biệt hai cách:
<!-- 
// Wrapper function thông thường
const wrapped = function(...args) {
  return original.apply(this, args);
};

// Proxy
const wrapped = new Proxy(original, {
  apply(target, thisArg, args) {
    return target.apply(thisArg, args);
  }
});
 -->
 Cách thứ nhất tạo function độc lập . Cách thứ 2 tạo Proxy đại diện cho function gốc , nên các properties của target
vẫn có thể được truy cập .
