1. Global object là gì?
2.1.Khái niệm 
Global object là 1 object đặc biệt của JS , chứa các thuộc tính và hàm có thể truy cập tư nhiều nơi trong chương trình
Ví dụ , JS cung cấp sẵn :
<!-- 
console.log(Math);
console.log(Array);
console.log(Promise);
console.log(JSON);
 -->
 Bạn có thể sử dugj chúng ở nhiều nơi mà k cần import hay khai báo trước
 Những Object này được lưu ở đâu ?
 Chúng thuộc môi trường global của JS
 2.2. Global object trong từng môi trường
 Tên của global object phụ thuộc vào môi trường JS chạy
 | Môi trường       | Global object |
 | ---------------- | ------------- |
 | Browser          | `window`      |
 | Node.js          | `global`      |
 | Chuẩn dùng chung | `globalThis`  |

Ví dụ trong trình duyệt:
<!-- 
console.log(window);
console.log(window.Math);
console.log(window.Array);
 -->
2.3. globalThis là gì?
Trước đây mỗi môi trường có một tên global object riêng :
Browser dùng window
Nodejs dùng global
Để có 1 cách try cập thống nhất , JS bổ sung globalThis
<!-- console.log(globalThis); -->
Trong trình duyệt thông thường:
<!-- console.log(globalThis === window); // true -->
Trong Node.js:
<!-- console.log(globalThis === global); // true -->
Ghi nhớ : Khi viết JavaScript có thể chạy ở nhiều môi trường , ưu tien globalThis thay vì phụ thuộc vào window hoặc global
Bài tập nhỏ 1:
Dự đoán kết quả:
<!-- 
console.log(window === globalThis);

console.log(window.Math === Math);

console.log(globalThis.Array === Array);
 -->
globalThis là cách truy cập thống nhất đến global object của từng môi trường

Browser
└── Global object = window = globalThis

Node.js
└── Global object = global = globalThis

2. Truy cập Global object
2.1. Khai báo biến global bằng var
Trong trình duyệt , nếu khai báo var ở phamj vi global:
<!-- 
var user = "Martin";

console.log(window.user); // Martin
console.log(globalThis.user); // Martin
 -->
Biến user được khai báo bằng var ở global scope nên nó trở thành thuộc tính của window
2.2. So sánh với let và const
<!-- 
let age = 27;
const country = "Vietnam";

console.log(window.age); // undefined
console.log(window.country); // undefined

console.log(age); // 27
console.log(country); // Vietnam
 -->
Tại sao?
- var global tạo thuộc tính trên window 
- let và const global không tạo thuộc tính trên window
- nhưng cả 3 vẫn có thể tryuy cập trong global scope
- 
| Khai báo global trong browser | Truy cập trực tiếp | Thuộc tính `window` |
| ----------------------------- | ------------------ | ------------------- |
| `var name`                    | Có                 | Có                  |
| `let name`                    | Có                 | Không               |
| `const name`                  | Có                 | Không               |

Bài tập nhỏ :
<!-- 
var a = 10;
let b = 20;
const c = 30;

console.log(globalThis.a);
console.log(globalThis.b);
console.log(globalThis.c);
 -->
Global Environment
│
├── Object Record (globalThis)
│   └── a = 10
│
└── Declarative Record
    ├── b = 20
    └── c = 30

3. Sử dụng Global object
Bạn cũng có thể tự tạo thuộc tính trên global object mà không cần khai báo var , let hay const
<!-- 
globalThis.user = "Martin";

console.log(user);            // Martin
console.log(globalThis.user); // Martin
 -->
 Ở đây:
-globalThis.user = "Martin" tạo thuộc tính user trên Global object
Trong môi trương global thông thường , thuộc tính này có thể truy cập trực tiếp bằng user
Lưu ý: k nên lạm dụng cách này vì dễ tạo ra biến global ngoài ý muốn và gây xung đột biến
<!-- 
globalThis.name = "Martin";

function sayHi() {
    console.log(name);
}

sayHi();
 -->
1. globalThis.name = "Martin" tạo thuộc tính name trên Global object.
2. Khi sayHi() chạy, JavaScript tìm biến name trong phạm vi của function.
3. Không tìm thấy biến cục bộ nên tiếp tục tìm ở môi trường bên ngoài.
4. Tìm thấy name trên Global object nên in ra "Martin"
   
Đây là cơ chế scope chain trong closure

4. Using for polyfills
4.1. Polyfill là gì?
Polyfill là đoạn code bổ sung tính năng JS mà môi trường hiện tại chưa hỗ trợ 
Ví dụ: Một trình duyệt cũ chưa hỗ trợ Array.prototype.includes().
Ta có thể kiểm tra trước khi bổ sung
<!-- 
if (!Array.prototype.includes) {
    Array.prototype.includes = function (value) {
        return this.indexOf(value) !== -1;
    };
}
-->
Giải thích:
-Array.prototype.includes: kiểm tra tính năng có tồn tại không
-Nếu chưa có (!), ta tự bổ sung implementation.
- Nếu đã có không cần làm gì
4.2. Tại sao cần kiểm tra trước?
Không nên ghi đè 1 tính năng mà đã được JS hỗ trợ
Ví dụ:
<!-- 
if (!globalThis.Promise) {
    // Bổ sung Promise polyfill
}
 -->
 Ở đây , globalThis giúp kiểm tra 1 tính năng global có tồn tại trong môi trươngf hay k
 Lưu ý: Đây là ví dụ minh họa. Trong dự án thực tế, polyfill thường được dùng từ thư viện chuyên dụng để đảm bảo tính tương thích.
