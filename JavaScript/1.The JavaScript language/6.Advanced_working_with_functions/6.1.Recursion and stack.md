1. Two ways of thinking
1.1. Recursion là gì?
Recursion ( đệ quy) là ĩ thuật trong đó 1 function tự gọi lại nó để giải quyết 1 bài toán
<!-- 
function sayHello() {
    console.log("Hello");

    sayHello();
}

sayHello();
 -->

Function sayHello sẽ gọi lại chính nó liên tục kết quả là chương trình sẽ chạy mãi cho đến khi maxium call stack
Một function đệ quy thường có 2 thành phần :
Base case : điều kiện dừng giúp funtion k gọi chính nó nữa
Recursive step : bước đệ quy , function gọi lại chính nó với bài toán nhỏ hơn

1.2. Hai cách giải quyết một bài toán
Cách 1: Iterative thinking – Sử dụng vòng lặp
<!-- 
function pow(x, n) {

    let result = 1;

    for (let i = 0; i <= n; i++) {
        result *= x;
    }

    return result;
}
console.log(pow(2, 5))
 -->

Cách 2: Recursive thinking – Sử dụng đệ quy
<!-- 
function pow(x, n) {
    if (n === 1) {
        return x;
    }

    return x * pow(x, n - 1);
}

console.log(pow(2, 4)); // 16
 -->
ở đây thay vì dùng vòng lặp function sẽ tự gọi lại chính nó

5. Summary – Tổng kết Recursion and stack
5.1. Recursion là gì?
Recursion (đệ quy) là kỹ thuật một function tự gọi lại chính nó để giải quyết bài toán nhỏ hơn.

Một hàm đệ quy cần có hai thành phần:
- Base case: Điều kiện dừng recursion.
- Recursive step: Bước gọi lại chính function với dữ liệu nhỏ hơn.
  <!-- 
  function countDown(n) {
    if (n === 0) return; // Base case

    console.log(n);
    countDown(n - 1);   // Recursive step
}
-->
5.2. Execution context và Call Stack
- Mỗi lần gọi function sẽ tạo một Execution Context.
- Các Execution Context được quản lý trong Call Stack.
- Call Stack hoạt động theo nguyên tắc LIFO (Last In, First Out).
- Khi function kết thúc, Execution Context được lấy ra khỏi Stack.
5.3. Recursion và Loop
| Tiêu chí       | Recursion                       | Loop                    |
| -------------- | ------------------------------- | ----------------------- |
| Cách thực hiện | Function tự gọi lại             | `for`, `while`          |
| Bộ nhớ         | Tốn Stack theo độ sâu gọi hàm   | Thường ít tốn Stack hơn |
| Điều kiện dừng | Base case                       | Điều kiện vòng lặp      |
| Phù hợp        | Cấu trúc dữ liệu lồng nhau, cây | Lặp tuần tự             |
5.4. Recursive structures
Một cấu trúc dữ liệu có thể chứa các cấu trúc nhỏ hơn cùng loại.
<!-- 10 → 20 → 30 → null -->
Mỗi node gồm:
- value: Giá trị của node.
- next: Tham chiếu đến node tiếp theo.
- null: Đánh dấu node cuối cùng.
Có thể duyệt Linked List bằng recursion hoặc loop.
5.5. Những điều cần nhớ
1. Luôn xác định điều kiện dừng khi viết recursion.
2. Mỗi lần đệ quy nên tiến gần hơn đến điều kiện dừng.
3. Hiểu Call Stack để biết thứ tự thực thi và trả về.
