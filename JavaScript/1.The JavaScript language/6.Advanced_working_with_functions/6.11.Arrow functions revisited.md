* Bắt đầu – Phần 1: Arrow functions have no this
1.1. Ôn lại this trong regular function
Với regular function, this phụ thuộc vào cách function được gọi 
<!-- 
let user = {
    name: "Martin",

    sayHi() {
        console.log(this.name);
    }
};

user.sayHi(); // Martin
 -->
 Ở đây:
- Function được gọi thông qua user
- Vì vậy this = user
- this.name trả về "Martin"
 
1.2. this trong arrow function
Arrow function không có this riêng . Nó lấy this từ phạm vi bên ngoài nơi nó được tạo ra ( lexical this )
Ví dụ :
 <!--
 let user = {
    name: "Martin",

    sayHi() {
        let arrow = () => {
            console.log(this.name);
        };

        arrow();
    }
};

user.sayHi(); // Martin
   -->
Giải thích :
1. user.sayHi() được gọi thông qua object user;
2. Vì vậy this bên trong sayHi() là user
3. Arrow funcion không tạo this riêng
4. Nó sử dụng this từ sayHi()
5. Kết quả là "Martin"

Điểm cần nhớ
-Regulả function : this phụ thuộc vào cách gọi
- Arrow function : this được kế thừa từ phạm vi bên ngoài 
Bài tập 1 :
<!-- 
let user = {
    name: "Martin",

    sayHi() {
        let arrow = () => {
            console.log(this.name);
        };

        arrow();
    }
};

user.sayHi();
 -->
1.3 – Arrow function lấy this từ đâu?
<!-- 
let user = {
    name: "Martin",

    sayHi() {
        let arrow = () => {
            console.log(this.name);
        };

        arrow();
    }
};

user.sayHi(); // Martin
 -->
 Arrow function lấy this từ phạm vi bên ngoài , tức là sayHi()
 Lưu ý: Arrow function không lấy this từ pbject chứa nó
 Ví dụ dễ nhầm :
 <!-- 
 let user = {
    name: "Martin",

    sayHi: () => {
        console.log(this.name);
    }
};

user.sayHi();
  -->
sayHi() là arrow function nên this không phải là user . Nó kế thừa this từ phạm vi bên ngoiaf object
Bài tập :
<!-- 
let user = {
    name: "Martin",

    sayHi() {
        let arrow = () => {
            console.log(this.name);
        };

        arrow();
    }
};

let admin = {
    name: "John"
};

user.sayHi.call(admin);
 -->
1. call(admin) gọi sayHi() với this = admin.
2. Arrow function được tạo bên trong sayHi().
3. Arrow function kế thừa this từ sayHi().
4. Vì vậy this.name = admin.name = "John"

Ghi nhớ: Arrow function không có this riêng , mà kế thừa this nơi nó tạo ra

* 2. Arrow functions can't be called with new
2.1. Ôn lại new với regular function
Trong JS chúng ta có thể dùng regular function làm constructor tạo object
<!-- 
function User(name) {
    this.name = name;
}

let user = new User("Martin");

console.log(user.name); // Martin
 -->
Khi gọi new User("Martin"), JavaScript thực hiện các bước:
1. Tạo 1 object mới
2. Gán this bên trong function bằng object mới đó
3. Chạy phần thân function
4. Trả về object mới 
   
2.2. Arrow function không thể dùng với new
Tại sao ?
Arrow function không có cơ chế constructor và không có this riêng . Vì vậy , nó không thể gọi bằng từ khoá new
So sánh:
| Tiêu chí          | Regular function                              | Arrow function            |
| ----------------- | --------------------------------------------- | ------------------------- |
| Sử dụng với `new` | Dùng được với `new` nếu là constructor hợp lệ | Không dùng được với `new` |
| `this`            | Có `this` riêng khi gọi bằng `new`            | Không có `this` riêng     |
| Constructor       | Có thể làm constructor                        | Không thể làm constructor |
Bài tập :
<!-- 
const Person = (name) => {
    this.name = name;
};

console.log(typeof Person);
console.log(new Person("Martin"));
 -->
Arrow function vẫn có kiểu function trong JavaScript.
Điểm dễ nhầm: typeof Person === "function" không có nghĩa là function đó dùng được với new.

****************************************************************************************************************************
* Phần 3 – Arrow functions don't have arguments.
3.1. arguments trong regular function là gì?
arguments là 1 object đặc biệt có sẵn bên trong regular function, chứa tất cả arguments được truyền vào khi gọi function
<!-- 
function showArguments() {
    console.log(arguments);
}

showArguments("Martin", 25, "Frontend");
 -->
Chúng ta có thể truy cập từng argument bằng index:
<!-- 
function showArguments() {
    console.log(arguments[0]);
    console.log(arguments[1]);
    console.log(arguments.length);
}

showArguments("Martin", 25, "Frontend");

// Martin
// 25
// 3
 -->
3.2. Arrow function không có arguments
Ví dụ :
<!-- 
const showArguments = () => {
    console.log(arguments);
};

showArguments("Martin", 25);
 -->
Arrow function không tự tạo arguments riêng.
Nếu không có arguments ở phạm vi bên ngoài , đoạn code này sẽ gây ReferenceError;
3.3. Dùng rest parameters thay thế
<!-- 
const showArguments = (...args) => {
    console.log(args);
};

showArguments("Martin", 25, "Frontend");
 -->

Khác với arguments, args là 1 array thực sự có các phương thức của array nhu : map(), filter(),..
So sánh:
| Tiêu chí        | `arguments`                          | `...args`                                    |
| --------------- | ------------------------------------ | -------------------------------------------- |
| Phạm vi sử dụng | Có trong regular function            | Dùng được trong cả regular và arrow function |
| Kiểu dữ liệu    | Là array-like object                 | Là Array thực sự                             |
| Array methods   | Không có các array methods trực tiếp | Có thể dùng `map`, `filter`, `reduce`        |

* Phần 4 – Arrow functions don't have super
4.1. super là gì?
Trong JS , super được sử dụng class kế thừa để truy cập :
Constructor là class cha : super();
Method của class cha : super.method();
<!-- 
class Animal {
    speak() {
        console.log("Animal makes a sound");
    }
}

class Dog extends Animal {
    speak() {
        super.speak();
        console.log("Dog barks");
    }
}

let dog = new Dog();
dog.speak();
 -->
4.2. Arrow function và super
Arrow function không có super riêng . Nó kế thừa super từ phạm vi bên ngoài , tương tự như nó cách kế thừa this
<!-- 
class Animal {
    speak() {
        console.log("Animal speaks");
    }
}

class Dog extends Animal {
    speak() {
        let arrow = () => {
            super.speak();
        };

        arrow();
    }
}

new Dog().speak();
 -->
1. Dog kế thừa Animal.
2. Method speak() của Dog có thể sử dụng super.speak().
3. Arrow function được tạo bên trong method này.
4.  Arrow function sử dụng super từ method bên ngoài.

Chú ý : arrow function không tạo this , argument , super riêng
4 điều quan trọng cần nhớ:
1. Arrow function kế thừa this từ phạm vi bên ngoài.
2. Không thể sử dụng arrow function làm constructor với new.
3. Arrow function không có arguments riêng, dùng ...args thay thế.
4. Arrow function kế thừa super từ phạm vi bên ngoài.
