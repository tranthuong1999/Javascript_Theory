1. Rest parameters (...)
1.1. Function nhận nhiều arguments
<!-- 
function sum(a, b) {
    return a + b;
}

console.log(sum(1, 2));       // 3
console.log(sum(1, 2, 3));    // 3
console.log(sum(1, 2, 3, 4)); // 3
 -->
 Có thể truyền bao nhiêu arguments tuỳ ý khi gọi function , kể cả khi funtion chỉ khai báo 2 parameters
 Nhưng có một điểm cần hiểu:
- a nhận argument đầu tiên.
- b nhận argument thứ hai.
- Các arguments còn lại không được sử dụng trong phép tính.
JS không báo lỗi khi bạn truyền thừa arguments
1.2. Rest parameters là gì? 
Rest parameters cho phép thu thập các arguments còn lại vào 1 array bằng cú pháp ...
Ví dụ 
<!-- 
function sumAll(...args) {
    let sum = 0;

    for (let arg of args) {
        sum += arg;
    }

    return sum;
}

console.log(sumAll(1, 2, 3));       // 6
console.log(sumAll(1, 2, 3, 4, 5)); // 15
 -->
 Bên trong function tương đương:
 args = [1, 2, 3, 4];
 Do đó chúng có thể các phương thức của Array như : map , filter,...
 1.3. Kết hợp parameters thông thường và Rest parameters
 Bạn không nhất thiết phải gom tất cả argument vào rest parameters
 <!-- 
 function showName(firstName, lastName, ...titles) {
    console.log(firstName);
    console.log(lastName);
    console.log(titles);
}

showName("Julius", "Caesar", "Consul", "Imperator");
Kết quả :
Julius
Caesar
["Consul", "Imperator"]
  -->
1.4. Rest parameters phải nằm cuối cùng
Ví dụ hợp lệ:
<!-- function test(a, b, ...rest) {} -->
Ví dụ không hợp lệ:
<!-- function test(a, ...rest, b) {} -->
Tại sao : 
Vì ...rest có nhiệm vụ thu thập tất cả các arguments còn lại . Nếu phía sau nó vẫn có paramters khác thì JS không biết 
phân chia arguments như thế nào

2. The "arguments" variable
2.1. arguments là gì?
Trước khi có Rest parameters, JS cung cấp 1 biến đặc biệt là arguments để truy cập tất cả arguments
được truyền vào function
<!-- 
function showArguments() {
    console.log(arguments);
}

showArguments(10, 20, 30);
 -->
Kết quả: [10, 20, 30]
Bạn có thể truy cập từng argument bằng index:
<!-- 
function showArguments() {
    console.log(arguments[0]); // 10
    console.log(arguments[1]); // 20
    console.log(arguments[2]); // 30
}

showArguments(10, 20, 30);
 -->
2.2. arguments không phải Array
arguments là một array-like object( đối tượng có hình dạng giống array) không phải array thực sự 
Nó có :
length
Index để truy cập các phần tử 
Nhưng k có đâỳ đủ các phương thức như : map() , filter() , reduce();
<!--
function test() {
    console.log(arguments.length); // 3
    console.log(arguments[0]);     // 10

    console.log(arguments.map);    // undefined
}

test(10, 20, 30);
  -->
2.3. So sánh Rest parameters và arguments
| Tiêu chí            | Rest parameters | arguments         |
| ------------------- | --------------- | ----------------- |
| Kiểu dữ liệu        | Array           | Array-like object |
| Truy cập bằng index | Có              | Có                |
| `length`            | Có              | Có                |
| `map/filter/reduce` | Có              | Không trực tiếp   |
| Arrow function      | Có thể sử dụng  | Không có riêng    |
2.4. Arrow function không có arguments riêng
<!-- 
const show = () => {
    console.log(arguments);
};
 -->
 Arrow function không tự tạo biến arguments . Nếu có thể truy cập arguments , nó sẽ lấy scope từ bên ngòai ,
 nếu không có sẽ gây ReferenceError
 Muốn nhận nhiều argument trong arrow function , hãy sử dụng rest parameters
 <!-- 
 const show = (...args) => {
    console.log(args);
};

show(10, 20, 30);
  -->
Bài tập thực hành:
<!-- 
function test(a, b) {
    console.log(arguments.length);
    console.log(arguments[2]);
    console.log(arguments.map);
}

test(10, 20, 30);
 -->

3. Spread syntax (...)
3.1. Spread là gì?
Spread syntax sử dụng dấu ..., giống Rest paramters nhưng mục đích hoàn toàn khác nhau
Rest : gom nhiều phần tử thành 1 mảng
Spread : trải các phần tử của một interable thành các phần tử riêng lẻ
<!-- 
const numbers = [1, 2, 3];

console.log(...numbers);
Result : 1 2 3
 -->
3.2. Truyền Array vào Function
Giả sử bạn muốn tìm số lớn nhất trong 1 array
Bạn có thể sử dụng Math.max();
<!-- console.log(Math.max(3, 5, 1)); // 5 -->
Nhưng nếu dữ liệu nằm trong array:
<!-- const numbers = [3, 5, 1];

console.log(Math.max(numbers)); // NaN -->

Tại sao:
Vì Math.max() nhận nhiều argument riêng lẻ , nhưng bạn lại truyền vào một array
Sử dụng Spread để giải quyết:
<!-- 
const numbers = [3, 5, 1];

console.log(Math.max(...numbers)); // 5
 -->
JavaScript sẽ trải Array thành: Math.max(3, 5, 1);
Bài tập thực hành:
<!-- 
const numbers = [10, 20, 30];

function calculate(a, b, c) {
    return a + b + c;
}

console.log(calculate(...numbers));
 -->
3.3. Spread với nhiều Iterable
Bạn có thể sử dụng spread để kết hợp nhiều array
<!-- 
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];

const combined = [...arr1, ...arr2];

console.log(combined);
 -->
Kết quả:
<!-- [1, 2, 3, 4, 5, 6] -->
Bạnc cũng có thể kết hợp Spread với giá trị thông thường
<!-- 
const arr1 = [1, 2, 3];

const combined = [0, ...arr1, 4, 5];

console.log(combined);
 -->
Kết quả:
<!-- [0, 1, 2, 3, 4, 5] -->
3.4. Spread với String và Iterable
Spread k chỉ hoạt động với array > Nó còn hoạt động với các Iterable như String , set
Ví dụ với String:
<!-- 
const str = "Hello";
console.log([...str]);
 -->
Kết quả: ["H", "e", "l", "l", "o"]

Ví dụ với Set:
<!-- 
const set = new Set([1, 2, 2, 3]);

console.log([...set]);
 -->
 Vì set chỉ lưu các giá trị duy nhất
 3.5. Spread và Array.from()
 Cả 2 đều chuyển Iterable hoặc  Array-like object thành Array , nhưng có 1 số khác biệt
 <!-- 
 const str = "Hello";

const arr1 = [...str];
const arr2 = Array.from(str);

console.log(arr1); // ["H", "e", "l", "l", "o"]
console.log(arr2); // ["H", "e", "l", "l", "o"]
  -->
Điểm khác biệt quan trọng :
Spread hoạt động với Iterable.
Array.from() hoạt động với Iterable và array like object
Ví dụ arguments:
<!-- 
function test() {
    const arr = Array.from(arguments);
    console.log(arr);
}

test(10, 20, 30);
 -->
 arguments không phải là Iterable trong mọi môi trương JS cũ , nhưng Array.from() vẫn có thể chuyển nó thành Array
 nhờ đặc tính array like
 Bài tập nhỏ 4
 <!-- 
const arr1 = [1, 2];
const arr2 = [3, 4];

const result = [0, ...arr1, ...arr2, 5];

console.log(result);
  -->
Một điểm cần phân biệt
1. [...arr1, ...arr2]: Tạo một Array mới và trải các phần tử.
2. Math.max(...arr1): Trải các phần tử thành arguments riêng biệt.
3. [...str]: Trải các ký tự của String thành từng phần tử.

4. Copy an array/object
4.1. Copy Array bằng Spread
Trong JS khi gán 1 array cho biến khác , bạn chỉ sao chép reference chứ k tạo array mới
<!-- 
const arr1 = [1, 2, 3];
const arr2 = arr1;

arr2.push(4);

console.log(arr1); // [1, 2, 3, 4]
console.log(arr2); // [1, 2, 3, 4]
 -->
 Vì array1 và arr2 cùng tham chiếu đến một array trong bộ nhớ
 Giải pháp: Dùng Spread để tạo bản sao mới.
 <!-- 
const arr1 = [1, 2, 3];
const arr2 = [...arr1];

arr2.push(4);

console.log(arr1); // [1, 2, 3]
console.log(arr2); // [1, 2, 3, 4]
  -->
Lúc này arr1 và arr2 là 2 Array riêng biệt 
4.2. Copy Object bằng Spread
Spread cũng có thể sao chép object
<!-- 
const user1 = {
    name: "Martin",
    age: 27
};

const user2 = { ...user1 };

user2.age = 30;

console.log(user1); // { name: "Martin", age: 27 }
console.log(user2); // { name: "Martin", age: 30 }
 -->
user2 là 1 object mới , không cùng reference với user1
4.3.Shallow copy - Sao chép nông
Spread chỉ sao chép ở một cấp độ (shadow copy)
<!-- 
const user1 = {
    name: "Martin",
    address: {
        city: "Hanoi"
    }
};

const user2 = { ...user1 };

user2.name = "John";
user2.address.city = "Da Nang";

console.log(user1);
 -->
Tại sao user1.address.city cũng thay đổi?
Vì spread chỉ tạo Object mới ở cấp ngoài cùng . Object lồng bên nhau address vẫn dùng chung reference
((Ghi nhớ:
-Primitive values : được sao chép giá trị
-Nested Object/Array:reference vẫn được chia sẻ
-Spread không phải Deep Copy.
Bài tập nhỏ:
<!-- 
const user1 = {
    name: "Martin",
    skills: ["JavaScript", "React"]
};

const user2 = { ...user1 };

user2.name = "John";
user2.skills.push("Next.js");

console.log(user1.name);
console.log(user1.skills);
 -->
skills là Array (Object), nên 2 object vẫn tham chiếu đến cùng 1 array
Vì vậy, user1.skills cũng thay đổi.

5. Summary – Tổng kết bài học
5.1. Rest parameters
Sử dụng ... để gom các arguments còn lại thành Array.
Có thể kết hợp parameters thông thường với Rest.
Rest parameters phải nằm cuối danh sách parameters.
<!--
function sum(...numbers) {
    return numbers.reduce((total, n) => total + n, 0);
} 
 -->
5.2. Arguments
- arguments là array-like object, không phải Array.
- Có length, truy cập được bằng index.
- Không có trực tiếp các Array methods như map, filter, reduce.
- Arrow function không có arguments riêng.
5.3. Spread syntax
- Sử dụng ... để trải các phần tử của Iterable.
- Có thể truyền Array vào Function.
- Có thể kết hợp nhiều Array.
- Có thể trải String, Set và các Iterable khác.
- Array.from() còn hỗ trợ Array-like object.
5.4. Copy Array/Object
- Spread tạo bản sao mới ở cấp ngoài cùng.
- Không sao chép sâu các Object/Array lồng bên trong.
- Cần phân biệt Shallow Copy và Deep Copy.
  
Bảng ghi nhớ: Rest vs Spread
Tiêu chí	Rest	Spread
Mục đích	Gom phần tử	Trải phần tử
Vị trí thường gặp	Function parameters	Function arguments, Array, Object
Kết quả	Array	Các phần tử được trải ra
