1. Syntax
1.1. Cú pháp new Function()
Thông thường bạn tạo function bằng function Declaration
<!-- 
function sum(a, b) {
    return a + b;
}
-->
hoặc functionn expression
<!-- 
const sum = function(a, b) {
    return a + b;
};
 -->
Nhưng JavaScript còn có một cách khác:
<!-- 
const sum = new Function('a', 'b', 'return a + b');

console.log(sum(1, 2)); // 3
 -->
Cú pháp tổng quát:
<!-- let func = new Function(arg1, arg2, ..., functionBody); -->
1.2. Function không có parameters
<!-- 
const sayHi = new Function('console.log("Hello")');

sayHi(); // Hello
 -->
Ở đây:
- Không có parameters
- Nội dung functio là chuỗi 'console.log("Hello")'.
- Khi gọi sayHi() nội dung bên trong được thực thi
  
1.3. Function có parameters
<!-- 
const sum = new Function('a', 'b', 'return a + b');

console.log(sum(10, 20)); // 30
 -->
1.4. Function body dưới dạng String
<!-- const sayHi = new Function('alert("Hello")'); -->
Phần:
<!-- 'alert("Hello")' -->
1.5. Truyền parameters dưới dạng chuỗi
<!-- 
const sum = new Function('a, b', 'return a + b');

console.log(sum(5, 10)); // 15
 -->
Ghi nhớ: Các arguments ngoại trừ arguments cuối cùng đều được xem là tên parameters;argument cuối cùng là function body

2. Closure
2.1. Lexical Environment của function thông thường
<!-- 
let name = "Martin";

function sayHi() {
    console.log(name);
}

sayHi(); // Martin
 -->
Vì function được tạo tại global scope , nên có thể truy cập biến trong lexical enviroment nơi nó được khai báo
Một ví dụ khác:
<!-- 
function outer() {
    let message = "Hello";

    function inner() {
        console.log(message);
    }

    return inner;
}

const fn = outer();
fn(); // Hello
 -->
 Dù outer() chạy xog , inner() vẫn truy cập được message nhờ Closure
 2.2. Lexical Environment của new Function()

 <!-- 
 function getFunc() {
    let value = "Hello";

    const func = new Function(
        'console.log(value)'
    );

    return func;
}

const sayHi = getFunc();

sayHi();
  -->
Quá trình:
1. getFunc() tạo biến value = "Hello" trong scope của nó.
2. new Function() tạo function mới.
3. Function này không truy cập được biến value trong getFunc().
4. Khi gọi sayHi(), JavaScript tìm value nhưng không tìm thấy trong scope của function hoặc global scope.
5. Kết quả là ReferenceError.
   
2. Điểm khác biệt quan trọng
Function thông thường
<!-- 
function getFunc() {
    let value = "Hello";

    return function() {
        console.log(value);
    };
}
 -->
 Có closure 
 Function truy cập được biến value vì nó được tạo trong lexical environment của getFunc();

 Function được tạo bằng new Function()
 <!-- 
 function getFunc() {
    let value = "Hello";

    return new Function(
        'console.log(value)'
    );
}
  -->
Function k truy cập được biến value của getFunc().
3. Vậy new Function() truy cập được những gì?
Nó có thể truy cập được các biến thuôcj global scope
<!-- 
let name = "Martin";

const sayHi = new Function(
    'console.log(name)'
);

sayHi(); // Martin
 -->
 Ở đây name nằm trong global scope nên function có thể truy cập được 
Lưu ý:Global scope ở đây là global environment của JS , không phải mọi biến được khai báo bên trong 1 function bên ngoài
<!-- 
let x = 10;

function test() {
    let y = 20;

    return new Function(
        'return x + y'
    );
}

const fn = test();

console.log(fn());
 -->
2.3. Vì sao new Function() không sử dụng Closure?
Đây là thiết kế của JS 
new Function() được tạo từ chuỗi code tại thời điểm hiện tại 
2.4. Cách truyền dữ liệu vào new Function()
Nếu muốn sử dụng y ,bạn có thể truyền nó thành parameter
<!-- 
function test() {
    let y = 20;

    return new Function(
        'y',
        'return y'
    );
}

const fn = test();

console.log(fn(20)); // 20
 -->
 Ở đây y không được lấy từ closure mà được truyền trực tiếp vào function

 | Loại scope                  | `new Function()` truy cập được? |
 | --------------------------- | ------------------------------- |
 | Function scope bên ngoài    | Không                           |
 | Module scope                | Không                           |
 | Global scope (`globalThis`) | Có                              |
Ghi nhớ quan trọng: new Function() không có closre nơi nó tạo ra
