Mục 1. Symbols
1.1. Symbol là gì?
Symbol là kiểu dữ liệu nguyên thuỷ dùng để tạo ra các giá trị định danh duy nhất

const id1 = Symbol();
const id2 = Symbol();

console.log(id1 === id2); // false

1.2. So sánh Symbol với string
const key1 = "id";
const key2 = "id";

console.log(key1 === key2); // true
Với Symbol:
const key1 = Symbol("id");
const key2 = Symbol("id");

console.log(key1 === key2); // false
1.3. Symbol không tự động chuyển thành chuỗi
JavaScript không tự động chuyển Symbol thành chuỗi theo cách thông thường. Khi muốn hiển thị, bạn cần chuyển đổi tường minh bằng String(id) hoặc đọc id.description.
Bài tập thức hành:

const a = Symbol("user");
const b = Symbol("user");

console.log(a === b);
console.log(a.description === b.description);

Dòng 2: a.description === b.description → true
- a.description trả về chuỗi "user".
- b.description cũng trả về chuỗi "user".
- Hai chuỗi có cùng nội dung nên bằng nhau.

Mục 2. “Hidden” properties — Thuộc tính ẩn bằng Symbol
Trong JS symbol dùng để làm key cho 1 object để tạo thuộc tính có it nguy cơ xung đột 
2.1. Vấn đề khi dùng key dạng chuỗi
2.2. Dùng Symbol để tránh xung đột
const userId = Symbol("id");

const user = {
    name: "Martin",
    [userId]: 1
};

console.log(user[userId]); // 1
console.log(user.id);      // undefined
2.3. Vì sao gọi là thuộc tính “ẩn”?
Symbol k xuất hiện trong vong lặp for in , nên code vô tình xử lý hoặc ghi đè nó

const id1 = Symbol("id");
const id2 = Symbol("id");

const user = {
    name: "Martin",
    [id1]: 100,
    [id2]: 200
};

console.log(user[id1]);
console.log(user[id2]);

3.1. Dùng Symbol làm key khi khai báo object
Tại sao phải có dấu []?
- [id]: JavaScript lấy giá trị của biến id làm key — ở đây là một Symbol.
- id: nếu viết không có [] trong object literal, JavaScript hiểu đó là key dạng chuỗi "id".
3.2. Symbol không được chuyển thành JSON
const id = Symbol("id");

const user = {
    name: "Martin",
    [id]: 123
};

console.log(JSON.stringify(user));
// '{"name":"Martin"}'
JSON.stringify() bỏ qua thuộc tính có key làm symbol 

key     → key dạng chuỗi "key"
[key]   → key là giá trị của biến key

JSON.stringify(object)
→ bỏ qua các thuộc tính có key là Symbol

Mục 4. Symbols are skipped by for...in
4.1. for...in bỏ qua các key là Symbol

const id = Symbol("id");

const user = {
    name: "Martin",
    age: 27,
    [id]: 123
};

for (const key in user) {
    console.log(key);
}
Thuộc tính id không xuát hiện trong vòng lặp 
TUy nhiên thuộc tính đó vẫn tồn tại và truy cập được 
console.log(user[id]); // 123
4.2. Có thể lấy các Symbol bằng Object.getOwnPropertySymbols()
4.3.
| Cách duyệt                       | Key chuỗi          | Key Symbol                    |
| -------------------------------- | ------------------ | ----------------------------- |
| `for...in`                       | Có, nếu enumerable | Không                         |
| `Object.getOwnPropertySymbols()` | Không              | Có, các Symbol own properties |
| `Reflect.ownKeys()`              | Có                 | Có                            |

Bài tập tự luyện :

const key = Symbol("secret");

const obj = {
    name: "JavaScript",
    [key]: 99
};

let count = 0;

for (const prop in obj) {
    count++;
}

console.log(count);
console.log(Object.getOwnPropertySymbols(obj).length);
console.log(Reflect.ownKeys(obj).length);

for...in                         → key chuỗi enumerable
Object.getOwnPropertySymbols()   → key Symbol
Reflect.ownKeys()                → tất cả key riêng của object

Mục 5. Global symbols — Symbol.for() và Symbol.keyFor()
Ở mục trước mỗi lần gọi Symbol id sẽ tạo ra 1 symbol mới . Nhưng nếu cả 2 phần khác nhau của một ứng dụng cần symbol
, js cung cấp Symbol.for().
5.1. Symbol.for() — Tạo hoặc lấy Symbol dùng chung
const a = Symbol("id");
const b = Symbol("id");

console.log(a === b); // false

Với Symbol.for():
const a = Symbol.for("id");
const b = Symbol.for("id");

console.log(a === b); // true
Cách hoạt động:
1.Symbol.for("id") tìm trong global Symbol registry theo key "id".
5.2. Symbol.keyFor() — Tìm key của Global Symbol
Symbol.for() giúp lấy Symbol từ register
Symbol.keyFor() giúp tìm lại key đã đăng ký
Điểm dễ nhầm:
- Symbol.keyFor(symbol) trả về key đăng ký trong global registry, nếu có.
- symbol.description trả về mô tả của Symbol, bất kể Symbol đó được tạo bằng Symbol() hay Symbol.for().
  
  Bài tập tự luyện 
  const a = Symbol("role");
const b = Symbol.for("role");
const c = Symbol.for("role");

console.log(a === b);
console.log(b === c);
console.log(Symbol.keyFor(a));
console.log(Symbol.keyFor(b));

6.1. System symbols là gì?
Bạn chưa cần học sâu cách triển khai từng Symbol ngay lúc này. Chỉ cần hiểu rằng JavaScript sử dụng các key Symbol đặc biệt để cho phép object tùy chỉnh hành vi tích hợp.

Bài tập tổng hợp 
const id1 = Symbol("id");
const id2 = Symbol("id");
const id3 = Symbol.for("id");
const id4 = Symbol.for("id");

const obj = {
    name: "JavaScript",
    [id1]: 10,
    [id3]: 20
};

let count = 0;

for (const key in obj) {
    count++;
}

console.log(id1 === id2);
console.log(id3 === id4);
console.log(count);
console.log(Reflect.ownKeys(obj).length);
console.log(Symbol.keyFor(id1));

Symbol("id")
└── Tạo Symbol mới mỗi lần gọi

Symbol.for("id")
└── Tìm hoặc tạo Symbol theo key trong global registry

for...in
└── Bỏ qua key Symbol

Object.getOwnPropertySymbols(obj)
└── Lấy các key Symbol riêng của obj

Reflect.ownKeys(obj)
└── Lấy tất cả key riêng: chuỗi + Symbol

Symbol.keyFor(sym)
└── Lấy key trong global registry
    └── Không có → undefined

Bài tập :
const a = Symbol("user");
const b = Symbol("user");

console.log(a === b); false
console.log(a.description === b.description); true
console.log(typeof a); symbol

* Bài 3
const a = Symbol("role");
const b = Symbol.for("role");
const c = Symbol.for("role");

console.log(a === b);
console.log(b === c);
console.log(Symbol.keyFor(a));
console.log(Symbol.keyFor(c));

a === b → false: Symbol() tạo Symbol riêng, còn Symbol.for() sử dụng global registry.
b === c → true: cả hai cùng lấy Symbol có key "role" trong global registry.
Symbol.keyFor(a) → undefined: a không được đăng ký bằng Symbol.for().
Symbol.keyFor(c) → "role": c thuộc global registry với key "role".
