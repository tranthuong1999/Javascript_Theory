Mục 1 – Conversion rules
1.1. Object to primitive conversion là gì?
Định nghĩa: đây là quá trình JS tự chuyển một object thành một giá trị nguyên thuỷ 
khi toán tử và hàm hoặc hàm cần giá trị nguyên thuỷ
Các kiểu dữ liệu nguyên thủy gồm: number , string , boolean  ,symbol ,undefined , null
const obj = {
    value: 10
};

console.log(obj + 5);
JS chuyển obj thành primitive trước khi thực hiện phép +;
1.2. Có những loại chuyển đổi nào?
Chuyển đổi sang chuỗi hoặc chuyển sang số . Không có quy tắc nào chuyển object sang boolean
Mọi object đều là truthy kể cả object rỗng
const obj = {};

console.log(Boolean(obj)); // true
console.log(!obj);         // false
console.log(+obj);         // NaN
console.log(String(obj));  // "[object Object]"
Bài tập thực hành:
const obj = {};

console.log(Boolean(obj));
console.log(String(obj));
console.log(+obj);

Boolean({}) // true
Boolean([]) // true

+[]         // 0
+{}         // NaN

Mục 2 – Hints: JavaScript quyết định chuyển đổi kiểu như thế nào?
2.1. Ba loại hints
1. "string" – Khi cần chuỗi
2. 2. "number" – Khi cần số

const obj = {
    valueOf() {
        return 10;
    }
};

console.log(+obj);    // 10
console.log(obj - 2); // 8
console.log(obj > 5); // true
3. "default" – Khi toán tử không xác định rõ kiểu cần dùng

Mục 3 – Symbol.toPrimitive
Hành vi chuyển đổi 1 object thành primitive bằng system symbol
3.1. Cú pháp
const obj = {
    [Symbol.toPrimitive](hint) {
        // hint là "string", "number" hoặc "default"
        return /* một giá trị primitive */;
    }
};
3.2. Ví dụ theo bài gốc
const user = {
    name: "John",
    money: 1000,

    [Symbol.toPrimitive](hint) {
        if (hint === "string") {
            return `{name: "${this.name}"}`;
        }

        return this.money;
    }
};

console.log(String(user)); // '{name: "John"}'
console.log(+user);        // 1000
console.log(user + 500);   // 1500

[Symbol.toPrimitive] là một method có key là Symbol, không phải key chuỗi thông thường.
hint cho biết JavaScript đang yêu cầu chuyển đổi theo hướng nào.
Method bắt buộc trả về một giá trị primitive, không được trả về object.

Mục 4 – toString() / valueOf()
Object → primitive
├── Có Symbol.toPrimitive?
│   └── Có → gọi Symbol.toPrimitive(hint)
│
└── Không có
    ├── hint = "string"
    │   ├── Thử toString()
    │   └── Nếu không trả primitive → thử valueOf()
    │
    └── hint = "number" hoặc "default"
        ├── Thử valueOf()
        └── Nếu không trả primitive → thử toString()
4.2. Ví dụ 1 – toString() được ưu tiên

const user = {
    name: "John",

    toString() {
        return this.name;
    },

    valueOf() {
        return 100;
    }
};

console.log(String(user)); // "John"
console.log(+user);        // 100
console.log(user + 5);     // 105

String(user) dùng hint "string" → gọi toString() → "John".
+user dùng hint "number" → gọi valueOf() → 100.
user + 5 dùng hint "default" → gọi valueOf() → 100 + 5 = 105.

4.3. Ví dụ 2 – Khi valueOf() trả về object

const obj = {
    valueOf() {
        return {};
    },

    toString() {
        return "10";
    }
};

console.log(+obj); // 10
1. +obj yêu cầu hint "number".
2. JavaScript gọi valueOf(), nhưng nhận được {} — một object, không phải primitive.
3. JavaScript bỏ qua kết quả này và gọi toString().
4. toString() trả về chuỗi "10", là primitive hợp lệ.
5. Dấu + một ngôi tiếp tục chuyển chuỗi "10" thành số 10.

4.4. Điểm dễ nhầm: method mặc định
valueOf() mặc định trả về chính object đó.


const product = {
    valueOf() {
        return {};
    },

    toString() {
        return "25";
    }
};

console.log(+product);
console.log(String(product));
console.log(product + 5);

valueOf() trả về object
└── Bỏ qua kết quả
    └── Thử toString()
        ├── Trả về primitive → dùng kết quả
        └── Trả về object → thử tiếp hoặc TypeError

Mục 5 – A conversion can return any primitive type

JavaScript cần primitive
Ví dụ +obj, String(obj), obj + 5
Gọi Symbol.toPrimitive(hint)
Hoặc toString() / valueOf() nếu không có
Nhận một primitive
String, number, boolean, bigint, symbol, null hoặc undefined
Phép toán tiếp tục xử lý
Ví dụ Number("100") hoặc nối chuỗi

const obj = {
  [Symbol.toPrimitive](hint) {
    return false;
  }
};

console.log(+obj);
console.log(String(obj));
console.log(obj + 1);

Mục 6 – Further conversions.
1. Hai giai đoạn chuyển đổi
Giai đoạn 1: Chuyển object thành primitive bằng Symbol.toPrimitive, valueOf() hoặc toString().
Giai đoạn 2: Nếu phép toán yêu cầu kiểu dữ liệu khác, JavaScript tiếp tục chuyển primitive đó sang kiểu phù hợp.
const obj = {
    toString() {
        return "2";
    }
};

console.log(obj * 2); // 4
console.log(obj + 2); // "22"

Bài tập thực hành :
const obj = {
    toString() {
        return "5";
    }
};

console.log(obj - 2);
console.log(obj + 2);
console.log(obj * 2);
