Mục 1 — Constructor function
1. Constructor function là gì?
Bình thường tạo object bằng object literal:
Nhưng nếu cần tạo object có cấu trúc tương tự nhau :
Tên hàm bắt đầu bằng chữ in hoa.
Gọi hàm bằng từ khóa new.

function User(name) {
  this.name = name;
  this.isAdmin = false;
}

const user1 = new User("Martin");
const user2 = new User("John");

console.log(user1.name); // "Martin"
console.log(user2.name); // "John"
console.log(user1.isAdmin); // false
User là constructor function . Mỗi lần gọi new User() JS tạo 1 object mới

Mục 2 — Constructor mode test: new.target
new.target giúp một hàm được gọi bằng new hay được gọi như thông thường
1. new.target là gì?
function User() {
  console.log(new.target);
}

User();     // undefined
new User(); // function User() { ... }
User() — gọi hàm thông thường, new.target là undefined.
new User() — gọi bằng new, new.target là chính constructor User.
2. Dùng new.target để làm gì?
function User(name) {
  if (!new.target) {
    return new User(name);
  }

  this.name = name;
}

const user = User("Martin");

console.log(user.name); // "Martin"

Khi gọi User("Martin") mà không có new, hàm tự gọi lại bằng new User(name). Vì thế, object vẫn được tạo đúng cách.

function User(name) {
  if (!new.target) {
    return new User(name);
  }

  this.name = name;
}

const user = User("Martin");

console.log(user.name); // "Martin"

Mục 3 — Return from constructors
1. Trường hợp không có return
function User() {
  this.name = "Martin";
}

const user = new User();

console.log(user.name); // "Martin"
JavaScript tự động trả về object được tạo và gán qua this.

2. return một object
Nếu constructor trả về object khác nó sẽ thay thế object ban đầu
function User() {
  this.name = "Martin";

  return { name: "Admin" };
}

const user = new User();
console.log(user.name); // "Admin"
3. return một giá trị nguyên thủy
Nếu constructor trả về giá trị nguyên thuỷ như string , number , boolean hoặc undefined thì giá trị đó sẽ bị bỏ qua
4. Bảng ghi nhớ
| Giá trị `return`           | Kết quả của `new User()`   |
| -------------------------- | -------------------------- |
| Không có `return`          | Object được tạo qua `this` |
| `return { name: "Admin" }` | Object được trả về         |
| `return "Admin"`           | Object được tạo qua `this` |
| `return 123`               | Object được tạo qua `this` |
| `return;`                  | Object được tạo qua `this` |

function Product() {
  this.name = "Laptop";
  return { name: "Phone" };
}

const product = new Product();

console.log(product.name);

Mục 4 — Methods in constructor
Constructor không chỉ tạo thuộc tính dữ liệu mà còn tạo phương thức
1. Khai báo method bên trong constructor
function User(name) {
  this.name = name;

  this.sayHi = function () {
    console.log("My name is: " + this.name);
  };
}

const john = new User("John");
const martin = new User("Martin");

john.sayHi();   // My name is: John
martin.sayHi(); // My name is: Martin
