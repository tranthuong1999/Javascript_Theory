Mục 1 — Method examples
1.1. Object method là gì?
Khi một fucntion được lưu trong thuộc tính của object thì ta gọi nó là method
const user = {
  name: "John",

  sayHi: function () {
    console.log("Hello!");
  },
};

user.sayHi(); // Hello!
name là thuộc tính lưu dữ liệu.
sayHi là thuộc tính lưu function.
user.sayHi() gọi method sayHi của object user.
1.2. Method shorthand — Cú pháp rút gọn
1.3. OOP — Lập trình hướng đối tượng
OOP là cách chương trình tổ chức bằng các object đại điện mỗi object có dữ liệu và hành động liên quan
Ví dụ với ứng dụng quản lý người dùng:

const user = {
  name: "Martin",

  login() {
    console.log(`${this.name} logged in`);
  },
};

user.login(); // Martin logged in
Recap:
Method:
- Function được lưu trong thuộc tính của object.
- Gọi method bằng: object.method()

Cú pháp đầy đủ:
const user = {
  sayHi: function () {
    console.log("Hello");
  },
};

Cú pháp rút gọn:
const user = {
  sayHi() {
    console.log("Hello");
  },
};

OOP:
- Object có thể đại diện cho một thực thể.
- Thuộc tính lưu dữ liệu.
- Method biểu diễn hành động.
Bài tập :
const product = {
  name: "Laptop",

  showName() {
    console.log(this.name);
  },
};

product.showName();

Mục 2 — "this" in methods
this cho pheps truy cập dữ liệu của object mà nó đang thao tác
1. this là gì?
this tham chiếu đến object đứng trước dấu chấm tại thời điểm gọi method giúp nó linh hoạt hơn
let user = {
  name: "John",

  sayHi() {
    console.log(this.name);
  },
};

const admin = user;
user = null;

admin.sayHi(); // "John"

Mục 3 — this is not bound
This trong JS không bị cố định với đối tượng nơi hàm đuọc khai báo

const user = { name: "Martin" };
const admin = { name: "Admin" };

function sayHi() {
  console.log(this.name);
}

user.sayHi = sayHi;
admin.sayHi = sayHi;

user.sayHi();  // "Martin"
admin.sayHi(); // "Admin"
Bài tập 

"use strict";

const user = {
  name: "Martin",
  sayHi() {
    console.log(this.name);
  },
};

const greet = user.sayHi;
greet();
Greet chỉ nhận tham chiếu đến sayHi , không giữ user lại làm this
Khi gọi đọc lập trong 'use strict' this là undefined
truy cập this.name sẽ gây lỗi TypeError

Mục 4 — Arrow functions have no this
Arrow function không có this riêng , nó lấy giá trị từ phạm vi bên ngoài

const user = {
  firstName: "Martin",
  sayHi() {
    const arrow = () => {
      console.log(this.firstName);
    };

    arrow();
  },
};

user.sayHi(); // "Martin"
1. user.sayHi() được gọi nên this trong sayHi là user;
2. arrow là arrow function, không tạo this riêng.
3. this bên trong arrow lấy từ sayHi
4. Kết quà là "Martin"
* * 2. So sánh với function thông thường

const user = {
  firstName: "Martin",

  sayHi() {
    function normal() {
      console.log(this);
    }

    const arrow = () => {
      console.log(this.firstName);
    };

    normal();
    arrow();
  },
};

user.sayHi();
Trong strict mode:
Normal có this riêng , gọi độc lập nên this là undefined
Arrow() không có this riêng nên kế thừa this của sayHi() tức là user
Bài tập thực hành :
"use strict";

const user = {
  name: "Martin",

  sayHi() {
    const arrow = () => {
      console.log(this.name);
    };

    arrow();
  },
};

user.sayHi();
