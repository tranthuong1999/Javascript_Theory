Mục 1 — Reachability
1. Reachability là gì?
Reachability( khả năng truy cập ): là khái niệm cốt lõi để JS xác định object nào cần giữ trong bộ nhớ

Hiều đơ giản : 
Object có thể được truy cập thông qua 1 chuỗi tham chiếu thì được xem là reachable
Objct không còn reachable sẽ trở thành ứng viên GC để thu hồi bộ nhớ 
Một số root thường gặp theo bài gốc:
- Biến toàn cục (global variables).
- Biến và tham số của hàm đang thực thi.
- Biến và tham số của các hàm trên chuỗi lời gọi hiện tại.
let user = {
  name: "John",
};
Biến user đang tham chiếu đến object { name : "John"}
nếu viết tiếp : user = null;

Lưu ý: Garbage Collector tự động quản lý bộ nhớ. Việc gán null không trực tiếp xóa object ngay lập tức; nó chỉ có thể làm object không còn reachable.
Mục 1 — Reachability

- Root: điểm gốc để xác định khả năng truy cập.
- Reachable: có thể truy cập từ root thông qua tham chiếu.
- Unreachable: không còn đường tham chiếu từ root.
- Garbage Collector tự động thu hồi object unreachable.
- Gán biến = null chỉ xóa tham chiếu từ biến đó,
  không đảm bảo object bị thu hồi ngay lập tức.

  let user = {
  name: "John",
};

let admin = user;

user = null;

console.log(admin.name);

admin = user sao chép tham chiếu đến cùng object, không tạo object mới.
user = null chỉ xóa tham chiếu từ biến user.
admin vẫn tham chiếu đến object nên object còn reachable và admin.name vẫn là "John".

Mục 2 — A simple example
1. Ban đầu: object còn reachable

Mục 2 — A simple example
let user = { name: "John" };
user = null;

- Biến user không còn tham chiếu đến object John.
- Nếu không còn đường tham chiếu nào từ root đến John,
  object trở thành unreachable.
- Garbage Collector tự động thu hồi bộ nhớ khi thích hợp.
- Không thể mặc định rằng object bị xóa ngay lập tức.

Mục 3 — Two references (Hai tham chiếu)

let user = { name: "John" };
let admin = user;

user = null;

- user không còn tham chiếu đến object.
- admin vẫn tham chiếu đến object.
- Object vẫn reachable nên được giữ lại trong bộ nhớ.

Chỉ khi không còn đường tham chiếu từ root đến object,
object mới trở thành unreachable.
let user = { name: "John" };
let admin = user;

user = null;
admin = null;

console.log(user);
console.log(admin);

Mục 4 — Interlinked objects (Các object liên kết với nhau)
1. Tạo các object liên kết với nhau
Mục 4 — Interlinked objects

- Các object có thể tham chiếu qua lại với nhau.
- delete obj.property xóa một thuộc tính, không trực tiếp xóa object.
- Xóa một tham chiếu chưa chắc làm object unreachable.
- Garbage Collector quan tâm object có còn truy cập được
  từ root hay không.
- Incoming references từ cấu trúc reachable giúp object
  tiếp tục reachable.

Mục 5 — Unreachable island
Một nhóm object vẫn tham chiếu lẫn nhau nhưng cả nhóm vẫn có thể bị Garbage Collector thu hồi nếu không còn đường truy cập từ root. 
GC xet đi từ root nếu root null thì GC 
Mục 5 — Unreachable island

- Một nhóm object có thể tham chiếu lẫn nhau.
- Gán family = null sẽ loại bỏ tham chiếu từ biến family.
- Nếu không còn đường nào từ root đến nhóm object,
  toàn bộ nhóm trở thành unreachable.
- Garbage Collector có thể thu hồi cả nhóm.

Key point:
Referenced ≠ Reachable
let a = {};
let b = {};

a.other = b;
b.other = a;

a = null;
b = null;

Mục 6 — Internal algorithms
Sử dụng thuật toán Mark-and-Sweep để xác định object nào còn reachable không

let user = {
  name: "John",
};

let admin = user;

let abandoned = {
  name: "Ann",
};

user = null;
admin = null;

Phân tích sau khi chạy đoạn code:
- Object John: không còn tham chiếu từ user hoặc admin. Nếu không còn đường nào khác từ root đến object này, nó sẽ không được đánh dấu và có thể được thu hồi.
- Object Ann: biến abandoned vẫn tham chiếu đến nó, nên object vẫn reachable và được giữ lại.
- Mục 6 — Internal algorithms

Mark-and-Sweep:
1. Mark roots.
2. Đi theo tham chiếu và đánh dấu mọi object reachable.
3. Thu hồi object không được đánh dấu.

Tối ưu hóa:
- Generational: phân loại object mới và object cũ.
- Incremental: chia công việc thành các phần nhỏ.
- Idle-time: ưu tiên chạy khi CPU rảnh.

Key point:
Reachable → được giữ lại.
Unreachable → có thể được thu hồi.
