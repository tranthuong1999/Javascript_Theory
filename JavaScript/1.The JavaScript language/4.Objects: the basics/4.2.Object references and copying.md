Mục 1 — Object references
1. Primitive và object được sao chép khác nhau thế nào?
   Primitive như string , number , boolean , biến nhận bản sao giá trị độc lập 

let message = "Hello";
let phrase = message;

phrase = "Hi";

console.log(message); // "Hello"
console.log(phrase);  // "Hi"
* Với primitive: THay đổi phrase không làm thay đổi message
* Với object: khi gán object này cho biến khác , JS sao chép tham chiếu

let user = { name: "John" };
let admin = user;

admin.name = "Pete";

console.log(user.name);  // "Pete"
console.log(admin.name); // "Pete"

Mục 1 — Object references

Primitive:
- Gán biến → sao chép giá trị.
- Thay đổi biến mới không ảnh hưởng biến cũ.

Object:
- Biến lưu tham chiếu đến object.
- Gán object sang biến khác → sao chép tham chiếu.
- Hai biến có thể cùng truy cập và sửa một object.

Ví dụ:
const a = { name: "John" };
const b = a;

b.name = "Pete";

console.log(a.name); // "Pete"

Mục 2 — Comparison by reference
Hai objeyt được xem là bằng nhau khi chúng tham chiếu đến cùng 1 pbject
1. Cùng tham chiếu → bằng nhau
let a = {};
let b = a;

console.log(a == b);  // true
console.log(a === b); // true
2. Hai object riêng biệt → không bằng nhau
Mục 2 — Comparison by reference

- Cùng tham chiếu đến một object → bằng nhau.
- Hai object được tạo riêng → không bằng nhau,
  kể cả khi nội dung giống hệt nhau.

Ví dụ:
const a = {};
const b = a;
console.log(a === b); // true

const c = {};
const d = {};
console.log(c === d); // false

Bài tập :
const user1 = { name: "Martin" };
const user2 = user1;
const user3 = { name: "Martin" };

console.log(user1 === user2);
console.log(user1 === user3);

Mục 3 — Const objects can be modified.
TỪ khoá const không ngăn bản thay đổi các thuộc tính trong object nhưng nó ngăn bạn gán lại 
biến sang 1 tham chiếu khác
1. Có thể thay đổi thuộc tính của object const
const user = {
  name: "John",
};

user.name = "Pete";

console.log(user.name); // "Pete"
2. Không thể gán lại biến const
const user = {
  name: "John",
};

user = {
  name: "Pete",
}; // TypeError
Mục 3 — Const objects can be modified

const với object:
- Không thể gán lại biến sang object khác.
- Vẫn có thể thêm, sửa, xóa thuộc tính.

Ví dụ:
const user = { name: "John" };

user.name = "Pete"; // Hợp lệ
user.age = 30;      // Hợp lệ
delete user.name;   // Hợp lệ

user = {};          // TypeError

Mục 4 — Cloning and merging, Object.assign()
1. Vì sao cần clone object?

Mục 4 — Cloning and merging

1. Clone bằng for...in:
const clone = {};

for (const key in user) {
  clone[key] = user[key];
}

2. Clone bằng Object.assign:
const clone = Object.assign({}, user);

3. Gộp object:
Object.assign(target, source1, source2);

Ghi nhớ:
- Clone tạo object cấp đầu mới.
- Object.assign sửa target và trả về target.
- Key trùng nhau: source đứng sau ghi đè source đứng trước.
- Đây là shallow copy; object lồng nhau vẫn có thể dùng chung tham chiếu.

***********************************************************
Mục 5 — Nested cloning
Object.assign() chỉ sao chép nông (shallow copy) nên các object bên trong vẫn có thể dùng chung tham chiếu
1. Vấn đề với object lồng nhau
const user = {
  name: "John",
  sizes: {
    height: 182,
    width: 50,
  },
};

const clone = Object.assign({}, user);

console.log(user === clone);             // false
console.log(user.sizes === clone.sizes); // true
3. Dùng structuredClone() để deep clone
Mục 5 — Nested cloning

Shallow copy:
const clone = Object.assign({}, user);

- Object cấp đầu được sao chép.
- Object lồng nhau vẫn có thể dùng chung tham chiếu.

Deep clone:
const clone = structuredClone(user);

- Sao chép cả object lồng nhau.
- Thay đổi object lồng nhau ở bản gốc không ảnh hưởng bản clone.
- Không hỗ trợ mọi loại giá trị, ví dụ function.

***********************************************************
Mục 6 — structuredClone()
1. Cú pháp
const clone = structuredClone(original);

original: object gốc cần sao chép.
clone: object mới, có dữ liệu được sao chép từ object gốc.
Mục 6 — structuredClone()

Cú pháp:
const clone = structuredClone(original);

- Deep clone: sao chép cả object lồng nhau.
- Thay đổi object lồng nhau ở bản gốc không ảnh hưởng bản sao.
- Hỗ trợ tham chiếu vòng.
- Không hỗ trợ mọi loại giá trị; ví dụ object chứa function sẽ gây lỗi.

Phân biệt:
Object.assign({}, original) → shallow copy
structuredClone(original)   → deep clone

### 1. Tổng hợp kiến thức

| Nội dung            | Điều cần nhớ                                                                                                |
| ------------------- | ----------------------------------------------------------------------------------------------------------- |
| Object reference    | Gán `b = a` chỉ sao chép tham chiếu, không tạo object mới.                                                  |
| Comparison          | Hai biến tham chiếu cùng object thì `===` trả về `true`.                                                    |
| `const` object      | Có thể sửa thuộc tính, nhưng không thể gán lại biến.                                                        |
| `for...in`          | Có thể duyệt thuộc tính để tạo bản sao nông.                                                                |
| `Object.assign()`   | Sao chép thuộc tính vào object đích; object đích bị thay đổi.                                               |
| Shallow copy        | Object bên ngoài mới, nhưng object lồng nhau có thể vẫn dùng chung tham chiếu.                              |
| `structuredClone()` | Sao chép sâu nhiều kiểu dữ liệu, hỗ trợ tham chiếu vòng nhưng không hỗ trợ mọi giá trị, chẳng hạn function. |
