**************************************************************************************************
* 1 – Property flags
1.1. Property trong JavaScript không chỉ có key và value
<!-- 
let user = {
    name: "John"
};
 -->
Ta thường hiểu property name gồm:
key : "name"
value : "John"
Nhưng thực tế , mỗi propety còn có 3 thuộc tính cấu hình đặc biệt gọi là property flags.
1.2. Ba property flags
| Flag           | Ý nghĩa                                           |
| -------------- | ------------------------------------------------- |
| `writable`     | Có cho phép thay đổi value không?                 |
| `enumerable`   | Có xuất hiện khi duyệt property không?            |
| `configurable` | Có cho phép xóa property và thay đổi flags không? |
Propety name có cấu hình tương đương :
<!-- 
| Flag           | Ý nghĩa                                           |
| -------------- | ------------------------------------------------- |
| `writable`     | Có cho phép thay đổi value không?                 |
| `enumerable`   | Có xuất hiện khi duyệt property không?            |
| `configurable` | Có cho phép xóa property và thay đổi flags không? |
 -->
1.3. Object.getOwnPropertyDescriptor()
Đây là cú pháp lấy toàn bộ thông tin descriptor của một property.
Cú pháp:
<!-- Object.getOwnPropertyDescriptor(obj, propertyName); -->
Ví dụ trong tài liệu:
<!--

let user = {
    name: "John"
};

let descriptor = Object.getOwnPropertyDescriptor(user, "name");

console.log(descriptor);
  -->
Giải thích:
-obj: object cần kiểm tra.
-propertyName: tên property cần lấy descriptor.
-- Kết quả trả về là một object chứa value và ba flags.
1.4. Object.defineProperty()
Method này dùng để thay đổi flags hoặc tạo property với descriptor tuỳ chỉnh
Cú pháp:
<!-- Object.defineProperty(obj, propertyName, descriptor); -->
Ví dụ:
<!-- 
let user = {};

Object.defineProperty(user, "name", {
    value: "John"
});

console.log(Object.getOwnPropertyDescriptor(user, "name"));
 -->
{
    value: "John",
    writable: false,
    enumerable: false,
    configurable: false
}
Khi tạo propety mới bằng Object.defineProperty() , các flag không được khai báo mặc định sẽ là false
Khác với cách khai báo object thông thường , nơi cả ba flags mặc định là true.
Chú ý :
- writable: cho phép thay đổi giá trị
- enumerable : cho phép property xuất hiện trong quá trình liệt kê
- configurable : cho phép xoá property và thay đổi descriptor theo quy tăc của JS
- Object.getOwnPropertyDescriptor(): đọc descriptor.
- Object.defineProperty(): định nghĩa hoặc cấu hình property.

* Phần 2 – Non-writable

2.1. writable: false
Khi đặ wriaabe bằng false chúng ta không thể thay đổi giá trị của propety bằng phép gán thông thường
<!-- 
let user = {};

Object.defineProperty(user, "name", {
    value: "John",
    writable: false
});

user.name = "Martin";

console.log(user.name); // John
 -->
Giải thích : 
name ban đầu có giá trị John
writable: false khiến property không cho phép gán giá trị mới
Phép gán : "Martin" không thay đổi được giá trị 

2.2. Strict mode và non-strict mode
Non-strict mode:
<!-- 
let user = {};

Object.defineProperty(user, "name", {
    value: "John",
    writable: false
});

user.name = "Martin";

console.log(user.name); // John
 -->
 Phpép gán thất bại nhưng không báo lỗi :
 Strict mode:
 <!-- 
 "use strict";

let user = {};

Object.defineProperty(user, "name", {
    value: "John",
    writable: false
});

user.name = "Martin"; // TypeError
  -->
Phép gán thất bại và JavaScript ném TypeError.

**************************************************************************************************
* Phần 3 – Non-enumerable
3.1. enumerable: false
Khi một propety có enumerable: false , property đó sẽ không xuất hiện các thao tác liệt kê thông thường như :
for...in
Object.keys()
<!-- 
let user = {
    name: "John",
    age: 25
};

Object.defineProperty(user, "secret", {
    value: "123456",
    enumerable: false
});

console.log(Object.keys(user));
// ["name", "age"]
 -->
Giải thích:
- name và age được tạo bằng cú pháp thông thường của obj nên enumerable: true.
- secret được tạo bằng defined propety và đặt enumerable bằng false
- Vì vậy secret sẽ không xuất hiện trong Object.keys();
  Tuy nhiên propety vẫn tồn tại và truy cập bình thường
  <!-- 
  console.log(user.secret); // 123456
console.log("secret" in user); // true
   -->
3.2. for...in
secret không được liệt kê vì enumerable: false.
3.3. So sánh với Object.getOwnPropertyNames()
<!-- console.log(Object.getOwnPropertyNames(user)); -->
Method này trả về tất cả own properties dạng string , kể cả non-enumerable properties.
| Cách duyệt                     | Có lấy `secret`? |
| ------------------------------ | ---------------- |
| `Object.keys()`                | Không            |
| `for...in`                     | Không            |
| `Object.getOwnPropertyNames()` | Có               |
| `user.secret`                  | Có               |
Bài tập bổ sung : 
<!-- 
let account = {
    username: "martin"
};

Object.defineProperty(account, "password", {
    value: "abc123",
    enumerable: false
});

console.log(Object.keys(account));
console.log(account.password);
 -->

**************************************************************************************************
* Phần 4 – Non-configurable
4.1. configurable: false
Khi một property có configurable: false, chúng ta không thể:
1. Xoá property bằng delete
2. Thay đổi các flags của property
3. Thay đổi propety thành getter/setter hoặc ngược lại 


4.2. Không thể thay đổi flags
<!-- 
let user = {
    name: "John"
};

Object.defineProperty(user, "name", {
    configurable: false
});

Object.defineProperty(user, "name", {
    configurable: true
}); // TypeError
 -->
Sau khi đặt configurable: false, không thể bật lại thành true.

4.3. Ngoại lệ: writable
Nếu configurable: false và writable: true, chúng ta vẫn có thể chuyển writable từ true sang false.
<!-- 
let user = {
    name: "John"
};

Object.defineProperty(user, "name", {
    configurable: false
});

Object.defineProperty(user, "name", {
    writable: false
});

console.log(
    Object.getOwnPropertyDescriptor(user, "name")
);
 -->

* Phần 5 – Object.defineProperties
5.1. Mục đích
Object.defineProperty() để định nghĩa hoặc cấu hình một property.
Nếu muốn định nghĩa nhiều properties cùng lúc , JS cung cấp :
<!-- Object.defineProperties(obj, descriptors); -->
obj: object cần cấu hình.
descriptors: object chứa các property descriptors cần định nghĩa.
5.2. Ví dụ
<!-- 
let user = {};

Object.defineProperties(user, {
    name: {
        value: "John",
        writable: false,
        enumerable: true,
        configurable: false
    },

    age: {
        value: 25,
        writable: true,
        enumerable: true,
        configurable: true
    }
});

console.log(user.name); // John
console.log(user.age);  // 25
 -->
 Giải thích:
- name và age được định nghĩa trong cùng một lần gọi.
- Mỗi property có descriptor riêng.
- Các flags được thiết lập độc lập cho từng property.
  
Lưu ý: Những flags không được khai báo trong descriptor của property mới vẫn mặc định là false.


<!-- 
let product = {};

Object.defineProperties(product, {
    name: {
        value: "Laptop",
        enumerable: true
    },

    price: {
        value: 1500,
        writable: true
    }
});

console.log(Object.keys(product)); ['name']
console.log(product.price); 1500
 -->

Ghi nhớ: enumerable: false chỉ ảnh hưởng đến việc liệt kê property, không làm property biến mất khỏi object.

6. Object.getOwnPropertyDescriptors
Mục đích: Lấy descriptors của tất cả properties thuộc chính object đó.
1. Cú pháp
<!-- Object.getOwnPropertyDescriptors(obj); -->
2. Ví dụ
<!-- 
let user = {
    name: "John",
    age: 25
};

let descriptors = Object.getOwnPropertyDescriptors(user);

console.log(descriptors);
 -->
 Kết quả :
 <!-- 
 {
    name: {
        value: "John",
        writable: true,
        enumerable: true,
        configurable: true
    },
    age: {
        value: 25,
        writable: true,
        enumerable: true,
        configurable: true
    }
}
  -->
Mỗi property được trả về kèm theo đầy đủ descriptor của nó.

3. Ứng dụng: Clone object và giữ nguyên flags
Nếu dùng Object.assign(), các flag của propeties không được giữ nguyên . Muốn clone object giữa nguyên descriptor , có thể kết hợp 2 phương thức
<!-- 
let clone = Object.defineProperties(
    {},
    Object.getOwnPropertyDescriptors(user)
);
 -->
Luồng hoạt động:
1. Object.getOwnPropertyDescriptors(user) lấy descriptors của tất cả properties.
2. Object.defineProperties({}, descriptors) tạo object mới với các descriptors đó.
<!-- 
let user = {};

Object.defineProperty(user, "secret", {
    value: "123",
    enumerable: false
});

let descriptors = Object.getOwnPropertyDescriptors(user);

console.log(descriptors.secret);
 -->

Vì khi tạo property bằng Object.defineProperty(), các flags không được khai báo sẽ mặc định là false.

7. Sealing an object globally

Sealing an object globally
│
├── Object.preventExtensions()
├── Object.seal()
├── Object.freeze()
├── Object.isExtensible()
├── Object.isSealed()
└── Object.isFrozen()

7.1. Object.preventExtensions()
Mục đích: Ngăn không cho thêm properties mới vào object.
<!-- Object.preventExtensions(obj); -->
<!-- 
let user = {
    name: "John"
};

Object.preventExtensions(user);

user.age = 25;

console.log(user.age); // undefined
 -->
 Sau khi gọi Object.preventExtensions(user):
- Không thê thêm property mới (age).
- Vẫn có thể thay đổi property hiện có (name).
- Vẫn có thể xóa property hiện có nếu configurable: true.
Ghi nhớ: Object.preventExtensions() chỉ ngăn thêm property mới, không ngăn sửa hoặc xóa property hiện có.
7.2. Object.seal()
Mục đích: Ngăn thêm và xóa properties, đồng thời đặt configurable: false cho tất cả properties hiện có.
<!-- 
let user = {
    name: "John",
    age: 25
};

Object.seal(user);

user.name = "Martin"; // Vẫn sửa được
delete user.age;      // Không xóa được
user.email = "a@b.com"; // Không thêm được
 -->

<!-- 
let product = {
    name: "Laptop",
    price: 1500
};

Object.seal(product);

product.price = 2000;
product.stock = 10;
delete product.name;

console.log(product);
 -->
7.3. Object.freeze()
Mục đích: Ngăn thêm, xóa và thay đổi giá trị các properties hiện có.
<!-- 
let user = {
    name: "John",
    age: 25
};

Object.freeze(user);

user.name = "Martin";
user.email = "john@example.com";
delete user.age;

console.log(user);
 -->
Về bản chất, Object.freeze() đặt:
- writable: false
- configurable: false
cho tất cả own properties hiện có, đồng thời ngăn object được mở rộng.
Lưu ý quan trọng: Object.freeze() chỉ đóng băng nông (shallow freeze). Nếu property chứa một object khác, object lồng bên trong vẫn có thể thay đổi.
<!-- 
let user = {
    name: "John",
    address: {
        city: "Hanoi"
    }
};

Object.freeze(user);

user.address.city = "Da Nang";

console.log(user.address.city); // "Da Nang"
 -->

Bài tập :
<!-- 
let product = {
    name: "Laptop",
    detail: {
        color: "Black"
    }
};

Object.freeze(product);

product.name = "Phone";
product.detail.color = "White";

console.log(product.name);
console.log(product.detail.color);
 -->
 Ghi nhớ: Object.freeze() chỉ đóng băng object ở cấp độ hiện tại, không tự động đóng băng các object lồng nhau.
 7.4. Object.isExtensible()
 Mục đích: Kiểm tra object có cho phép thêm properties mới hay không.
 <!-- 
 let user = {
    name: "John"
};

console.log(Object.isExtensible(user)); // true

Object.preventExtensions(user);

console.log(Object.isExtensible(user)); // false
  -->
Kết quả:
- Object thông thường: true.
- Sau Object.preventExtensions(): false.
- Sau Object.seal() hoặc Object.freeze(): cũng là false.
  
7.5. Object.isSealed()
Mục đích: Kiểm tra object đã được sealed hay chưa.
Syntax: Object.isSealed(obj);
<!-- 
let user = {
    name: "John"
};

console.log(Object.isSealed(user)); // false

Object.seal(user);

console.log(Object.isSealed(user)); // true
 -->
Một object được xem là sealed khi:
- Không thể thêm property mới.
- Tất cả own properties đều có configurable: false.

preventExtensions()
└── Chỉ ngăn thêm property

seal()
├── Ngăn thêm property
├── Ngăn xóa property
└── configurable = false

freeze()
├── Ngăn thêm property
├── Ngăn xóa property
├── Ngăn sửa value
└── writable = false, configurable = false
