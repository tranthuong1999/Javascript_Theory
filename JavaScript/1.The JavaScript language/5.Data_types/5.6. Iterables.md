1. Symbol.iterator
1.1. Iterable là gì?
Iterable là đối tượng có khả năng cung cấp các giá trị để ta duyệt qua , chẳng hạn vong lặp for...of
1.2. Tại sao cần Symbol.iterator?
let range = {
  from: 1,
  to: 5
};
1.3. Cách triển khai Symbol.iterator
1.4. for...of hoạt động như thế nào?
1.5. Phân biệt Iterable và Iterator

let range = {
  from: 1,
  to: 3,

  [Symbol.iterator]() {
    this.current = this.from;
    return this;
  },

  next() {
    if (this.current <= this.to) {
      return { done: false, value: this.current++ };
    }

    return { done: true };
  }
};

for (let num of range) {
  console.log(num);
}
Cách hoạt động:
1.for...of gọi range[Symbol.iterator]().
2. Gán this.current = this.from rồi trả về chính range
3. for...of liên tục gọi range.next()
4. Khi current > 0 , iterator trả về { done: true } và vòng lặp dừng

1.2. Infinite iterators — Iterator vô hạn
Iterator k nhất thiết phải có điểm kết thúc
let range = {
  from: 1,
  to: Infinity,

  [Symbol.iterator]() {
    return {
      current: this.from,
      last: this.to,

      next() {
        return { done: false, value: this.current++ };
      }
    };
  }
};

for (let num of range) {
  if (num > 5) break;
  console.log(num);
}

3. Calling an iterator explicitly
for...of tự gọi Symbol.iterator() và next();
let str = "Hello";

// Lấy iterator của string
let iterator = str[Symbol.iterator]();

while (true) {
  let result = iterator.next();

  if (result.done) break;

  console.log(result.value);
}

4. Iterables and array-likes
JS có 2 khái niệm dễ nhầm là iterable và array like . Một object có thể thuộc 1 loại hoặc đôngf thời thuộc 2 loại 
4.1. Iterable là gì?
Interable là object có phương thức Symbol.interator , cung cấp interator để duyệt các giá trị 
let str = "Hello";

for (let char of str) {
  console.log(char);
}
4.2. Array-like là gì?
Array like là object có:
Thuộc tính length biểu thị số lượng phần tử 
Các thuộc tính dạng key như 0 ,1,2...
let arrayLike = {
  0: "Hello",
  1: "World",
  length: 2
};

console.log(arrayLike.length); // 2
console.log(arrayLike[0]);     // "Hello"
Object này có hình dạng giống mảng nhưng không phải mảng và không tự động có các phương thức như map() và filter();
4.3. Phân biệt iterable và array-like
| Tiêu chí            | Iterable             | Array-like                 |
| ------------------- | -------------------- | -------------------------- |
| Dấu hiệu            | Có `Symbol.iterator` | Có `length` và key dạng số |
| Dùng với `for...of` | Có                   | Không nhất thiết           |
| Có `length`         | Không bắt buộc       | Có                         |
| Có phải mảng thật?  | Không nhất thiết     | Không nhất thiết           |
Bài tập :
let obj = {
  0: "A",
  1: "B",
  length: 2
};
Iterable: không vì object chưa có Symbol.iterator
Array-like: có vì có length : 2 và các key dạng số 0, 1
5. Array.from
Array.from() dùng để tạo mảng thật từ iterable hoặc array like
Ví dụ 1.  chuyển array like thành mảng 
let obj = {
  0: "A",
  1: "B",
  length: 2
};

let arr = Array.from(obj);

console.log(arr); // ["A", "B"]
sau chuyển đổi arr là mảng thật nên có thể dùng map , filter và các phương thức mảng khác
Ví dụ 2 — chuyển iterable thành mảng:
let str = "Hello";
let arr = Array.from(str);

console.log(arr); // ["H", "e", "l", "l", "o"]

let obj = {
  0: 10,
  1: 20,
  2: 30,
  length: 3
};

let arr = Array.from(obj);

console.log(arr);
console.log(arr.map(num => num / 10));


5.2. Sử dụng mapFn và thisArg
Array.from() còn nhận các tham số tuỳ ý

Array.from(arrayLike, mapFn, thisArg);
arrayLike: iterable hoặc array like cần chuyển đổi 
mapFn : hàm được gọi tưng phần tử trong quá trình tạo mảng
thisArg : giá trị this được dùng bên trong mapFn nếu cần
let range = {
  0: 2,
  1: 4,
  2: 6,
  length: 3
};

let arr = Array.from(range, num => num * 2);

console.log(arr); // [4, 8, 12]
