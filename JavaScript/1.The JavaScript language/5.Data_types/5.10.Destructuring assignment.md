1. Array destructuring
1.1. Cú pháp cơ bản
Destructuring là cú pháp giúp lấy dữ liệu từ array hoặc object và gán vào các biến 1 cách ngắn gọn 
Giả sử có array:

<!-- 
const user = ["An", "Nguyen"]; 
-->
Nếu k dùng Destructuring ta viết 
const firstName = user[0];
const lastName = user[1];
<!-- 
Sử dụng Destructuring: 
const [firstName, lastName] = user;

console.log(firstName); // "An"
console.log(lastName);  // "Nguyen"
 -->
 const [a, b] = array tương đương với việc array[0] gán cho a , array[1] gán cho b
 Destructuring không làm hay đổi array gốc . Nó chỉ lấy giá trị ârray và gán cho biến

 Nó thường dùng với phương thức trả về array chẳng hạn split():

 <!-- 
const [firstName, lastName] = "An Nguyen".split(" ");
console.log(firstName); // "An"
console.log(lastName);  // "Nguyen"
  -->
Bài tập nhỏ :

<!-- 
const numbers = [10, 20, 30];
const [a, b] = numbers;

console.log(a);
console.log(b);
 -->

1.2. Bỏ qua phần tử bằng dấu phẩy
<!-- 
const numbers = [10, 20, 30];

const [a, , c] = numbers;

console.log(a); // 10
console.log(c); // 30
 -->
 Bài tập thực hành 
 <!-- 
 const fruits = ["Apple", "Orange", "Banana", "Mango"];

const [, second, , fourth] = fruits;

console.log(second);
console.log(fourth);
  -->
1.3. Hoạt động với mọi iterable
Iterable là đối tượng mà JS có thể duyệt qua các phần tử > Ví dụ : Array , String , Set và Map
Array destructuring k chỉ được dùng với array mà còn có thể lấy dữ liệu từ các iterable khác
<!-- 
const [a, b, c] = "Cat";

console.log(a); // "C"
console.log(b); // "a"
console.log(c); // "t"
 -->

 <!--
 const set = new Set([10, 20, 30]);

const [a, b] = set;

console.log(a); // 10
console.log(b); // 20
   -->
 (( Destructuring không bắt buộc dữ liệu bên phải là array . Điều kiện quan trong nó pahir là iterable
1.4. Gán vào bất kỳ vị trí có thể gán nào
Destructuring k nhất thiết phải gán vào biến mới . Bạn có thể gán vào những giá trị đã tồn tại và có thể nhận giá trị

<!-- 
let a, b;

[a, b] = [10, 20];

console.log(a); // 10
console.log(b); // 20
 -->
 hoặc cũng có thể gán cho object
 <!-- 
 const user = {};

[user.name, user.age] = ["An", 25];

console.log(user); // { name: "An", age: 25 }
  -->

  const user = {
    name: "An",
    age: 25
};

for (const [key, value] of Object.entries(user)) {
    console.log(key, value);
}
Object.entries(user) tạo ra các cặp [key, value] . Vòng lặp lấy từng cặp rồi destructuring thành 2 biến key và value

1.5. Duyệt Object.entries() và Map
Với Object

<!-- 
const user = {
    name: "An",
    age: 25
};

for (const [key, value] of Object.entries(user)) {
    console.log(key, value);
}

[
    ["name", "An"],
    ["age", 25]
]
 -->
 Với Map

<!-- 
const map = new Map([
    ["name", "An"],
    ["age", 25]
]);

for (const [key, value] of map) {
    console.log(key, value);
}
name An
age 25
 -->
 Phân biêt: Object.entries(obj) chuyển các thuộc tính thông thường của Object thành mảng các cặp
 Map : bản thân nó là interable gồm các cặp [key, value];

 1.6. Hoán đổi biến
 Với destructuring, JavaScript cho phép hoán đổi trực tiếp:

 <!-- 
let a = 1;
let b = 2;

[a, b] = [b, a];

console.log(a, b); // 2 1
  -->
1.7. Rest pattern (...)
Rest pattern cho phép thu thập các phần tử còn lại của 1 array
<!-- 
const numbers = [10, 20, 30, 40, 50];

const [first, second, ...rest] = numbers;

console.log(first);  // 10
console.log(second); // 20
console.log(rest);   // [30, 40, 50]
 -->
 Lưu ý quan trọng:
-Rest pattern phải nằm cuối trong danh sách destructuring
- Biến rest nhận 1 array kể cả chỉ có 1 phần tử 
- ...rest trong destructuring thu thập các phần tử còn lại ,còn spread syntax dùng để trải các phần tử ra
<!-- 
const fruits = ["Apple", "Orange", "Banana", "Mango"];

const [first, ...others] = fruits;

console.log(first);
console.log(others);
 -->
 1.8. Giá trị mặc định
 Khi destructuring, nếu không có phần tử tương ứng biến sẽ nhận underfined . Bạn cũng có thể cung cấp giá trị mặc định
 <!--
 const [name = "Guest", age = 18] = ["An"];

console.log(name); // "An"
console.log(age);  // 18
   -->
Điểm cần nhớ : gía trị mặc định được sử dụng khi giá trị là undèined, không phải là gía trị null , o , false ay rỗng
<!-- 
const [a = 10, b = 20, c = 30] = [undefined, null, 0];

console.log(a); // 10
console.log(b); // null
console.log(c); // 0
 -->

2. Object destructuring
2.1. Cú pháp cơ bản
<!-- 
const user = {
    name: "An",
    age: 25
};
 -->
 const { name, age } = user;
Điểm khác biệt quan trọng : 
Array detrucutring dựa vào vị trí của phần tử
Object destructuring dựa vào thuộc tính
2.2. Thứ tự thuộc tính không quan trọng
Đây là điểm khác biệt chính giữa array và object
Array lấy theo vị trí
Với object lấy theo tên thuộc tính
2.3. Đổi tên biến bằng dấu :
Đôi khi bạn muốn lấy tên thuộc tính nhưung đặt tên khác . JS cho phép dùng dấu : để đổi tên biến khi destructuring
<!-- 
const user = {
    name: "An",
    age: 25
};

const { name: userName, age: userAge } = user;

console.log(userName); // "An"
console.log(userAge);  // 25
 -->
 Bài tập thực hành:
 <!-- 
 const employee = {
    name: "Minh",
    salary: 1500
};

const { name: employeeName, salary: monthlySalary } = employee;

console.log(employeeName);
console.log(monthlySalary);
  -->
2.4. Giá trị mặc định
Object destructuring cũng hỗ trợ mặc định khi thuộc tính k tồn tại hoặc có giá trị là undefined
<!-- 
const user = {
    name: "An"
};

const { name, age = 18 } = user;

console.log(name); // "An"
console.log(age);  // 18
 -->
Object user không có thuộc tính age , nên biến age nhận giá trị mặc định là 18
<!-- 

const product = {
    name: "Mouse",
    price: undefined,
    quantity: null
};

const {
    name,
    price = 100,
    quantity = 1,
    stock = 10
} = product;

console.log(name);
console.log(price);
console.log(quantity);
console.log(stock);
 -->
 2.5. Kết hợp đổi tên và giá trị mặc định
 Bạn có thể kết hợp : và = trong cùng 1 phép destructuring
  <!--
  const user = {
    name: "An"
};

const { name: userName = "Guest", age: userAge = 18 } = user;

console.log(userName); // "An"
console.log(userAge);  // 18
-->
Cách đọc : 
name: userName = "Guest": lấy thuộc tính name, gán vào userName nếu giá trị là undefined , dùng guest
age: userAge = 18: lấy thuộc tính age, gán vào userAge; nếu giá trị là undefined dung 18
<!-- 
const account = {
    username: undefined,
    role: "admin"
};

const {
    username: displayName = "Guest",
    role: userRole = "user"
} = account;

console.log(displayName);
console.log(userRole);
 -->
 2.6. Chỉ lấy thuộc tính cần thiết
 Object destructuring cho phép lấy các thuộc tính cần thiét , không cần khai báo tất cả các thuộc tính của object
 <!-- 
 const user = {
    name: "An",
    age: 25,
    city: "Hanoi"
};

const { name } = user;

console.log(name); // "An"
  -->
2.7. Rest pattern (...)
Trong Object destructuring, rest pattern giúp lấy các thuộc tính còn lại vào 1 object mới

<!-- 
const user = {
    name: "An",
    age: 25,
    city: "Hanoi"
};

const { name, ...rest } = user;

console.log(name); // "An"
console.log(rest); // { age: 25, city: "Hanoi" }
 -->
 | Cú pháp                      | Kiểu dữ liệu nhận được |
 | ---------------------------- | ---------------------- |
 | `const [a, ...rest] = arr`   | `rest` là Array        |
 | `const { a, ...rest } = obj` | `rest` là Object       |

2.8. Trường hợp không có let
Khi destructuring object,, nếu bạn muốn gán vào các biến đã khai báo , cần chú ý cú pháp
<!-- 
let name, age;

({ name, age } = { name: "An", age: 25 });

console.log(name); // "An"
console.log(age);  // 25
 -->

3. Nested destructuring
Nested destructuring là destructuring dữ liệu lồng nhau khi 1 object chứa 1 object khác hạowc array chứa 1. array khác
<!-- 
const user = {
    name: "An",
    address: {
        city: "Hanoi",
        district: "Cau Giay"
    }
};
 -->
 const {
    address,
    address: { city }
} = user;

console.log(address); // { city: "Hanoi", district: "Cau Giay" }
console.log(city);    // "Hanoi"

Nested destructuring với Array
<!-- 
const numbers = [1, [2, 3]];

const [first, [second, third]] = numbers;

console.log(first);  // 1
console.log(second); // 2
console.log(third);  // 3
 -->

4. Smart function parameters
Giải thích cách dùng destructuring để viết tham số dễ đọc hơn f hàm linh hoạt hơn
4.1. Vấn đề khi có nhiều tham số
Giả sử hàm nhiều thông tin ngươid dùng cần nhiều tham số
<!-- 
function showUser(name, age, city, role) {
    console.log(name, age, city, role);
}

showUser("An", 25, "Hanoi", "admin");
 -->
 Một cách khác là truyền một object:
 <!-- 
 function showUser(user) {
    console.log(user.name, user.age, user.city, user.role);
}

showUser({
    name: "An",
    age: 25,
    city: "Hanoi",
    role: "admin"
});
  -->
4.2. Destructuring tham số object
<!-- 
// Không destructuring
function createProduct(product) {
    console.log(product.name);
}

// Có destructuring
function createProduct({ name }) {
    console.log(name);
}
 -->
4.3. Kết hợp đổi tên, giá trị mặc định và destructuring lồng nhau
<!--
function showUser({
    name: userName = "Guest",
    address: { city } = {}
}) {
    console.log(userName);
    console.log(city);
}

showUser({
    name: "Minh",
    address: { city: "Hanoi" }
});
  -->
Lưu ý: giá trị mặc định chỉ áp dụng khi gía trị là undefined không áp dụng cho null
4.4. Giá trị mặc định cho toàn bộ object tham số
<!-- 
function showUser({ name = "Guest", age = 18 } = {}) {
    console.log(name);
    console.log(age);
}
 -->

 <!-- 
 function createProduct({ name = "Unknown", price = 0 } = {}) {
    console.log(name);
    console.log(price);
}

createProduct();
  -->

5.1. Phân biệt những cú pháp dễ nhầm
| Cú pháp                      | Ý nghĩa                              |
| ---------------------------- | ------------------------------------ |
| `const [a, b] = arr`         | Lấy phần tử theo vị trí              |
| `const { a, b } = obj`       | Lấy thuộc tính theo tên              |
| `const { a: x } = obj`       | Lấy thuộc tính `a`, tạo biến `x`     |
| `const [a, ...rest] = arr`   | `rest` là Array                      |
| `const { a, ...rest } = obj` | `rest` là Object                     |
| `const { a = 10 } = obj`     | Dùng `10` khi `a` là `undefined`     |
| `function f({ a } = {}) {}`  | Có thể gọi `f()` không truyền đối số |
