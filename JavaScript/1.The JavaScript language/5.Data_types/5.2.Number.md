Mục 1. More ways to write a number
1. Viết số lớn dễ đọc với _
const billion = 1_000_000_000;
console.log(billion); // 1000000000
Dấu _ chỉ giúp con người dễ đọc số hơn. JavaScript bỏ qua dấu này khi xử lý giá trị.
2. Ký hiệu e — viết số bằng lũy thừa của 10
console.log(1e3);  // 1000
console.log(1e6);  // 1000000
console.log(1e9);  // 1000000000
console.log(7.3e9); // 7300000000
1e3 nghĩa là \(1 \times 10^3\).
7.3e9 nghĩa là \(7.3 \times 10^9\).
Với số mũ âm, ta chia cho lũy thừa của 10:
console.log(1e-3);   // 0.001
console.log(1e-6);   // 0.000001
console.log(1.23e-6); // 0.00000123
3. Hệ thập lục phân, nhị phân và bát phân
JavaScript hỗ trợ viết số trực tiếp ở ba hệ phổ biến ngoài hệ thập phân.

| Hệ số                       | Tiền tố | Ví dụ        | Giá trị thập phân |
| --------------------------- | ------- | ------------ | ----------------- |
| Thập lục phân (Hexadecimal) | `0x`    | `0xff`       | 255               |
| Nhị phân (Binary)           | `0b`    | `0b11111111` | 255               |
| Bát phân (Octal)            | `0o`    | `0o377`      | 255               |

Mục 2. toString(base) — Chuyển số thành chuỗi theo hệ đếm
Method number.toString(base) chuyển số thành 1 chuỗi biểu diễn theo hệ số đếm
1. Cú pháp
number.toString(base)
number: số cần chuyển đổi.
base: hệ đếm muốn sử dụng, thường từ 2 đến 36.
Kết quả trả về là string, không phải number.
const num = 255;
console.log(num.toString());   // "255"
console.log(num.toString(10)); // "255"
console.log(num.toString(16)); // "ff"
console.log(num.toString(2));  // "11111111"
Nếu bỏ qua base, JavaScript mặc định sử dụng hệ thập phân (10).

Mục 3. Rounding — Làm tròn số
1. Bốn hàm làm tròn cơ bản
| Hàm             | Quy tắc                                           | Ví dụ                   |
| --------------- | ------------------------------------------------- | ----------------------- |
| `Math.floor(x)` | Làm tròn xuống về số nguyên nhỏ hơn hoặc bằng `x` | `Math.floor(3.8)` → `3` |
| `Math.ceil(x)`  | Làm tròn lên về số nguyên lớn hơn hoặc bằng `x`   | `Math.ceil(3.2)` → `4`  |
| `Math.round(x)` | Làm tròn đến số nguyên gần nhất                   | `Math.round(3.5)` → `4` |
| `Math.trunc(x)` | Bỏ phần thập phân, giữ phần nguyên                | `Math.trunc(3.8)` → `3` |
2. Phân biệt bằng số âm
console.log(Math.floor(-3.2)); // -4
console.log(Math.ceil(-3.2));  // -3
console.log(Math.round(-3.2)); // -3
console.log(Math.trunc(-3.2)); // -3

floor đi về phía âm vô cùng, nên -3.2 thành -4.
ceil đi về phía dương vô cùng, nên -3.2 thành -3.
trunc cắt phần thập phân, không quan tâm dấu.
round chọn số nguyên gần nhất; khi cách đều hai số nguyên, JavaScript làm tròn về phía \(+\infty\). Vì
3. toFixed(digits) — Làm tròn và định dạng số thập phân

Mục 4. Imprecise calculations — Tính toán số thực không chính xác tuyệt đối
1. Vì sao phép tính có thể cho kết quả lạ?
Bạn có thể gặp trường hợp:
console.log(0.1 + 0.2); // 0.30000000000000004

Nguyên nhân : JS sử dụng kiểu number để biểu diễn số thực bằng hệ nhị phân 
2. Một ví dụ dễ hiểu
console.log(0.1 + 0.2 === 0.3); // false
3. Cách xử lý sai số
const result = 0.1 + 0.2;

console.log(Math.abs(result - 0.3) < 1e-10); // true
4. Giá trị 0 và -0
JavaScript có cả 0 và -0:
console.log(0 === -0);          // true
console.log(Object.is(0, -0));  // false
console.log(1 / 0);             // Infinity
console.log(1 / -0);            // -Infinity

Object.is(value1, value2)
├── Không ép kiểu
├── NaN với NaN       → true
├── 0 với -0          → false
└── Các trường hợp thông thường
    └── Tương tự ===
Vì vậy, với object và array, Object.is() kiểm tra xem hai giá trị có tham chiếu đến cùng một object hay không, chứ không so sánh sâu nội dung bên trong.
Object.is(value1, value2);
CHú ý : Nan k bằng giá trị nào ngay cả khi so sánh với chính nó
Để biết nó là Nan : Number.Nan()

Mục 5. isFinite() và isNaN() — Kiểm tra giá trị số
Giúp kiêm tra 1 giá trị có hợp lệ để tính toán hay không
1. NaN là gì?
NaN biểu thị kết quả của phép tính toán không hợp lệ 
console.log("hello" / 2); // NaN
console.log("abc" * 3);   // NaN
console.log(typeof NaN);  // "number"
2. isNaN() và Number.isNaN()
isNaN(value) chuyển value sang số trước khi kiểm tra nếu kết quả NaN trả về true
Number.isNaN(value) : chỉ trả về true khi giá trị thực sư là NaN
3. isFinite() và Number.isFinite()
   Dùng để kiểm tra 1 số có phải hưu hạn không
Infinity, -Infinity và NaN không phải là các số hữu hạn.
console.log(isFinite(100));          // true
console.log(isFinite(Infinity));     // false
console.log(isFinite(-Infinity));    // false
console.log(isFinite(NaN));          // false

isFinite() tự động ép kiểu trước khi kiểm tra.
Number.isFinite() không tự động ép kiểu. Giá trị truyền vào phải có kiểu number và phải là số hữu hạn.

isFinite(value)
├── Có ép kiểu
├── isFinite("100")  → true
├── isFinite(null)   → true
└── isFinite(Infinity) → false

Number.isFinite(value)
├── Không ép kiểu
├── Number.isFinite(100)   → true
├── Number.isFinite("100") → false
└── Number.isFinite(NaN)   → false

Mục 6: parseInt() và parseFloat()
Cách lấy số từ chuỗi và phân biệt chúng với NUmber();
1. parseInt() — lấy số nguyên
parseInt("100px"); // 100
parseInt("12.8");  // 12
parseInt("abc123"); // NaN
Đọc từ đầu chuỗi sau khi bỏ khoảng trắng.
Dừng khi gặp ký tự không hợp lệ 
Nếu không đọc được số ngya từ đầu , kết quả là NaN
2. parseFloat() — lấy số thực
parseFloat("12.8px"); // 12.8
parseFloat("3.14");   // 3.14
parseFloat("abc3.14"); // NaN
CHú ý : Number() yêu cầu toàn bộ chuỗi biểu diễn được 1 số hợp lệ , parseInt() và parseFloat()
có thể đọc phần số ở đầu chuỗi rồi dừng
Number(str)
└── Yêu cầu toàn bộ chuỗi hợp lệ

parseInt(str, radix)
└── Đọc số nguyên ở đầu chuỗi

parseFloat(str)
└── Đọc số thực ở đầu chuỗi
