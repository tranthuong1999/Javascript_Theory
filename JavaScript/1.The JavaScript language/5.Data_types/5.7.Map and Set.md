1. Map
1.1. Map là gì?
Map là cấu trúc dữ liệu lưu thông tin dưới dạng key value tương tự như object
let user = new Map();

user.set("name", "Martin");
user.set("age", 27);

console.log(user.get("name")); // "Martin"
console.log(user.get("age"));  // 27
1.2. Điểm khác biệt quan trọng giữa Map và Object
Map cho phép key thuộc bất kỳ kiểu dữ liệu nào còn key của object thông thường là string hoặc symbol
Map còn cho phép object làm key
1.2. Các phương thức và thuộc tính của Map

| Phương thức / thuộc tính | Công dụng                                           |
| ------------------------ | --------------------------------------------------- |
| `set(key, value)`        | Thêm hoặc cập nhật                                  |
| `get(key)`               | Lấy value; key không tồn tại thì trả về `undefined` |
| `has(key)`               | Kiểm tra key tồn tại                                |
| `delete(key)`            | Xóa phần tử theo key                                |
| `clear()`                | Xóa tất cả phần tử                                  |
| `size`                   | Số phần tử hiện có                                  |

1.3. Map và Object khác nhau thế nào?
Map cho phép key thuộc mọi kiểu dữ liệu , Object thông thường dùng string hoặc symbol làm key
Map có thuộc tính size để lấy số phần tử
Map giữ thứ tự các phần tử theo thứ tự thêm vào khi duyệt 
Map được thiết kế riêng cho việc lưu các cặp key và value

Map duyệt theo thứ tụ các key được thêm vào . Nếu cập nhật value của key đã tồn tại , key đó k tự chuyển xuống dưới
1.4. Dùng object làm key trong Map
Map cho phép dùng object làm key . Nhưng có 1 điểm rất dễ nhầm : 2 object có cùng nội dung vẫn là 2 key khác nhau
nếu chúng là 2 object riêng biệt
let map = new Map();

map.set({ name: "An" }, 100);

console.log(map.get({ name: "An" })); // undefined
Tại sao là undefined bởi vì 2 lần viết {name :"An"} tạo ra 2 object khác nhau trong bộ nhớ. Muốn lấy được value ta phải dùng 
đungs object đã dùng làm key
let map = new Map();

let a = { id: 1 };
let b = { id: 1 };

map.set(a, "Hello");

console.log(map.get(a));
console.log(map.get(b));
console.log(map.size);

1.5. Map so sánh key như thế nào?
Map sử dụng quy tắc so sánh tương đương SameValueZero
Những case cần nhớ :
1 và "1" là 2 key khác nhau 
Nan được xem bằng NaN khi làm key trong map
Với object 2 key được xem là giống nhau khi chúng tham chiếu đến object
let map = new Map();

map.set(NaN, "first");
map.set(NaN, "second");

console.log(map.size); // 1
console.log(map.get(NaN)); // "second"
Bài tập 5 :
let map = new Map();

map.set(NaN, "A");
map.set(NaN, "B");
map.set(1, "C");
map.set("1", "D");

console.log(map.size);
console.log(map.get(NaN));
console.log(map.get(1));
console.log(map.get("1"));

1.6. Chaining — Gọi nối tiếp map.set()
Trong JS , map.set(key, value) trả về chính Map đó nên bạn có thể gọi nhiều lần liên tiếp

2. Iteration over Map — Duyệt Map
2.1. map.keys()
map.keys() trả về một iterable chứa các key của Map , theo thứ tự chúng được thêm vào 

const map = new Map([
  ["name", "Martin"],
  ["age", 27],
  ["job", "Developer"]
]);

console.log([...map.keys()]);
// ["name", "age", "job"]
Lưu ý: map.keys() không trực tiếp trả về một array.
2.2. map.values()
map.values() trả về 1 interator chứa các value của Map theo thứ tự các phần tử được thêm vào
const map = new Map([
  ["name", "Martin"],
  ["age", 27],
  ["job", "Developer"]
]);

console.log([...map.values()]);
// ["Martin", 27, "Developer"]

| Phương thức     | Trả về                 |
| --------------- | ---------------------- |
| `map.keys()`    | Các key                |
| `map.values()`  | Các value              |
| `map.entries()` | Các cặp `[key, value]` |
2.3. map.entries()
map.entries() trả về 1 interator chứa các cặp [key, value] theo thứ tự các phần tử được thêm vào


2.4. Duyệt Map bằng for...of
Map có thể duyệt trực tiếp bằng for of . Mỗi lần lặp ta nhận được cặp key-value

const map = new Map([
  ["name", "Martin"],
  ["age", 27]
]);

for (const [key, value] of map) {
  console.log(key, value);
}

2.5. Thứ tự phần tử được thêm vào
Map giuwx thứ tự các key được thêm vào

Cập nhật value không làm key chuyển xuống cuối map )))

const map = new Map([
  ["A", 1],
  ["B", 2],
  ["C", 3]
]);

map.set("A", 100); // Cập nhật key đã tồn tại
map.set("D", 4);   // Thêm key mới

console.log([...map.keys()]);
2.6. map.forEach()
Map có phương thức for each để thực hiện 1 callback cho các key và value

Object.entries — Tạo Map từ Object
3.1. Khởi tạo Map từ các cặp [key, value]
Map có thể khơi tạo từ 1 interable chứa các cặp [ key , value];
3.2. Object.entries(obj)
Object.entries(obj) trả về một mảng gồm các cặp [key , value] của các thuộc tính riêng , có thể liệt kê object
const obj = {
  name: "Martin",
  age: 27
};

console.log(Object.entries(obj));
[
  ["name", "Martin"],
  ["age", 27]
]
Điểm cần nhớ:
Object.entries(obj) chuyển object thành mảng các cặp [key , value]
new Map() nhận các cặp đó để tạo map
Key lấy từ object là chuỗi hoặc symbol 

3.3. Chuyển Object thành Map — Tổng kết
Object → Object.entries() → mảng các cặp [key, value] → new Map() → Map.

**************************************************************
1. Object.fromEntries — Tạo Object từ Map
4.1. Object.fromEntries(entries)
Object.fromEntries() thực hiện 2 chiều ngược lại : nhận một iterable chứa các cặp [key , value] 
const entries = [
  ["name", "An"],
  ["age", 25]
];

const obj = Object.fromEntries(entries);

console.log(obj);
// { name: "An", age: 25 }
Nếu dữ liệu đang ở dạng map ta có thể chuyển thanhf Object.fromEntries(map).
4.2. Chuyển Map thành Object
Vì Map là iterable gồm các cặp [key, value] ta có thể truyền trục tiếp vào map
const map = new Map([
  ["name", "An"],
  ["age", 25]
]);

const obj = Object.fromEntries(map);

console.log(obj);
// { name: "An", age: 25 }
const obj = {
  name: "An",
  age: 25
};

// Object → Map
const map = new Map(Object.entries(obj));

// Map → Object
const objAgain = Object.fromEntries(map);

console.log(objAgain);
// { name: "An", age: 25 }

<!-- 
const obj = {
  name: "An",
  age: 25
};

// Object → Map
const map = new Map(Object.entries(obj));

// Map → Object
const objAgain = Object.fromEntries(map);

console.log(objAgain);
// { name: "An", age: 25 }
 -->

Ghi nhớ:
- Object.entries(obj) → mảng các cặp [key, value].
- new Map(entries) → tạo Map từ các cặp.
- Object.fromEntries(entries) → tạo Object từ các cặp.

5. Set
5.1. Set là gì?
Set là 1 cấud trúc dữ liệu để lưu các giá trị duy nhất , không cho phép các giá trị cùng nhau
const set = new Set();

set.add("Apple");
set.add("Orange");
set.add("Apple");

console.log(set.size); // 2
console.log([...set]); // ["Apple", "Orange"]
5.2. Các phương thức và thuộc tính
| Phương thức / thuộc tính | Tác dụng                                |
| ------------------------ | --------------------------------------- |
| `new Set()`              | Tạo Set rỗng                            |
| `new Set(iterable)`      | Tạo Set từ iterable                     |
| `set.add(value)`         | Thêm giá trị                            |
| `set.delete(value)`      | Xóa giá trị, trả về `true` nếu xóa được |
| `set.has(value)`         | Kiểm tra giá trị có tồn tại             |
| `set.clear()`            | Xóa toàn bộ giá trị                     |
| `set.size`               | Số lượng giá trị duy nhất               |

<!-- 
const set = new Set();

 5.3. Set chỉ lưu giá trị duy nhất
 Set lưu các giá trị trùng lặp theo quy tăc tương tự map 
 Ví dụ :
 <!-- 
 const set = new Set();
set.add(NaN);
set.add(NaN);
console.log(set.size); // 1
  -->
Mặc dù NAN ===  NAN được coi là false , Set vẫn coi NAN là 1 giá trị trùng nhau
Chú ý với object : Set so sánh ôbject theo tham chiếu , không so sánh giá trị bên trong
<!-- 
const set = new Set();

set.add({ id: 1 });

console.log(set.size); // 2
Set có đúng 3 giá trị duy nhất 
 -->
 5.4. Sử dụng Set để loại bỏ phần tử trùng lặp
 Đây là 1 ứng dụng phổ biến của set , chuyển array thành set sau đó loại bỏ các giá trị trùng nhau sau đó lại chuyển thành array
 <!--

Cách hoạt động :
1. new Set(numbers): tạo set chỉ giữ các giá trị duy nhất

3. Thứ tứ xuất hiện đầu tiên được giữ lại

6. Iteration over Set — Duyệt Set
Set duy trì thêm các giá trị mới . Nếu thêm 1 giá trị đã tồn tại , Set không thêm bản sao và khôg thay đổi vị trí giá trị đó
<!--
const set = new Set([10, 20, 10, 30]);

set.delete(20);
set.add(10);
set.add(40);

for (const value of set) {
  console.log(value);
}
  -->

6.1. Duyệt Set bằng for...of
 Tương tụ như Map , Set có thể duyệt bằng for of . Mỗi lần lặp ta nhận đượuc 1 gía trị set
 <!--
 const set = new Set(["apple", "banana", "orange"]);

for (const value of set) {
  console.log(value);
}
   -->
6.2. Duyệt Set bằng forEach()
Set cũng có phơng thức forEach() để thực hiện callback cho từng giá trị 
<!--
const set = new Set(["a", "b", "c"]);

set.forEach((value) => {
  console.log(value);
});
  -->
6.3. Vì sao callback của Set.forEach() nhận (value, valueAgain, set)?
Với set callback có thể nhận 3 tham số:
<!-- 
set.forEach((value, valueAgain, set) => {
  // ...
});
 -->
 Thông thường tham số thứ 2 của foreach là index nhưng Set không có index , nên tham số thứ 2 của callback set được đặt bằng giá trị đầu tiên

 <!-- 
 const set = new Set([10, 20]);

set.forEach((value, valueAgain, collection) => {
  console.log(value, valueAgain, collection.size);
});
  -->

6.4. set.keys() và set.values()
Set có các phương thức :
set.keys() 
set.values()
Cả 2 đều trả về interator chứa các giá trị của set . CHúng cho kết quả tương đương nhau
<!-- 
const set = new Set(["a", "b", "c"]);

console.log([...set.keys()]);
console.log([...set.values()]);
Kết quả:
["a", "b", "c"]
["a", "b", "c"]
 -->
 Tại sao Set có cả keys() và values() trong khi nó chỉ lưu giá trị 
 Đây là để duy trì tính tương thích với Map . Trog set mỗi giá trị có thể được xem như là key và value
 <!-- 
 const set = new Set([1, 2, 2, 3]);

console.log([...set.keys()]);
console.log([...set.values()]);
console.log(set.keys() === set.values());
  -->
6.5. set.entries()
Set cũng có phhương thức entries() nhưng kết quả hơi khác Map
Với Map , mỗi entry là [key, value] . Với set mỗi entry là [value , value]. cùng 1 giá trị nhưng đựouc lặp 2 lần
<!-- 
const set = new Set(["a", "b"]);

console.log([...set.entries()]);
Kết quả :
[
  ["a", "a"],
  ["b", "b"]
]
 -->
 Điều này nằm duy trì tính tương thích giữa API của set và map
 <!-- 
 const set = new Set([10, 20, 10]);

console.log([...set.entries()]);
console.log([...set.entries()].length);
  -->

7. Summary — Tổng kết lý thuyết Map và Set
7.1. So sánh Map, Set và Object
| Đặc điểm  | `Map`                   | `Set`                   | `Object`                                    |
| --------- | ----------------------- | ----------------------- | ------------------------------------------- |
| Lưu trữ   | Cặp key-value           | Giá trị duy nhất        | Thuộc tính key-value                        |
| Key       | Mọi kiểu dữ liệu        | Không có key riêng      | Chuỗi hoặc Symbol                           |
| Trùng lặp | Key không trùng         | Value không trùng       | Tên thuộc tính không trùng                  |
| Số lượng  | `map.size`              | `set.size`              | Thường dùng `Object.keys(obj).length`       |
| Duyệt     | `for...of`, `forEach()` | `for...of`, `forEach()` | `Object.entries()` hoặc các cách duyệt khác |
| Thứ tự    | Theo lần thêm key mới   | Theo lần thêm value mới | Có quy tắc riêng cho thứ tự thuộc tính      |

7.2. Các phương thức quan trọng
7.3. Những điểm dễ nhầm cần nhớ

1. map.set() trả về chính Map, nên có thể gọi nối tiếp.
2. map.keys(), map.values() và map.entries() trả về iterator, không phải array.
3. Cập nhật key đã tồn tại không làm key chuyển xuống cuối Map.
4. Xóa rồi thêm lại key sẽ đưa key đó xuống cuối.
5. Map phân biệt key số 1 với key chuỗi "1".
6. Set loại bỏ giá trị trùng; object được so sánh theo tham chiếu.
7. Set.forEach() nhận (value, valueAgain, set).
8. Object.entries() chuyển Object thành các cặp; Object.fromEntries() làm chiều ngược lại.
