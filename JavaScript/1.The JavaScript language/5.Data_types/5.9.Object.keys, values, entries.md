2.1. Các phương thức lấy dữ liệu từ Object
Trong JS , 1 object thường được lưu dữ liệu dưới dạng key: value
<!-- 
const user = {
    name: "John",
    age: 30,
    job: "Developer"
};
 -->
 JS cung cấp 3 phương thức:
Object.keys(obj) — lấy danh sách keys.
Object.values(obj) — lấy danh sách values.
Object.entries(obj) — lấy danh sách các cặp [key, value].
2.2. Object.keys(obj) — lấy keys
<!-- 
const user = {
    name: "John",
    age: 30,
    job: "Developer"
};

console.log(Object.keys(user));
// ["name", "age", "job"]
 -->
Object.keys(user) trả về 1 array chứa các key của object
2.3. Object.values(obj) — lấy values
<!-- 
const user = {
    name: "John",
    age: 30,
    job: "Developer"
};

console.log(Object.values(user));
// ["John", 30, "Developer"]
 -->
Trả về 1 array chứa các giá trị , k phải tên thuộc tính
<!-- 
const prices = {
    apple: 10,
    banana: 20,
    orange: 30
};

console.log(Object.values(prices));
// [10, 20, 30]
 -->
 2.4. Object.entries(obj) — lấy cặp [key, value]
 <!-- 
 const user = {
    name: "John",
    age: 30
};

console.log(Object.entries(user));
// [["name", "John"], ["age", 30]]
  -->
Một phần tử bên trong array kết quả của 1 array con gồm 2 phần tử
Phần tử thứ nhất là key
Phần tử thứ hai là value
Có thể truy câpj bằng index
<!-- 
const entries = Object.entries(user);

console.log(entries[0][0]); // "name"
console.log(entries[0][1]); // "John"
 -->
 hoặc có thể truy cập bằng
 <!-- 
 for (const [key, value] of Object.entries(user)) {
    console.log(key, value);
}

// name John
// age 30
  -->

Bài tập thực hành:
const product = {
    name: "Laptop",
    price: 1500,
    stock: 5
};

console.log(Object.keys(product));
console.log(Object.values(product));
console.log(Object.entries(product));

2.5. So sánh Object với Map
Object và Map đều lưu dữ liệu dưới dạng key value nhưng cách sử dụng khác nhau
1. Khác nhau về cách gọi
Với Object các phương thức là hàm tĩnh của Object 
Với Map các phương thức là instance method của đối tượng Map
<!-- 
const map = new Map();

map.set("name", "John");
map.set("age", 30);

map.keys();
map.values();
map.entries();
 -->
 Khác nhau về giá trị trả về
 Object trar về Array
 <!-- 
 const user = {
  name: "John",
  age: 30
};

const keys = Object.keys(user);

console.log(Array.isArray(keys));
// true
  -->
Map trả về Iterator không phải array
<!-- 
const map = new Map([
  ["name", "John"],
  ["age", 30]
]);

const keys = map.keys();

console.log(Array.isArray(keys));
// false 
-->
| Tiêu chí                 | Object             | Map          |
| ------------------------ | ------------------ | ------------ |
| Gọi phương thức          | `Object.keys(obj)` | `map.keys()` |
| Kiểu trả về              | Array              | Iterator     |
| Dùng `.push()` trực tiếp | Có                 | Không        |

Bài tập thực hành :

<!-- 
const user = {
  name: "John",
  age: 30
};

const map = new Map([
  ["name", "John"],
  ["age", 30]
]);

const objectKeys = Object.keys(user);
const mapKeys = map.keys();

console.log(Array.isArray(objectKeys));
console.log(Array.isArray(mapKeys));
console.log([...mapKeys]);
 -->
 2.6. Duyệt values bằng for...of
 Object.values() để duyệt trức tiếp các giá trị

 const prices = {
    apple: 10,
    banana: 20,
    orange: 30

for (const price of Object.values(prices)) {
    console.log(price);

-->
2.7. Symbol properties bị bỏ qua
Ba phương thức Object.keys(), Object.values() và Object.entries() chỉ trả về các thuộc tính own , enumerable,
có key kiểu string . Các thuộc tính có key kiểu symbol không xuất hiện trong kết quả

<!-- 
const id = Symbol("id");

const user = {
    name: "An",
    age: 25,
    [id]: 123
};

console.log(Object.keys(user));
// ["name", "age"]

console.log(Object.values(user));
// ["An", 25]

console.log(Object.entries(user));
// [["name", "An"], ["age", 25]]
 -->
 Thuộc tính id vẫn tồn tại nhưng k được 3 phương thức trên trả về
 Nếu muốn các key kiểu Symbol
 <!-- console.log(Object.getOwnPropertySymbols(user)); -->
 Nếu muốn lấy tất cả own keys gồm cả string và symbol kể cả thuộc tính không enumerable

 <!-- console.log(Reflect.ownKeys(user)); -->

3. Transforming objects — Biến đổi Object
3.1. Vì sao Object không có map() và filter()?
Các phương thức map và filter là phương thức của Array không phải của Object
3.2. Dùng Object.entries() để chuyển Object thành Array
<!-- 
const prices = {
    apple: 10,
    banana: 20
};

const entries = Object.entries(prices);

console.log(entries);
// [["apple", 10], ["banana", 20]]
 -->
3.3. Dùng map() để biến đổi dữ liệu
<!-- 
const prices = {
    apple: 10,
    banana: 20
};

const entries = Object.entries(prices);

const doubledEntries = entries.map(([key, value]) => {
    return [key, value * 2];
});

console.log(doubledEntries);
// [["apple", 20], ["banana", 40]]
 -->
 3.4. Dùng Object.fromEntries() để chuyển Array về Object
 <!-- 
 const doubledPrices = Object.fromEntries(doubledEntries);

console.log(doubledPrices);
// { apple: 20, banana: 40 }
  -->
Object.fromEntries() nhận một iterable chứa các cặp [key , value] và tạo ra Object

3.5. Kết hợp thành một quy trình

<!-- 
const prices = {
    apple: 10,
    banana: 20
};

const result = Object.fromEntries(
    Object.entries(prices).map(([key, value]) => [key, value * 2])
);

console.log(result);
// { apple: 20, banana: 40 }
 -->

 Object
  ↓ Object.entries()
Array of [key, value]
  ↓ map() / filter()
Transformed Array
  ↓ Object.fromEntries()
New Object

3.6. Dùng filter() để lọc thuộc tính
Ngoài map ta có thể dùng filter để loại bỏ các cặp key và value không thoả mãn điều kiẹn
<!-- 
const scores = {
    An: 8,
    Binh: 6,
    Chi: 9
};

const result = Object.fromEntries(
    Object.entries(scores).filter(([key, value]) => value >= 8)
);

console.log(result);
// { An: 8, Chi: 9 }
 -->

4. Summary — Tổng kết bài học

4.1. Ba phương thức lấy dữ liệu
<!-- 
Object.keys(obj);   // Array chứa keys
Object.values(obj); // Array chứa values
Object.entries(obj);// Array chứa [key, value]
 -->
4.2. Chuyển đổi Object
<!-- 
const result = Object.fromEntries(
    Object.entries(obj).map(([key, value]) => [key, value * 2])
);
 -->
4.3. Các điểm dễ nhầm
Object.keys(obj) trả về Array còn map.keys() trả về Iterator
Object.keys(), Object.values() và Object.entries() bỏ qua các key kiểu Symbol.
Map() biến đổi phần tử , Filter dùng để lọc phần tử
