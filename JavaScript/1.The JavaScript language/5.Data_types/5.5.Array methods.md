Mục 1 — map()
1.1. Lý thuyết theo tài liệu gốc
map() gọi một hàm cho tưng phần tử của mảng và trả về 1 hàm mới chứa kết quả mà hàm đó tạo ra
Syntax:
let result = arr.map(function(item, index, array) {
    // Trả về giá trị mới thay cho item
});
1.2. Case dễ nhầm: map() không tự thay đổi mảng gốc
map() tạo ra mảng kết qủa mới , k sửa mảng gốc
1.3. So sánh map() với forEach()
| Phương thức | Mục đích chính                       | Giá trị trả về |
| ----------- | ------------------------------------ | -------------- |
| `map()`     | Chuyển đổi từng phần tử              | Mảng mới       |
| `forEach()` | Thực hiện hành động với từng phần tử | `undefined`    |

* sort(fn)
1. sort sắp xếp các phần tử mảng ngay trên mảng gốc và trả về chính mảng đó
  let arr = [1, 2, 15];
  arr.sort();
  console.log(arr); // [1, 15, 2]
  Khi không truyền hàm so sánh mặc định sắp xếp các phần tử theo chuỗi string
1. Cách sắp xếp số đúng
let arr = [1, 2, 15];
arr.sort((a, b) => a - b);
console.log(arr); // [1, 2, 15]
1. Tiếp theo: sort(fn) — hàm so sánh có thể trả về bất kỳ số nào

let arr = [3, 1, 2];

arr.sort((a, b) => a - b);
So sánh 1 và 3: trả về -2, nghĩa là 1 đứng trước 3.
So sánh 2 và 1: trả về 1, nghĩa là 2 đứng sau 1.
Chỉ cần dấu của kết quả quyết định thứ tự, không cần chính xác là -1 hay 1.

* Mục 1.2 — slice()
  
* Slice () lấy 1 phần của mảng và trả về mảng mới , không làm thay đổi mảng gốc
arr.slice(start, end);
start: index bắt đầu lấy, được tính vào kết quả.
end: index kết thúc, không được tính vào kết quả.
Nếu bỏ end, lấy đến cuối mảng.
let arr = ["A", "B", "C", "D", "E"];
let result = arr.slice(1, 3);
console.log(result); // ["B", "C"]
console.log(arr);    // ["A", "B", "C", "D", "E"]
) Slice cũng có thể lấy vị trí âm
slice() cũng có thể nhận index âm, tính từ cuối mảng.

let arr = ["A", "B", "C", "D", "E"];
console.log(arr.slice(-3, -1));
// ["C", "D"]
) slice() sao chép mảng
Slice k truyền tham số sẽ tạo ra 1 bản nông của mảng
let arr = ["A", "B", "C"];

let copy = arr.slice();

console.log(copy);      // ["A", "B", "C"]
console.log(copy === arr); // false
Lưu ý mở rộng: Đây là bản sao nông. Nếu mảng chứa object lồng bên trong, object đó vẫn có thể được tham chiếu chung giữa hai mảng.
REcap : arr.slice(start, end);
Lấy phần tử từ start đến trước end.
Không truyền tham số: tạo bản sao nông của mảng.
Không làm thay đổi mảng gốc.
Có thể sử dụng index âm để đếm từ cuối mảng.

Recap — Add/remove items

| Phương thức | Tác dụng                        | Thay đổi mảng gốc? |
| ----------- | ------------------------------- | ------------------ |
| `splice()`  | Xóa, chèn, thay thế             | Có                 |
| `slice()`   | Lấy một phần hoặc sao chép mảng | Không              |
| `concat()`  | Kết hợp mảng và giá trị         | Không              |

splice(start, deleteCount, ...items)
    → Xóa / chèn / thay thế
    → Thay đổi mảng gốc
    → Trả về mảng các phần tử bị xóa

slice(start, end)
    → Lấy phần tử từ start đến trước end
    → Không thay đổi mảng gốc
    → Không truyền tham số thì sao chép mảng

concat(...items)
    → Kết hợp mảng và giá trị
    → Trả về mảng mới
    → Không thay đổi mảng gốc
* 2. Những điểm dễ nhầm
- splice(1, 2): xóa 2 phần tử bắt đầu tại index 1.
- splice(1, 0, "X"): chèn "X" tại index 1, không xóa phần tử nào.
- slice(1, 3): lấy index 1, 2; không lấy index 3.
- concat([3, [4, 5]]): mảng [4, 5] vẫn lồng bên trong kết quả.
- delete arr[1] tạo ô trống, không làm giảm length; splice() thì loại bỏ phần tử khỏi mảng.

3.1. indexOf(), lastIndexOf() và includes()
3 phương thức này dùng để tìm 1 giá trị cụ thể trong mảng
1. indexOf() — tìm vị trí xuất hiện đầu tiên
arr.indexOf(item, from);
item: giá trị cần tìm.
from: vị trí bắt đầu tìm, mặc định là 0.
Trả về index đầu tiên tìm thấy giá trị.
Nếu không tìm thấy, trả về -1.
let fruits = ["Apple", "Banana", "Orange", "Banana"];

console.log(fruits.indexOf("Banana")); // 1
console.log(fruits.indexOf("Orange")); // 2
console.log(fruits.indexOf("Grape"));  // -1
console.log(fruits.indexOf("Banana", 2)); // 3
2. lastIndexOf() — tìm vị trí xuất hiện cuối cùng
let fruits = ["Apple", "Banana", "Orange", "Banana"];

console.log(fruits.lastIndexOf("Banana")); // 3
console.log(fruits.lastIndexOf("Grape"));  // -1
3. includes() — kiểm tra có tồn tại hay không
let fruits = ["Apple", "Banana", "Orange"];

console.log(fruits.includes("Banana")); // true
console.log(fruits.includes("Grape"));  // false
4. Phân biệt nhanh
| Phương thức     | Kết quả                   | Hướng tìm kiếm |
| --------------- | ------------------------- | -------------- |
| `indexOf()`     | Index đầu tiên hoặc `-1`  | Trái → phải    |
| `lastIndexOf()` | Index cuối cùng hoặc `-1` | Phải → trái    |
| `includes()`    | `true` hoặc `false`       | Trái → phải    |

Lưu ý: indexOf() dùng so sánh nghiêm ngặt (===), nên không coi 0 và false là cùng một giá trị.
let values = [0, false, 1];

console.log(values.indexOf(false)); // 1
console.log(values.indexOf(0));     // 0
console.log(values.includes(false)); // true
5. Trường hợp đặc biệt: NaN )))))))
let values = [NaN];

console.log(values.indexOf(NaN));  // -1
console.log(values.includes(NaN)); // true
includes nhận diện được NaN , còn indexOf thì không

Bài tập tự luyênj

console.log(numbers.indexOf(10)); 
console.log(numbers.lastIndexOf(10));
console.log(numbers.indexOf(10, 1));

Bài tập 2 : case dễ bị nhầm  )))))))

console.log(values.indexOf(NaN));
console.log(values.lastIndexOf(NaN));
console.log(values.includes(NaN));
console.log(values.includes("0"));
indexOf(NaN) và lastIndexOf(NaN) đều trả về -1 vì hai phương thức này không tìm thấy NaN.
includes(NaN) trả về true vì includes() nhận diện được NaN.
includes("0") trả về false vì "0" là chuỗi, còn 0 trong mảng là số. Không tự động chuyển kiểu khi so sánh.

* * find() và findIndex() )))

find duyệt qua từng phần tử và gọi callback để kiểm tra điều kiện . KHi găp phần tử đầu tiên thoả mãn nó trả về chính
phần tử đó và dừng tìm kiếm
find() duyệt từ trái sang phải:
- 5 > 10 → false, tiếp tục.

Ghi nhớ: find() trả về phần tử đầu tiên thỏa mãn điều kiện, không phải tất cả phần tử thỏa mãn.

findIndex() cũng tìm theo điều kiện và trả về index đầu tiên của phần tư thoả mãn
Nếu không tìm thấy trả về -1;

console.log(numbers.find(item => item > 10));
console.log(numbers.findIndex(item => item > 10));

findLastIndex() tìm từ phải sang trái , trả về index của phần tử cuối thoả mãn điều kiện

4.5. reduce() và reduceRight()
Reduce gộp mảng thành 1 gía trị 
reduce() chạy callback qua các phần tử tích luỹ kết qủa qua từng đợt 
arr.reduce((accumulator, item, index, array) => {
  return /* giá trị tích lũy tiếp theo */;
}, initialValue);
Trong đó:
- accumulator: giá trị tích lũy từ các lượt trước.
- item: phần tử hiện tại.
- index: index hiện tại.
- array: mảng gốc.
- initialValue: giá trị khởi tạo cho accumulator (nên truyền rõ ràng khi phù hợp).
2. Ví dụ cộng các số

let numbers = [1, 2, 3, 4];

let sum = numbers.reduce((acc, item) => {
  return acc + item;
}, 0);

console.log(sum); // 10

| Lượt | `acc` trước | `item` | Kết quả mới |
| ---- | ----------: | -----: | ----------: |
| 1    |           0 |      1 |           1 |
| 2    |           1 |      2 |           3 |
| 3    |           3 |      3 |           6 |
| 4    |           6 |      4 |          10 |

3. Vì sao cần initialValue?

let numbers = [1, 2, 3];
console.log(numbers.reduce((acc, item) => acc + item, 10));
// 16
4. reduceRight() — tích lũy từ phải sang trái
let letters = ["A", "B", "C"];
let result = letters.reduceRight((acc, item) => {
  return acc + item;

console.log(result); // "CBA"

4.7. Most methods support "thisArg"
Một số phương thức của mảng như find(), filter() và map() cho phép truyền thêm đối số thisArg để làm giá trị this trong callback

let user = {
  minAge: 18
};

let users = [
  { name: "An", age: 16 },
  { name: "Bình", age: 21 }
];

let adults = users.filter(function(item) {
  return item.age >= this.minAge;
}, user);

console.log(adults);
// [{ name: "Bình", age: 21 }]
