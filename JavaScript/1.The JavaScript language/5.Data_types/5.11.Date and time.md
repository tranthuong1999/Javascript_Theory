2. Creation — Tạo đối tượng Date
Date là đối tượng có sẵn trong JS dùng để biểu diễn ngày và giờ . Date luôn đại diện cho 1 thời điểm cụ thể ,
không chỉ riêng ngày hoặc giờ
2.1.new Date() -- Thời điểm hiện tại 
const now = new Date();

console.log(now);
2.2.new Date(milliseconds) - Tạo ngày từ milliseconds
JS biểu diễn bằng miliseconds 
<!-- 
const date = new Date(0);

console.log(date);
 -->
2.3. Timestamp là gì?
Timestamp là số miliseconds tính từ mốc thời gian 01/01/1970 UTC đến một thời điểm.
<!-- 
const now = new Date();

console.log(now.getTime());
 -->
2.4.new Date(datestring) - Tạo Date từ chuỗi
<!-- 
const date = new Date("2026-10-29");

console.log(date);
 -->
 JS có thể phân tích chuỗi ngày thành đối tượng Date 
2.5. new Date(year, month, date, ...)
<!-- 
const date = new Date(2026, 9, 29);

console.log(date);
 -->
 Đối tượng đại diện cho ngày 29/10/2026 lúc 00:00 theo múi giờ địa phương
year: năm , nên dùng 4 chữ số
month : bắt đầu từ 0 , không phải 1
date : trong ngày tháng , mặc đinh là 1. 
hours, minutes, seconds, milliseconds: mặc định bằng 0.
Bài tập 1 — Tạo Date
<!-- 
const date = new Date(2026, 9, 29);

console.log(date.getFullYear());
console.log(date.getMonth());
console.log(date.getDate());
 -->
getFullYear() → trả về 2026.
getMonth() → trả về 9 vì tháng bắt đầu bằng 0
getDate() trả về ngày trong tháng

2. Access date components — Lấy các thành phần ngày giờ
2.1. Lấy ngày , tháng , năm
| Phương thức     | Ý nghĩa                     | Ví dụ  |
| --------------- | --------------------------- | ------ |
| `getFullYear()` | Lấy năm                     | `2026` |
| `getMonth()`    | Lấy tháng (0–11)            | `9`    |
| `getDate()`     | Lấy ngày trong tháng (1–31) | `29`   |
<!-- 
const date = new Date(2026, 9, 29);

console.log(date.getFullYear()); // 2026
console.log(date.getMonth());    // 9
console.log(date.getDate());     // 29
 -->
2.2. Lấy giờ phút giây
| Phương thức         | Ý nghĩa          | Phạm vi |
| ------------------- | ---------------- | ------- |
| `getHours()`        | Lấy giờ          | 0–23    |
| `getMinutes()`      | Lấy phút         | 0–59    |
| `getSeconds()`      | Lấy giây         | 0–59    |
| `getMilliseconds()` | Lấy milliseconds | 0–999   |
2.3. getDay() — Lấy thứ trong tuần
getDay() trả về thứ trong tuần với quy ước
| Giá trị | Thứ      |
| ------: | -------- |
|       0 | Chủ nhật |
|       1 | Thứ hai  |
|       2 | Thứ ba   |
|       3 | Thứ tư   |
|       4 | Thứ năm  |
|       5 | Thứ sáu  |
|       6 | Thứ bảy  |

<!-- 
const date = new Date(2026, 9, 29);

console.log(date.getDay()); 4
Vì ngày 29/10/2026 là thứ năm.
 -->
 Dễ nhầm:
-getDate() : ngày trong tháng
-getDay() : thứ trong tuần

Bài tập nhỏ :

<!-- 
const date = new Date(2026, 9, 30, 14, 25, 40);

console.log(date.getDay());
console.log(date.getDate());
console.log(date.getHours());
console.log(date.getMonth());
 -->
2.4. Các phương thức UTC
JS cung cấp 2 phương thức để lấy thông tin ngày giờ:
getFullYear(), getMonth(), getDate() lấy theo múi giờ địa phương
getUTCFullYear(), getUTCMonth(), getUTCDate() lấy theo UTC
<!-- 
const date = new Date("2026-10-30T00:00:00Z");

console.log(date.getHours()); 7
console.log(date.getUTCHours()); 0
 -->
 Nếu chạy tại Việt Nam (UTC+7)
 Vì getHours() trả về giờ địa phương 07:00
 getUTCHours() trả vê giờ UTC : 00:00
 Các phương thức UTC tương ứng:
 | Local time          | UTC                    |
 | ------------------- | ---------------------- |
 | `getFullYear()`     | `getUTCFullYear()`     |
 | `getMonth()`        | `getUTCMonth()`        |
 | `getDate()`         | `getUTCDate()`         |
 | `getDay()`          | `getUTCDay()`          |
 | `getHours()`        | `getUTCHours()`        |
 | `getMinutes()`      | `getUTCMinutes()`      |
 | `getSeconds()`      | `getUTCSeconds()`      |
 | `getMilliseconds()` | `getUTCMilliseconds()` |
 2.5. getTime()
 getTime() trả về timeStamp của đối tượng Date , tức là số milliseconds tính từ mốc 01/01/1970
 <!-- 
 const date = new Date("1970-01-01T00:00:01Z");

console.log(date.getTime()); // 1000
  -->
getTIme() không phụ thuộc múi giờ hiển thị . Cùng 1 thời điểm timeStamp luôn giống nhau ở mọi múi giờ

2.6 getTimezoneOffset()
Phương thức này trả về độ lệch giữa UTC và giờ địa phương tính theo phút
<!-- 
const date = new Date();

console.log(date.getTimezoneOffset());
 -->
 -420 vì UTC - Local = 0 - 420 = -420
 Bài tập nhỏ :
 <!--  
const date = new Date("2026-10-30T00:00:00Z");

console.log(date.getUTCHours());
console.log(date.getHours());
console.log(date.getTime());
console.log(date.getTimezoneOffset());
  -->
getUTCHours() → 0.
getHours() → 7 (UTC+7).
getTimezoneOffset() → -420 phút.
3. Setting date component - Thiết lập thành phần ngày giờ

| Phương thức                           | Thành phần thay đổi |
| ------------------------------------- | ------------------- |
| `setFullYear(year, [month], [date])`  | Năm                 |
| `setMonth(month, [date])`             | Tháng               |
| `setDate(date)`                       | Ngày trong tháng    |
| `setHours(hours, [min], [sec], [ms])` | Giờ                 |
| `setMinutes(min, [sec], [ms])`        | Phút                |
| `setSeconds(sec, [ms])`               | Giây                |
| `setMilliseconds(ms)`                 | Milliseconds        |
| `setTime(milliseconds)`               | Timestamp           |

Ví dụ 1: Thay đổi năm
<!-- 
const date = new Date(2026, 9, 30);

date.setFullYear(2025);

console.log(date);
 -->
 Ngày giờ được giữ nguyên , chỉ thay đổi năm

 Ví dụ 2: Thay đổi tháng
<!-- 
const date = new Date(2026, 9, 30);

date.setMonth(0);

console.log(date);
 -->

 Ví dụ 3: Thay đổi nhiều thành phần

<!-- 
const date = new Date(2026, 9, 30, 14, 30);
date.setHours(10, 15, 20);
console.log(date);
 -->
Kết quả: 30/10/2026 lúc 10:15:20.

Các phương thức UTC tương ứng
1. setUTCFullYear()
2. setUTCMonth()
3. setUTCDate()
4. setUTCHours()
5. setUTCMinutes()
6. setUTCSeconds()
7. setUTCMilliseconds()
Chúng thay đổi thơi gian theo UTC thay vì múi giờ địa phương

Bài tập nhỏ : 
<!-- 
const date = new Date(2026, 9, 30);

date.setMonth(0);
date.setDate(15);

console.log(date.getFullYear());
console.log(date.getMonth());
console.log(date.getDate());
 -->

4. Autocorrection — Tự động điều chỉnh ngày giờ
JS tự động điều chỉnh múi giờ khi bạn truyền gía trị vượt phạm vi hợp lệ
<!-- 
const date = new Date(2026, 1, 32);

console.log(date);
 -->
 1 là tháng 2 mà tháng 2 có 28 ngày , nên ngày 32 được chuyển thành ngày 04/03/2026
 Tại sao tính năng này hữu ích?
 Ví dụ lấy ngày đấu tháng tiếp theo
<!-- 
const date = new Date(2026, 9, 1);
date.setMonth(date.getMonth() + 1);
console.log(date);
 -->
 Bài tập thực hành:
 <!-- 
const date = new Date(2026, 0, 1);
date.setDate(0);

console.log(date.getFullYear());
console.log(date.getMonth());
console.log(date.getDate());
  -->
3. Một số trường hợp tương tự cần nhớ
   <!-- const date = new Date(2026, 9, 15); -->
Ngày ban đầu là : 15/10/2026
| Code               | Kết quả    |
| ------------------ | ---------- |
| `date.setDate(0)`  | 30/09/2026 |
| `date.setDate(1)`  | 01/10/2026 |
| `date.setDate(32)` | 01/11/2026 |
| `date.setDate(-1)` | 29/09/2026 |
4. Ứng dụng thực tế
Muốn lấy ngày cuối cùng của tháng bất kỳ bạn có thể sử dụng mẹo này
<!-- 
function getLastDayOfMonth(year, month) {
    const date = new Date(year, month + 1, 0);

    return date.getDate();
}

console.log(getLastDayOfMonth(2026, 0)); // 31
console.log(getLastDayOfMonth(2026, 1)); // 28
console.log(getLastDayOfMonth(2026, 9)); // 31
 -->

5. Date to number, date diff
Hiểu cách so sánh 2 ngày và tính khoảng thời gian giữa chúng
5.1. Chuyển Date thành Number
Date có thể chuyển thành timestamp bằng cách sử dụng toán tử + hoặc getTime();
<!-- 
const date = new Date();

console.log(+date);
console.log(date.getTime());
 -->
 Ví du:
 <!-- 
 const start = new Date("2026-10-29");
const end = new Date("2026-10-30");

console.log(+end - +start);
86400000
  -->
5.2. Tính khoảng cách giữa hai ngày
<!-- 
const date1 = new Date("2026-10-29");
const date2 = new Date("2026-11-02");

const diff = date2 - date1;

const diffDays = diff / (1000 * 60 * 60 * 24);

console.log(diffDays); // 4
 -->

6. Date.now()
Date.now trả về timeStamp của thời điểm hiện tại tính bằng milisecond kể từ 01/01/1970
| Cách viết        | Ý nghĩa                                    |
| ---------------- | ------------------------------------------ |
| `new Date()`     | Tạo đối tượng Date hiện tại                |
| `Date.now()`     | Trả về timestamp hiện tại dưới dạng Number |
| `date.getTime()` | Lấy timestamp từ một Date có sẵn           |
<!-- 
const date = new Date();

console.log(typeof date);

console.log(typeof date.getTime());
 -->

7. Benchmarking — Đo hiệu năng
Benchmarking là quá trình đo time thực thi để so sánh hiệu năng giữa các đoạn code
<!-- 
const start = Date.now();

// Đoạn code cần kiểm tra
for (let i = 0; i < 1000000; i++) {
    // ...
}

const end = Date.now();

console.log(`Time: ${end - start} ms`);
 -->
7.1. So sánh hai cách thực hiện
Giả sử bạn muốn kiểm tra 2 cách tính toán:

<!--
const start1 = Date.now();

for (let i = 0; i < 1000000; i++) {
    Math.sqrt(i);
}

const end1 = Date.now();

const start2 = Date.now();

for (let i = 0; i < 1000000; i++) {
    i ** 0.5;
}

const end2 = Date.now();

console.log("Math.sqrt:", end1 - start1);
console.log("Exponent:", end2 - start2);
  -->
Lưu ý : time có thể dao động do CPU , trình duyệt 
7.2. Một số lưu ý khi benchmarking
1. Chạy thử nhiều lần để giảm ảnh hưởng của những biến động ngẫu nhiên.
2. Không kết luận chỉ dựa trên một lần đo.
3. So sánh cùng điều kiện đầu vào.
4. Với tác vụ rất ngắn, Date.now() có độ phân giải chưa đủ tốt; có thể dùng performance.now() trong môi trường trình duyệt.

8. Date.parse from a string
<!--

8.1. Định dạng chuỗi được hỗ trợ
<!-- YYYY-MM-DDTHH:mm:ss.sssZ -->
| Thành phần | Ý nghĩa               |
| ---------- | --------------------- |
| `YYYY`     | Năm                   |
| `MM`       | Tháng                 |
| `DD`       | Ngày                  |
| `T`        | Phân cách ngày và giờ |
| `HH`       | Giờ                   |
| `mm`       | Phút                  |
| `ss`       | Giây                  |
| `sss`      | Milliseconds          |
| `Z`        | Múi giờ UTC           |
<!-- 
Date.parse("2026-10-30"); 
// Ngày 30/10/2026, 00:00 UTC

Date.parse("2026-10-30T10:00:00Z");
// 30/10/2026, 10:00 UTC

Date.parse("2026-10-30T10:00:00+07:00");
// 30/10/2026, 10:00 theo UTC+7
 -->

8.2. Date.parse() trả về gì?
<!--
const timestamp = Date.parse("2026-10-30T10:00:00Z");

console.log(typeof timestamp); // number
  -->
8.3. Phân biệt Date.parse() và new Date()
<!-- 
const timestamp = Date.parse("2026-10-30");

const date = new Date("2026-10-30");

console.log(typeof timestamp); // number
console.log(typeof date);      // object
 -->
