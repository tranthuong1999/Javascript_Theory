1. JSON.stringify
1.1. JSON là gì?
JSON ( JS Object Notation) là 1 định dạng dữ liệu dùng để lưu trữ và trao đổi dữ liệu giữa các hệ thống
Khi muốn gửi dữ liệu dưới dạng JSON , chúng ta chuyển nó thành chuỗi
<!-- 
const json = JSON.stringify(user);
console.log(json);
Kết quả :
{"name":"Martin","age":27,"isAdmin":false}
 -->
Điểm quan trọng:
-JavaScript Object: cấu trúc đang sử dụng trong JS
JSON : định dạng dữ liệu dạng văn bản (text)
JSON.stringify():chuyển JS value thành JSON string

1.2. Quy tắc cú pháp JSON
JSON có cú pháp nghiêm ngặt hơn JS object
<!--
JS Object 
const user = {
    name: 'Martin',
    age: 27
};
JSON
{
    "name": "Martin",
    "age": 27
}
 -->

 | JavaScript Object                   | JSON                                      |
 | ----------------------------------- | ----------------------------------------- |
 | Có thể dùng `'` hoặc `"` cho string | Bắt buộc dùng `"`                         |
 | Key có thể không có dấu nháy        | Key bắt buộc có `"`                       |
 | Có thể chứa function                | Không hỗ trợ function                     |
 | Có thể chứa `undefined`             | Không hỗ trợ `undefined`                  |
 | Có thể chứa `Date`, `Map`, `Set`    | Không có kiểu dữ liệu tương ứng trực tiếp |

1.3. Các kiểu dữ liệu JSON hỗ trợ
Object {} , Array [] , string , number , Booelean(true , false) , null
<!-- 
console.log(JSON.stringify(100)); 
// "100"

console.log(JSON.stringify("Hello"));
// '"Hello"'

console.log(JSON.stringify(true));
// "true"

console.log(JSON.stringify([1, 2, 3]));
// "[1,2,3]"

console.log(JSON.stringify(null));
// "null"
 -->
1.4. Những thuộc tính bị bỏ qua
JSON.stringify() không thể truyền tất cả các thuộc tính object thành JSON

Có 3 loại giá trị thường bị bỏ qua khi nằm trong Objec:
1. undefined
2. function
3. Symbol

<!-- 
const user = {
    name: "Martin",
    age: 27,
    sayHi() {},
    address: undefined,
    [Symbol("id")]: 123
};

console.log(JSON.stringify(user));
 -->

 Các thuộc tính : sayHi, address và Symbol không xuất hiện trong JSON
 Lưu ý thêm: Với Array , các giá trị undefined , Function và Symbol không bị bỏ qua mà đựoc chuyển thành null

 <!-- 
 const arr = [1, undefined, function() {}, 3];

console.log(JSON.stringify(arr));
// "[1,null,null,3]"
  -->
1.5. Nested objects và Circular references
1. Nested objects – Object lồng nhau
JSON.stringify() có thể chuyển đổi object chứa các object hoặc array bên trong 1 cách đệ quy
<!-- 
const user = {
    name: "Martin",
    age: 27,
    address: {
        city: "Hanoi",
        country: "Vietnam"
    },
    skills: ["JavaScript", "React"]
};

console.log(JSON.stringify(user));
 -->
 Bạn không cần gọi JSON.stringify() riêng cho address hoặc skills . Hàm sẽ tự đông xủ lý các cấp lồng nhau

2. Circular references – Tham chiếu vòng
Đây là 1 trường hợp 1 object tham chiếu đến chính nó , trực tiếp hoặc gián tiếp

2. Excluding and transforming: replacer
replacer là tham số thứ 2 của JSON.stringify(), cho phép chúng ta kiểm soat thuộc tính nào được chuyển thành json và
thay đổi gía trị của chúng
Syxtax:
<!-- JSON.stringify(value, replacer, space); -->
Trong đó :
value : Object hoặc giá trị cần chuyển đổi
replacer : quy định thuộc tính nào được giữ lại hoặc thay đổi
space : quy định các định dạng JSON
Có 2 dạng replacer:
<!-- 
2. Excluding and transforming: replacer
│
├── 2.1. Replacer dạng Array
│   └── Chọn những thuộc tính được phép xuất hiện
│
└── 2.2. Replacer dạng Function
    └── Lọc hoặc biến đổi giá trị bằng function
 -->
2.1. Replacer dạng Array
Bạn có thể truyền 1 array chứa tên các thuộc tính cần giữu lại 
<!-- 
const user = {
    name: "Martin",
    age: 27,
    password: "123456",
    email: "martin@gmail.com"
};

const json = JSON.stringify(user, ["name", "email"]);

console.log(json);
 -->
Lưu ý quan trọng: Replacer dạng Array cũng áp dụng cho các object lồng nhau.
<!-- 
const user = {
    name: "Martin",
    age: 27,
    address: {
        city: "Hanoi",
        district: "Cau Giay"
    }
};

console.log(JSON.stringify(user, ["name", "address", "city"]));
 -->
district bị loại bỏ vì không nằm trong danh sách cho phép

2.2. Replacer dạng Function
Ngoài Array, replace có thể là 1 function nhận 2 tham số:
<!-- 
JSON.stringify(value, function(key, value) {
    // Xử lý key và value
});
 -->
 Trong đó:
-key : tên thuộc tính hiện tại
value : gía trị tương ứng
return value : giữ lại giá trị
return undefined: loại bỏ thuộc tính
return giá_trị_mới : thay đổi giá trị trước khi chuyển thành JSON

Ví dụ 1: Loại bỏ thuộc tính password.

<!-- 
const user = {
    name: "Martin",
    age: 27,
    password: "123456"
};

const json = JSON.stringify(user, function(key, value) {
    if (key === "password") {
        return undefined;
    }

    return value;
});

console.log(json);
 -->

Ví dụ 2: Thay đổi giá trị trước khi chuyển thành JSON.
<!-- 
const user = {
    name: "Martin",
    age: 27
};

const json = JSON.stringify(user, function(key, value) {
    if (key === "name") {
        return value.toUpperCase();
    }

    return value;
});

console.log(json);
 -->

Một điểm rất quan trọng:Function replacer được goi cả với Object gốc trước khi duyệt các thuộc tính bên trong
Lần gọi đầu tiên có:
key = "" (chuỗi rỗng).
value = object gốc.
Sau đó function mới lần lượt goij với từng thuộc tính , kể cả các thuộc tính lồng nhau
Ghi nhớ sự khác nhau:
| Replacer | Cách hoạt động                               |
| -------- | -------------------------------------------- |
| Array    | Chọn thuộc tính được phép xuất hiện          |
| Function | Kiểm tra, loại bỏ hoặc biến đổi từng giá trị |

3. Formatting: space
JSON.stringify() tạo ra JSON trên một dòng , không có khoảng trắng hay xuống dòng
<!-- 
const user = {
    name: "Martin",
    age: 27,
    address: {
        city: "Hanoi"
    }
};

console.log(JSON.stringify(user));
 -->
Kết quả : 
{"name":"Martin","age":27,"address":{"city":"Hanoi"}}
Để json dễ đọc hơn ta sử dụng tham số thư 3 space

3.1. Sử dụng space dạng Number
<!-- JSON.stringify(value, replacer, space); -->

console.log(JSON.stringify(user, null, 2));
Số 2 có nghĩa là mỗi cấp lồng nhau nên thụt vào 2 khoảng trắng

3.2. Sử dụng space dạng String
<!-- console.log(JSON.stringify(user, null, "----")); -->
Lưu ý : space chỉ liên quan đến trình bày chuỗi JSON không thay đổi dữ liệu gốc
<!-- 
const product = {
    name: "MacBook",
    price: 2000
};

console.log(JSON.stringify(product, null, 4));
 -->

4. Custom toJSON
Mỗi object có thể định nghia phương thức toJSON() để quyết định dữ liệu nào sẽ được trả về khi gọi JSON.stringify()
<!-- 
const user = {
    name: "Martin",
    age: 27,

    toJSON() {
        return this.name;
    }
};

console.log(JSON.stringify(user));
 -->
1. JSON.stringify() phát hiện object có phương thức toJSON().
2. Nó gọi phương thức này.
3. Giá trị được toJSON() trả về sẽ được chuyển thành JSON thay vì object ban đầu.

Một ví dụ thực tế khác là Date:
<!-- 
const date = new Date("2026-10-30");

console.log(JSON.stringify(date));
 -->
 Dat có sẵn phương thức toJSON() để chuyển ngày thangs thành chuỗi ISO

5. JSON.parse
Nếu JSON.stringify() chuyển value thành JSON string thì JSON.parse() làm điều ngược lại
STRINGIFY: JavaScript → JSON string
PARSE: JSON string → JavaScript value

<!-- 
const json = '{"name":"Martin","age":27}';
const user = JSON.parse(json);
console.log(user.name); // Martin
console.log(user.age);  // 27
console.log(typeof user); // object
 -->
5.1.Chuyển JSON string thành JavaScript value
JSON.parse() có cú pháp:
JSON.parse(str, reviver);
str: chuỗi JSON cần chuyển đổi 
reviver : Fucntion tuỳ chọn để biến đổi dữ liệu trong quá trình parse
<!-- 
const json = '[1, 2, 3]';

const arr = JSON.parse(json);

console.log(arr); // [1, 2, 3]
console.log(Array.isArray(arr)); // true
 -->
 (( Bài tâp
 <!-- 
 const json = '{"name":"MacBook","price":2000}';

const product = JSON.parse(json);

console.log(product.name);
console.log(typeof product);
  -->
 
 5.2. Các lỗi thường gặp khi viết JSON
 JSON có cú pháp nghiêm ngặt hơn JS Object
1. Key không có dấu ngoặc kép
   <!-- 
   // Sai
{ name: "Martin" }

// Đúng
{ "name": "Martin" } 
-->
2. Sử dụng dấu nháy đơn
<!-- // Sai -->
{ "name": 'Martin' }
<!-- // Đúng -->
{ "name": "Martin" }
3. Có dấu phẩy thừa ở cuối
 <!-- // Sai -->
{ "name": "Martin", }
<!-- // Đúng -->
{ "name": "Martin" }
4. Sử dụng comment
JSON không hỗ trợ comment 
Lưu ý : JSON.parse() chỉ nhận JSON hợp lệ

6. Using reviver
replacer dùng trong JSON.stringify() để lọc hoặc biến đổi dữ liệu
Tương tụ revier trong JSON.parse() để biến đổi dữ liệu trong quá trình chuyển JSON string thành JS value
Cú pháp:
<!-- 
JSON.parse(json, function(key, value) {
    // Xử lý dữ liệu
});
 -->

 Ví dụ : chuyển đổi ngày thánh trong đối tượng date 
 <!--
 const json = '{"name":"Martin","date":"2026-10-30T00:00:00.000Z"}';

const user = JSON.parse(json, function(key, value) {
    if (key === "date") {
        return new Date(value);
    }

    return value;
});

console.log(user.date);
console.log(user.date instanceof Date);
   -->
Giải thích:
1. JSON.parse() đọc JSON string.
2. Khi gặp thuộc tính date, reviver kiểm tra key === "date".
3. Chuyển chuỗi ngày tháng thành new Date(value).
4. Các giá trị khác được giữ nguyên bằng return value.
(( Bài tập vận dungk
<!-- 
const json = '{"name":"Martin","age":"27"}';

const user = JSON.parse(json, function(key, value) {
    if (key === "age") {
        return Number(value);
    }

    return value;
});

console.log(user.age);
console.log(typeof user.age);
 -->
