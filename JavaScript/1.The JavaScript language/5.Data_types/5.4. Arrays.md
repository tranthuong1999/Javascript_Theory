Mục 1 — Declaration (Khai báo mảng)
1.1. Array là gì?
Array (mảng ) : là cấu trúc dũ liệu dùng để lưu 1 tập hợp các phần tử theo thứ tự 
Ví dụ, khi cần lưu danh sách trái cây:
let fruit1 = "Apple";
let fruit2 = "Orange";
let fruit3 = "Plum";
1.2. Cách khai báo mảng
Có hai cách tạo mảng rỗng:
let arr1 = new Array();
let arr2 = [];
1.3. Truy cập phần tử bằng index
1.4. Thay đổi và thêm phần tử
1.5. Thuộc tính length
length cho biết độ dài hiện tại của mảng
Mảng cũng có thể chứa nhiều kiểu dữ liệu khác nhau:

1. Declaration
├── Array là tập hợp phần tử có thứ tự
├── Khai báo
│   ├── []                 → cách thông dụng
│   └── new Array()        → cách khác
├── Truy cập phần tử
│   └── arr[index]
│       └── Index bắt đầu từ 0
├── Thay đổi phần tử
│   └── arr[index] = value
├── Thêm phần tử tại index mới
│   └── arr[arr.length] = value
└── length
    ├── Số phần tử thông thường
    └── Là thuộc tính, không phải hàm
Method at cho phép truy cập thuộc tính âm

2. Get last elements with "at"
├── at(0)  → phần tử đầu tiên
├── at(-1) → phần tử cuối cùng
├── at(-2) → phần tử kế cuối
├── at(-0) → tương đương at(0)
├── Index ngoài phạm vi → undefined
└── arr[-1] ≠ arr.at(-1)
    ├── arr[-1]      → thuộc tính "-1"
    └── arr.at(-1)   → phần tử cuối cùng

Mục 4 — Internals
Array là 1 object đặc biệt được thiết kế đặc biệt để lưu trữ các phần tử theo thứ tự 
Ngoài việc truy cập bằng index bạn cũng có thể gán thuộc tính cho mảng như object thông thường

1. Index của mảng và thuộc tính thông thường
let fruits = ["Apple", "Orange"];

fruits[2] = "Pear";
console.log(fruits.length); // 3

fruits.name = "My fruits";
console.log(fruits.length); // 3
1. Không nên dùng mảng như object thông thường
2. Không nên dùng mảng như object thông thường
let arr = [];

arr[100] = "Apple";

console.log(arr.length); // 101
Dù chỉ gán một phần tử tại index 100 , length vẫn bằng 101 vì độ dài mảng được tính theo index lớn nhất đang có +1
length của mảng dựa trên index nguyên không âm lớn nhất cộng 1
3. So sánh hai cách gán

Bài tập :
let arr = [];

arr[3] = "A";
arr.name = "Test";

console.log(arr.length);
console.log(arr[0]);
console.log(arr[3]);
console.log(arr.name);

Giải thích:
1. arr.length → 4 vì index lớn nhất được gán là 3, nên length = 3 + 1.
2. arr[0] → undefined vì vị trí 0 đang là ô trống.
3. arr[3] → "A".
4. arr.name → "Test" vì name là thuộc tính thông thường, không phải phần tử mảng.
   
Bài tập 2 — Phân biệt ô trống và undefined
let arr = [];
arr[2] = undefined;

console.log(arr.length);
console.log(0 in arr);
console.log(2 in arr);
arr.length → 3 vì index lớn nhất được gán là 2.
0 in arr → false vì index 0 là ô trống, chưa tồn tại phần tử.
2 in arr → true vì index 2 có phần tử được gán giá trị undefined.
Như vậy ô trống khác với các phần từ có giá trị là undefined . Toán tử in kiểm tra phần tư có tồn tại index hay không

4. Internals
├── Array là object đặc biệt
├── arr[index] = value
│   └── Gán phần tử theo index
├── arr.name = value
│   └── Gán thuộc tính, không tăng length
├── length
│   └── Index lớn nhất + 1 (nếu có phần tử)
└── Ô trống ≠ undefined được gán
    ├── 0 in arr → false nếu index 0 trống
    └── 2 in arr → true nếu index 2 được gán undefined

Mục 7 — A word about length
Ở mục Declaration, mình đã học arr.length là độ dài mảng. Nhưng có một điểm quan trọng hơn: length không chỉ đọc được mà còn có thể thay đổi để làm mảng ngắn đi hoặc dài ra
1. length bằng index lớn nhất + 1
let arr = [];
arr[3] = "A";

console.log(arr.length); // 4
2. Giảm length sẽ cắt bớt mảng
let fruits = ["Apple", "Orange", "Plum"];
fruits.length = 2;
console.log(fruits);        // ["Apple", "Orange"]
console.log(fruits.length); // 2
3. Tăng length tạo các ô trống
let arr = ["A", "B"];

arr.length = 5;

console.log(arr.length); // 5
console.log(arr[2]);     // undefined
console.log(2 in arr);   // false
Mảng có length bằng 5 nhưng các index 2 ,3,4, là các ô trống không phải các phần từ được gán undefined
4. length không phải số phần tử thực sự được gán
Nếu gán 1 phần từ tại index bằng 10 , length sẽ thành 11 , dù những index trước đó có thể đang trống

Bài tập :
let arr = ["A", "B", "C", "D"];

arr.length = 2;

console.log(arr);
console.log(arr.length);
console.log(arr[2]);

7. A word about "length"
├── length = index lớn nhất + 1 (khi gán phần tử theo index)
├── Giảm length → xóa các phần tử vượt quá độ dài mới
├── Tăng length → tạo các ô trống
└── arr.length = n → length chính xác bằng n

Mục 8 — new Array()
Có 2 cách tạo mảng [] hoặc new Array() . Nhưng new Array() có 1 sô trương hợp dễ gây nhầm lẫn khi truyền vào 1 số duy nhất
1. Khởi tạo bằng []
let arr = [3, 5, 8];

console.log(arr);        // [3, 5, 8]
console.log(arr.length); // 3
Các giá trị bên trong [] chính là những phần tử của mảng
2. Khởi tạo bằng new Array()
Nếu truyền nhiều giá trị chúng trở thành các phần từ 
let arr = new Array(3,5,8)
console.log(arr);        // [3, 5, 8]
console.log(arr.length); // 3
Nhưng nếu chỉ truyền 1 số dương , JS hiểu đó là độ dài mảng cần được tạo 
let arr = new Array(3);

console.log(arr.length); // 3
console.log(arr[0]);     // undefined
console.log(0 in arr);   // false
3. So sánh để tránh nhầm
let a = [3];
let b = new Array(3);

console.log(a.length); // 1
console.log(b.length); // 3

Bìa tập :
let a = [5];
let b = new Array(5);

console.log(a.length); // 1
console.log(b.length); // 5
console.log(0 in a);   // true
console.log(0 in b);   // false

Mục 9 — Multidimensional arrays
Multidimensional array là mảng chứa các mảng khác . Cách này thường dùng để biểu diễn dạng mảng , ma trận hoắc lưới
1. Khai báo mảng hai chiều
let matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];

2. Truy cập phần tử bằng hai index
console.log(matrix[0]);    // [1, 2, 3]
console.log(matrix[0][1]); // 2
console.log(matrix[2][0]); // 7

matrix[0] lấy hàng đầu tiên
matrix[0][1] lấy hàng đầu tiên và phân tử index bằng 1
matrix[2][0] lấy hàng thứ 2 và index bằng 0
Bài tập thực hành:
let matrix = [
    ["A", "B"],
    ["C", "D"],
    ["E", "F"]
];

console.log(matrix[0][0]);
console.log(matrix[1][1]);
console.log(matrix[2][0]);
console.log(matrix[0]);
Bài tập 2 — Mảng lồng nhau
let arr = [
    [10, 20],
    [30, 40]
];

arr[0][1] = 99;

console.log(arr[0]);
console.log(arr[1][0]);
console.log(arr[0][1]);

9. Multidimensional arrays
├── Mảng có thể chứa các mảng khác
├── arr[row]       → lấy mảng con
├── arr[row][col]  → lấy phần tử trong mảng con
└── Gán arr[row][col] = value
    └── Thay đổi phần tử trong mảng gốc

let arr = [1, 2, 3];

console.log(arr.toString()); // "1,2,3"

let fruits = ["Apple", "Orange", "Plum"];

console.log(fruits.toString());
// "Apple,Orange,Plum"
3. Mảng lồng nhau
 let arr = [[1, 2], [3, 4]];

console.log(arr.toString()); // "1,2,3,4"

- Mảng con [3, 4] chuyển thành "3,4".
- Hai kết quả được nối lại bằng dấu phẩy.

Mục 11 — Don't compare arrays with ==
1. Hai mảng có nội dung giống nhau nhưng vẫn khác nhau
let a = [];
let b = [];

console.log(a == b);  // false
console.log(a === b); // false
a và b được tạo riêng biệt tức là 2 object khác nhau trong bộ nhớ 
2. Hai biến cùng tham chiếu một mảng
let a = [];
let b = a;

console.log(a == b);  // true
console.log(a === b); // true
b=a không tạo ra mảng mới . Cả hai biến cùng tham chiếu đến 1 mảng
3. Đừng nhầm so sánh mảng với so sánh số
console.log([] == []);       // false
console.log([1, 2] == [1, 2]); // false

Bài tiếp theo: getMaxSubSum(arr) — tìm tổng lớn nhất của một đoạn phần tử liên tiếp trong mảng.
getMaxSubSum([-1, 2, 3, -9]); // 5
getMaxSubSum([2, -1, 2, 3, -9]); // 6
getMaxSubSum([-1, -2, -3]); // 0

| Phần tử vừa đọc | `currentSum` | `maxSum` |
| --------------- | ------------ | -------- |
| `2`             | ?    2       | ?     2  |
| `-1`            | ?  1         | ?    2   |
| `2`             | ?    3       | ?    3   |
currentSum là tổng đang xet
maxSum là tổng đã tìm thấy
2 2 2
-1 1 2
2 3 3

[2, -5, 3, 4]
2  2  2
-5 -3 2
3  3 3
4  7 7


Tại sao?
- Đọc 2: currentSum = 2, maxSum = 2.
- Đọc -5: currentSum = 2 + (-5) = -3.
- Đọc 3: vì tổng hiện tại -3 âm, bỏ đoạn cũ và bắt đầu lại từ 3. Do đó currentSum = 3.
- Đọc 4: currentSum = 3 + 4 = 7.
Vậy tổng lớn nhất là 7, tương ứng đoạn [3, 4].
