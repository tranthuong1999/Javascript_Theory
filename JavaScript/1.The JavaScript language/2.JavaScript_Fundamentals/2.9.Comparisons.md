Mục 1 — Boolean is the result
1.1. Khái niệm
Các toán tử so sánh trả về một trong hai giá trị Boolean: true hoặc false 
| Toán tử | Ý nghĩa                  | Ví dụ      | Kết quả |
| ------- | ------------------------ | ---------- | ------- |
| `>`     | Lớn hơn                  | `5 > 3`    | `true`  |
| `<`     | Nhỏ hơn                  | `2 < 1`    | `false` |
| `>=`    | Lớn hơn hoặc bằng        | `5 >= 5`   | `true`  |
| `<=`    | Nhỏ hơn hoặc bằng        | `3 <= 2`   | `false` |
| `==`    | Bằng, có chuyển đổi kiểu | `5 == "5"` | `true`  |
| `!=`    | Khác, có chuyển đổi kiểu | `5 != "5"` | `false` |
Phân biệt quan trọng :
=   là phép gán giá trị.
==  là phép so sánh bằng có thể chuyển đổi kiểu.
=== là phép so sánh bằng không chuyển đổi kiểu.

Mục 2 — String comparison (So sánh chuỗi)
2.1. Khái niệm
STRING COMPARISON

1. So sánh từng ký tự từ trái sang phải.
2. Nếu hai ký tự khác nhau, quyết định kết quả ngay tại vị trí đó.
3. Nếu một chuỗi là phần đầu của chuỗi kia, chuỗi dài hơn được xem là lớn hơn.
4. Chữ hoa và chữ thường có thứ tự Unicode khác nhau.

Ví dụ:
"Glow" > "Glee" // true, vì 'o' > 'e'
"Bee" > "Be"     // true, vì chuỗi thứ nhất dài hơn
"a" > "A"        // true

Mục 3. Comparison of different types
Khi so sánh 2 kiểu dữ liệu khác nhau JavaScript có thể tự chuyển đổi kiểu trước khi so sánh
Quy tắc cần nhớ:
khi so sánh string vói string thì so sánh theo mã unicode
So sánh các kiểu khác nhau >, <, >=, <= thì chuyển về number
Dùng == có thể chuyển kiểu dữ liệu truóc khi so sánh
console.log('2' > 1);    // true
console.log('01' == 1);  // true
console.log(true == 1);  // true
console.log(false == 0); // true
Giải thích:
- '2' > 1: chuỗi '2' được chuyển thành số 2, nên 2 > 1 là true.
- '01' == 1: chuỗi '01' được chuyển thành số 1, nên kết quả là true.
- true == 1: true được chuyển thành 1.
- false == 0: false được chuyển thành 0.
  
* Bài tập :
console.log('5' > 3);
console.log('10' < '2'); 
<!-- so sánh 2 string thì so sánh kí tự  -->
console.log(true == 1);

Mục 4. Strict equality (===)
=== là toán tử so sánh nghiêm ngặt: hai giá trị phaỉ cungf kiểu dữ liệu và bằng nhau về giá trị 
| Toán tử | Ý nghĩa                                |
| ------- | -------------------------------------- |
| `==`    | So sánh bằng, có thể chuyển đổi kiểu   |
| `===`   | So sánh bằng, không tự chuyển đổi kiểu |

console.log(1 == "1");  // true
console.log(1 === "1"); // false
console.log(0 == false);  // true
console.log(0 === false); // false

console.log(5 === 5); // true
3. Khi nào dùng?
Nên ưu tiên sử dụng === và !== để hạn chế lỗi do chuyển dữ liệu ngoài ý muốn

Mục 5.1. Strange result: null vs 0
console.log(null > 0);  // false
console.log(null == 0); // false
console.log(null >= 0); // true

1. So sánh bằng ==
JavaScript quy định null không bằng 0 khi dùng ==. Đây là quy tắc đặc biệt, không phải phép chuyển đổi thông thường.
2. So sánh lớn hơn >
 console.log(null > 0); // false
 Khi dùng toán tử so sánh lớn/nhỏ, null được chuyển thành số 0.
3. So sánh lớn hơn hoặc bằng >=
console.log(null >= 0); // true
null == 0   → false
null > 0    → false  (null chuyển thành 0)
null >= 0   → true   (null chuyển thành 0)
Bài tập :
console.log(null <= 0); true
console.log(null < 0); false
console.log(null == 0); false

************************************************
Mục 5.2. An incomparable undefined
Khi so sánh toán tử lớn nhỏ với undefined thì kết quả luôn false
console.log(undefined > 0);  // false
console.log(undefined < 0);  // false
console.log(undefined >= 0); // false
console.log(undefined <= 0); // false
Bởi vì nó chuyển undefined thành NaN mà NaN k thể tham gia so sánh => false

console.log(null >= 0);      // true
console.log(undefined >= 0); // false
null chuyển thành 0.
undefined chuyển thành NaN.
* Bài tập 
console.log(undefined == null);
console.log(undefined === null);
console.log(undefined > 1);
undefined == null → true vì quy tắc đặc biệt của ==.
undefined === null → false vì khác kiểu dữ liệu.
undefined > 1 → false vì undefined chuyển thành NaN.

Mục 6. Avoid problems
1. Ưu tiên === thay vì ==
console.log(0 == false);  // true
console.log(0 === false); // false
Có thể tự động chuyển đổi kiểu khiến kết quả không như mong đợi 
2. Cẩn thận khi so sánh null và undefined
console.log(null == undefined); // true
console.log(null >= 0);          // true
console.log(null == 0);          // false
3. Đừng mặc định mọi phép so sánh đều chuyển sang số
console.log("10" > 2);   // true
console.log("10" > "2"); // false
Recap : 
1. Ưu tiên === và !==
2. null, undefined có quy tắc đặc biệt
3. String + String khi so sánh → Unicode
4. String + Number khi so sánh số → chuyển String thành Number
