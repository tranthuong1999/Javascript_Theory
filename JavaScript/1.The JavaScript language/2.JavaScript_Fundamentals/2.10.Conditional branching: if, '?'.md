2. Học mục 1 — The “if” statement
   If là gì ?
if dùng để kiểm tra điều kiện và thực thi code khi điều kiện đúng
Syxtax: 
if (condition) {
  // Chạy khi condition là true
}

******************************************************************************

Mục 2 — Boolean conversion
1. Khái niệm
Câu lệnh if không bắt buộc là true hay false nó sẽ tự động chuyển thành boolean
| Giá trị     | Boolean | Ghi nhớ                   |
| ----------- | ------- | ------------------------- |
| `0`         | `false` | Số 0                      |
| `""`        | `false` | Chuỗi rỗng                |
| `null`      | `false` | Không có giá trị          |
| `undefined` | `false` | Chưa được gán giá trị     |
| `NaN`       | `false` | Giá trị số không hợp lệ   |
| `1`, `-1`   | `true`  | Số khác 0                 |
| `"0"`       | `true`  | Chuỗi không rỗng          |
| `"false"`   | `true`  | Chuỗi không rỗng          |
| `[]`        | `true`  | Mảng, kể cả mảng rỗng     |
| `{}`        | `true`  | Object, kể cả object rỗng |

Falsy: 0, -0, "", null, undefined, NaN, false.
Truthy: Hầu hết giá trị còn lại, bao gồm "0", "false", [] và {}.

* Mục 5 — Conditional operator ?
Toán tử điều kiện ? dùng để chọn một trong hai giá trị dựa trên điều kiện. Nó thường được gọi là ternary operator vì có 3 thành phần.
condition ? valueIfTrue : valueIfFalse;
