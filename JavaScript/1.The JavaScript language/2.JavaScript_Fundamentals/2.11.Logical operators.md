2.1. || dùng để làm gì?
|| là toán tử hoặc để kiểm tra ít nhất 1 điều kiện có đúng hay không
2.2. || không chỉ dùng với Boolean
Trong JavaScript, các giá trị không phải Boolean sẽ được xét theo quy tắc truthy/falsy.
if (1 || 0) {
  console.log("Hello");
}

1 là truthy.
0 là falsy.
1 || 0 có kết quả truthy nên in Hello.
let a = 0;
let b = "JavaScript";

if (a || b) {
  console.log("A");
} else {
  console.log("B");
}

→ Trả về giá trị truthy đầu tiên.
→ Nếu tất cả đều falsy, trả về giá trị cuối cùng.
→ Dừng ngay khi tìm thấy giá trị truthy đầu tiên.

6. Mục 3 — && (AND)

Recap :
A || B → tìm giá trị truthy đầu tiên.
A && B → tìm giá trị falsy đầu tiên.

10. Mục 5 — ! (NOT)
! là toán tử phủ định : đảo ngược giá trị của 1 biểu thức
10.1. Cách hoạt động
console.log(!true);  // false
console.log(!false); // true
Với giá trị không pahir boolean thí nó chuyển về boolean sau đó nó đảo ngược 
console.log(!0);        // true
console.log(!"React");  // false
console.log(!"");       // true
console.log(!null);     // true
Giải thích:
- 0 là falsy → !0 thành true.
- "React" là truthy → !"React" thành false.
- "" là falsy → !"" thành true.
- null là falsy → !null thành true.
10.2 !! chuyển giá trị thành boolean
console.log(!!"React"); // true
console.log(!!0);       // false
console.log(!!null);    // false
10.3. Case dễ nhầm 

console.log(!"0");  // false
console.log(!!"0"); // true
console.log(!0);    // true
Bài tập 
let a = "";
let b = "0";

console.log(!a); true 
console.log(!!b); true
console.log(!b);false

Bài tập:
alert(alert(1) || 2 || alert(3));
Phân tích từng bước:
1. alert(1) chạy trước → hiển thị 1.
2. Hàm alert() trả về undefined, không phải 1.
3. undefined là falsy, nên || xét tiếp giá trị 2.
4. 2 là truthy, nên || dừng tại đây. alert(3) không chạy.
5. alert() bên ngoài nhận giá trị 2 → hiển thị 2.

alert(alert(1) && alert(2));
<!-- 1 undefined -->
alert(null || 2 && 3 || 4);

Task chính thức 6/9 — Check the range between
Nguồn: đề gốc javascript.info, dòng 342–352. 

javascript.info



Đề bài: Viết điều kiện if để kiểm tra age nằm trong khoảng từ 14 đến 90, bao gồm cả hai mốc 14 và 90.
Ví dụ:
- age = 14 → điều kiện đúng.
- age = 50 → điều kiện đúng.
- age = 90 → điều kiện đúng.
- age = 13 hoặc age = 91 → điều kiện sai.
Hãy tự viết dòng code if (...) hoàn chỉnh nhé. Chưa cần viết phần thân {}.
if( age === 13 || age === 91 ) return false;
return true

Trong khoảng:
age >= 14 && age <= 90

Ngoài khoảng:
age < 14 || age > 90

Task chính thức 9/9 — Check the login
Nguồn: javascript.info/logical-operators#tasks
Đây là Task cuối cùng của bài Logical operators.
Đề gốc yêu cầu viết code kiểm tra đăng nhập với các quy tắc:
- Nếu prompt nhập "Admin" → yêu cầu nhập mật khẩu.
- Nếu người dùng nhấn Cancel → hiển thị "Canceled".
- Nếu tên đăng nhập không phải "Admin" → hiển thị "I don't know you".
- Mật khẩu là "TheMaster" → hiển thị "Welcome!".
- Mật khẩu sai → hiển thị "Wrong password".
- Nếu nhấn Cancel ở bước nhập mật khẩu → hiển thị "Canceled".


let userName = prompt("Who's there?");

if (userName === "Admin") {
  let password = prompt("Password?");

  if (password === "TheMaster") {
    alert("Welcome!");
  } else if (password === null || password === "") {
    alert("Canceled");
  } else {
    alert("Wrong password");
  }
} else if (userName === null || userName === "") {
  alert("Canceled");
} else {
  alert("I don't know you");
}

RECAP

&&  → Trả về giá trị falsy đầu tiên.
!   → Đảo kết quả Boolean.
!!  → Chuyển giá trị thành Boolean.
&&  → Có độ ưu tiên cao hơn ||.
