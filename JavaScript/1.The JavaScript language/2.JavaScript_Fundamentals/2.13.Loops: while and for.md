Mục 1 — The while loop
1.1. Vòng lặp while là gì?
while dùng để lặp lại 1 đoạn code khi điều kiện còn đúng
let i = 0;

while (i < 3) {
  console.log(i);
  i++;
}
1.3. Ba điểm cần nhớ
while kiểm tra điều kiện trước khi chạy phần thân
Mỗi lần chạy phần thân được gọi là một iteration (một lượt lặp).
- Nếu quên cập nhật biến điều kiện, vòng lặp có thể chạy vô hạn.
let i = 3;

while (i) {
  console.log(i);
  i--;
}
Kết quả là 3, 2, 1. Khi i giảm xuống 0, điều kiện while (i) trở thành falsy nên vòng lặp dừng.

let i = 1;

while (i <= 3) {
  console.log(i);
  i++;
}

i = 1: đúng → in 1, tăng lên 2.
i = 2: đúng → in 2, tăng lên 3.
i = 3: đúng → in 3, tăng lên 4.
i = 4: sai (4 <= 3 là false) → thoát vòng lặp.

Mục 2 — The do...while loop
Cú pháp: 
do {
  // Code được thực thi
} while (condition);

let i = 5;

while (i < 3) {
  console.log("while:", i);
}

do {
  console.log("do...while:", i);
} while (i < 3);
Result : do...while: 5

### So sánh nhanh

| Vòng lặp     | Cách hoạt động                     | Số lần chạy tối thiểu    |
| ------------ | ---------------------------------- | ------------------------ |
| `while`      | Kiểm tra điều kiện trước khi chạy. | Có thể chạy 0 lần.       |
| `do...while` | Chạy trước rồi mới kiểm tra.       | Luôn chạy ít nhất 1 lần. |

Bài tập :

let count = 10;

do {
  console.log(count);
  count++;
} while (count < 5);

Mục 3 — The for loop

for (begin; condition; step) {
  // loop body
}

for (let i = 0; i < 3; i++) {
  console.log(i);
}
1. let i = 0       → Khởi tạo
2. i < 3           → true
3. console.log(i)  → In 0
4. i++             → i = 1
5. i < 3           → true
6. console.log(i)  → In 1
7. i++             → i = 2
8. i < 3           → true
9. console.log(i)  → In 2
10. i++            → i = 3
11. i < 3          → false → Dừng

Mục 4 — Breaking the loop (break)
Break dùng để thoát vòng lặp ngay lập tức ngay cả khi điều kiện đúng
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    break;
  }

  console.log(i);
}
1
2
Bài tập :
for (let i = 1; i <= 5; i++) {
  if (i === 4) {
    break;
  }

  console.log(i);
}

console.log("Done");
- i = 1, 2, 3: điều kiện i === 4 sai nên in các số tương ứng.
- i = 4: điều kiện đúng, break thoát khỏi vòng lặp ngay lập tức.
- Sau vòng lặp, chương trình tiếp tục chạy console.log("Done"), nên "Done" vẫn được in.

Mục 5 — continue: Bỏ qua lượt lặp hiện tại
continue khiến vòng lặp bỏ qua phần còn lại của lượt hiện tại và chuyển sang lượt tiếp theo.
1. Cách sử dụng
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue;
  }

  console.log(i);
}
i = 1, 2: điều kiện sai → chạy console.log(i).
i = 3: điều kiện đúng → continue bỏ qua console.log(i).
i = 4, 5: tiếp tục in bình thường.
| Toán tử    | Tác dụng                                |
| ---------- | --------------------------------------- |
| `break`    | Thoát khỏi vòng lặp hiện tại            |
| `continue` | Bỏ qua lượt hiện tại, tiếp tục vòng lặp |

let i = 0;

while (i < 5) {
  if (i === 2) continue;
  console.log(i);
  i++;
}
Khi i === 2, continue khiến chương trình quay lại kiểm tra i < 5 mà không tăng i. Điều kiện luôn đúng nên vòng lặp bị mắc kẹt tại 2.

for (let i = 1; i <= 5; i++) {
  if (i === 2) {
    continue;
  }

  if (i === 4) {
    break;
  }

  console.log(i);
}

console.log("End");

 6.1. Vấn đề khi có vòng lặp lồng nhau

 for (let i = 1; i <= 3; i++) {

    if (j === 2) {
      break;
    }
    console.log(i, j);
  }
}

3 1

| `i` | `j` | `j === 2` | Hành động          |
| --- | --- | --------- | ------------------ |
| 1   | 1   | `false`   | In `1 1`           |
| 1   | 2   | `true`    | `break` vòng trong |
| 2   | 1   | `false`   | In `2 1`           |
| 2   | 2   | `true`    | `break` vòng trong |
| 3   | 1   | `false`   | In `3 1`           |
| 3   | 2   | `true`    | `break` vòng trong |
Điểm cần nhớ: break không làm chương trình thoát cả hai vòng lặp. Nó chỉ thoát vòng trong, nên vòng ngoài vẫn tiếp tục với i = 2, rồi i = 3.

* continue outer khác continue thông thường ở điểm nào?

*****************************************************************************
RECAP
| Cấu trúc                       | Quy tắc                                                                |
| ------------------------------ | ---------------------------------------------------------------------- |
| `while (condition)`            | Kiểm tra trước, có thể chạy 0 lần.                                     |
| `do...while (condition)`       | Chạy trước, luôn chạy ít nhất 1 lần.                                   |
| `for (begin; condition; step)` | Khởi tạo một lần; kiểm tra trước mỗi lượt; cập nhật sau thân vòng lặp. |
| `break`                        | Thoát vòng lặp gần nhất.                                               |
| `continue`                     | Bỏ phần còn lại của lượt hiện tại.                                     |
| `break outer`                  | Thoát vòng lặp được gắn nhãn `outer`.                                  |
| `continue outer`               | Chuyển sang lượt tiếp theo của vòng `outer`.                           |
3. Những case dễ nhầm
   
let i = 0;
while (++i < 3) console.log(i);
// 1, 2
let i = 0;
while (i++ < 3) console.log(i);
// 1, 2, 3
Trong điều kiện, ++i tăng trước rồi trả về giá trị mới; i++ trả về giá trị cũ rồi mới tăng. Vì vậy, hai vòng trên cho kết quả khác nhau.
Case C — continue trong while
Nếu bỏ qua phần tăng biến bằng continue, vòng lặp có thể bị vô hạn. Hãy đảm bảo biến điều kiện vẫn được cập nhật.
