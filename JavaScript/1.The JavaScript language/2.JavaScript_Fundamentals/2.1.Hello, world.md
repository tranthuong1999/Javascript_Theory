* Mục 1 — The <script> tag
Định nghĩa: Thẻ <script> cho phép chúng ta đưa mã JavaScript vào tài liệu HTML để trình duyệt thực thi.
<!DOCTYPE html>
<html>
<body>
  <p>Before the script...</p>

  <script>
    alert("Hello, world!");
  </script>

  <p>After the script...</p>
</body>
</html>

HTML: xác định cấu trúc nội dung trang web.
JavaScript: thêm hành vi và xử lý logic cho trang web.
<script>: kết nối mã JavaScript với tài liệu HTML.
Mục 2 — Modern markup
 Type là thuộc tính của javascript dùng để xác định loại script hoặc cách trình duyệt xử lý script đó 
 ./file.js       → thư mục hiện tại
./js/file.js    → thư mục con js
/js/file.js     → từ gốc website
