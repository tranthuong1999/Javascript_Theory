* Mục 1 — The syntax

1. switch dùng để làm gì?
switch dùng để so sánh với nhiều giá trị khác nhau giúp code dễ đọc hơn tránh if else nhiều

* Mục 2 — An example

let x = 2;

switch (x) {
    case 1:
        console.log("A");
        break;

    case 2:
        console.log("B");

    case 3:
        console.log("C");
        break;

    default:
        console.log("D");
}
* Mục 3 — Grouping of case
let fruit = "banana";

switch (fruit) {
    case "apple":
    case "banana":
    case "orange":
        console.log("This is a fruit");
        break;

    case "carrot":
        console.log("This is a vegetable");
        break;

    default:
        console.log("Unknown");
}
* Mục 4 — Type matters,
Như đã học ở mục 1, switch so sánh giá trị bằng === (strict equality). Vì vậy, hai giá trị có cùng nội dung nhưng khác kiểu dữ liệu vẫn có thể không khớp.

1. switch phân biệt kiểu dữ liệu
2. Không tự động chuyển đổi kiểu

Bài tập thực hành

let x = "1";

switch (x) {
    case true:
        console.log("A");
        break;

    case 1:
        console.log("B");
        break;

    case "1":
        console.log("C");
        break;

    default:
        console.log("D");
}
