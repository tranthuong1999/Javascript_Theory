Mục 1 — Function Declaration
1. Hàm là gì?
Hàm là 1 khối code đựoc đặt tên có thể gọi khi cần thực hiện  giúp tái sử code và tránh lặp lại 
function sayHello() {
    console.log("Hello");
}
Đoạn này chỉ khai báo hàm chưa làm gì cả
### 3. Phân biệt khai báo và gọi hàm

| Code                     | Ý nghĩa                          |
| ------------------------ | -------------------------------- |
| `function sayHello() {}` | Khai báo hàm                     |
| `sayHello()`             | Gọi hàm                          |
| `sayHello`               | Tham chiếu đến hàm, chưa gọi hàm |
4. Bài tập tự tạo — Mục 1
function greet() {
    console.log("Hello");
}

console.log("Start");
greet();
console.log("End");

Mục 2 — Local variables (Biến cục bộ)
Một biến được khai báo trong hàm chỉ có thể được truy cập từ trong hàm đó
function showMessage() {
    let message = "Hello, JavaScript!";

    console.log(message);
}

showMessage();       // Hello, JavaScript!
console.log(message); // ReferenceError

Local variables — Biến cục bộ

- Biến khai báo bên trong hàm chỉ truy cập được trong phạm vi của hàm.
- Gọi hàm không làm biến cục bộ trở thành biến toàn cục.
- Truy cập biến cục bộ từ bên ngoài sẽ gây ReferenceError.

Mục 3 — Outer variables (Biến bên ngoài hàm)

Hàm có thể truy cập các biến được khai báo bên ngoài nó. Nếu biến đó tồn tại trong phạm vi mà hàm nhìn thấy, hàm có thể đọc và đôi khi thay đổi giá trị của biến đó.
1. Đọc biến bên ngoài hàm
   
let userName = "Martin";

function showMessage() {
    let message = "Hello, " + userName;
    console.log(message);
}

showMessage();
2. Thay đổi biến bên ngoài hàm
let userName = "Martin";

function changeName() {
    userName = "Alex";
}

changeName();
console.log(userName);
Return : Alex
3. Dễ nhầm: Khai báo lại biến bên trong hàm

let userName = "Martin";

function showMessage() {
    let userName = "Alex";
    console.log(userName);
}

showMessage();
console.log(userName);
* Chú ý : 
userName = "Alex";      // Gán lại biến bên ngoài nếu biến đó đang được tham chiếu
let userName = "Alex";  // Khai báo biến cục bộ mới nếu nằm trong phạm vi hàm
Bài tập thực hành :

let count = 5;

function test() {
    count = 10;
    let message = "Hello";
    console.log(count);
}

test();
console.log(count);
console.log(message);

Outer variables — Biến bên ngoài hàm

- Hàm có thể đọc biến được khai báo bên ngoài.
- Gán lại biến bên ngoài sẽ làm thay đổi giá trị của biến đó.
- Khai báo let cùng tên bên trong hàm tạo biến cục bộ riêng.
- Biến cục bộ không thể truy cập từ bên ngoài hàm.

* Mục 4 — Parameters (Tham số)
Trong 1 hàm , parameters là các biến được khai báo trong phần định nghĩa hàm để nhận dữ liệu đầu vào 
function showMessage(from, text) {
    console.log(from + ": " + text);
}

showMessage("Martin", "Hello!");
from, text: parameters (tham số).
"Martin", "Hello!": arguments (đối số).
Khi gọi hàm đối số được gán cho tham số theo thứ tự 

* 4.1. Tham số nhận bản sao giá trị
  Khi truyền giá trị vào hàm js gán gía trị đó cho biến tham số cục bộ . Vì vậy thay đổi tham số không làm thay đổi biến bên ngoài 
  nếu giá trị đó là nguyên thuỷ như string , number và boolean

function showMessage(from, text) {
    from = "*" + from + "*";
    console.log(from + ": " + text);
}

let from = "Ann";

showMessage(from, "Hello");
console.log(from);
from bên ngoài đang là "Ann".
Khi gọi hàm, tham số from nhận bản sao giá trị "Ann".
Gán lại from bên trong chỉ thay đổi tham số cục bộ.
Biến from bên ngoài vẫn giữ "Ann"
* Tức là thay đổi bên trong không ảnh hưởng tới bên ngoài 

Baì tập thưc hành :

function calculate(a, b) {
    a = a + 5;
    console.log(a + b);
}

let x = 10;
let y = 3;

calculate(x, y);

console.log(x);
console.log(y);

Mục 5 — Default values (Giá trị mặc định)

5.1. Khi không truyền đối số
Nếu gọi hàm mà không cung cấp tham số thì tham số mặc định nhận undefined
5.2. Khai báo giá trị mặc định bằng =
function showMessage(from, text = "No text given") {
    console.log(from + ": " + text);
}

showMessage("Martin");
showMessage("Martin", "Hello!");

function greet(name = "Guest") {
    console.log(name);
}

greet();          // Guest
greet(undefined); // Guest
greet("Martin");  // Martin
greet(null);      // null
Chú ý : null k kích hoạt được giá trị mặc định 
5.3. Giá trị mặc định có thể là một lời gọi hàm
giá trị mặc định có thể là biểu thức phức tạp hoặc kết quả của một hàm
function getDefaultName() {
    console.log("Getting default name...");
    return "Guest";
}

function greet(name = getDefaultName()) {
    console.log("Hello, " + name);
}

greet("Martin");
greet();

Lần gọi đầu tiên không chạy getDefaultName() vì đã có đối số "Martin".
5.4. Phân biệt ||, ?? và giá trị mặc định

Bài tập thưc hành:

function test(a = 5, b = 10) {
    console.log(a, b);
}

test(); 5, 10
test(2); 2, 10
test(undefined, 7); 5 7
test(null, 0); null 0
Tham số mặc định:
- Bỏ qua đối số        → dùng giá trị mặc định
- Truyền undefined     → dùng giá trị mặc định
- Truyền null          → giữ null
- Truyền 0 hoặc false  → giữ nguyên giá trị
- Truyền chuỗi rỗng "" → giữ nguyên chuỗi rỗng

Mục 6 — Returning a value (Giá trị trả về)
return dùng để trả kết quả từ bên trong hàm ra nơi gọi hàm.
function sum(a, b) {
    return a + b;
}

let result = sum(3, 5);

console.log(result); // 8
6.3. return kết thúc hàm ngay lập tức
Khi chạy đến return hàm kết thúc ngay 
function checkAge(age) {
    if (age < 18) {
        return "Too young";
    }

    return "Allowed";
}

console.log(checkAge(16)); // Too young
console.log(checkAge(20)); // Allowed
6.4. return không có giá trị
Sẽ kết thúc hàm bằng undefined giống như hàm không có return;
function test() {
    return;
    console.log("Hello");
}

console.log(test());
6.5. Lỗi dễ nhầm: xuống dòng sau return
function sum(a, b) {
    return
        a + b;
}

console.log(sum(2, 3)); // undefined
RETURNING A VALUE
- return value: trả giá trị về nơi gọi hàm.
- return kết thúc hàm ngay lập tức.
- Không có return hoặc return không có giá trị → undefined.
- console.log() chỉ hiển thị, không thay thế return.
- Viết biểu thức cùng dòng với return để tránh lỗi tự chèn dấu chấm phẩy.
Bài tập thực hành :

function calculate(a, b) {
    console.log("Start");

    if (a > b) {
        return a - b;
    }

    console.log("Continue");
    return a + b;
}

let result = calculate(8, 3);
console.log(result);

Mục 7 — Naming a function (Đặt tên hàm)
7.1. Tên hàm nên mô tả hành động
Hàm thường thực hiện 1 hành động vì vậy têm hàm thường bắt đầu bằng 1 động từ 
function showMessage() {
    console.log("Hello!");
}

function getAge() {
    return 25;
}

function calcSum(a, b) {
    return a + b;
}

function checkPermission() {
    return true;
}
Ý ngĩa : 
showMessage: hiển thị thông báo.
getAge: lấy hoặc trả về tuổi.
calcSum: tính tổng.
checkPermission: kiểm tra quyền và trả về kết quả đúng/sai.
7.2. Quy ước tiền tố tên hàm
#### 7.2. Quy ước tiền tố tên hàm
| Tiền tố     | Ý nghĩa thường gặp                        | Ví dụ               |
| ----------- | ----------------------------------------- | ------------------- |
| `show...`   | Hiển thị thứ gì đó                        | `showMessage()`     |
| `get...`    | Lấy hoặc trả về giá trị                   | `getAge()`          |
| `calc...`   | Tính toán                                 | `calcSum()`         |
| `create...` | Tạo thứ gì đó                             | `createForm()`      |
| `check...`  | Kiểm tra điều kiện, thường trả về boolean | `checkPermission()` |
7.3. Một hàm — một hành động
Tên hàm phải phản ánh đúng việc hàm thực sự làm

Bài tập thực hành:
function getUserName() {
    return "Martin";
}

function showTotal(a, b) {
    return a + b;
}

function calcPrice(price, quantity) {
    return price * quantity;
}

Hàm nào có tên không phản ánh đúng hành động
Hàm showTotal tôi nghĩ nên đôi thành calcTotal

8.2. Tách thành các hàm nhỏ

Mục tiêu là không phải tạo thật nhiều hàm , mà chia code thành những phần có nhiệm vụ rõ ràng

FUNCTIONS == COMMENTS

- Một hàm nên ngắn gọn và tập trung vào một nhiệm vụ.
- Tách phần xử lý phức tạp thành hàm nhỏ khi giúp code dễ hiểu hơn.
- Tên hàm tốt cho người đọc biết đoạn code làm gì.
- Không cần thêm comment để diễn giải điều mà tên hàm đã thể hiện rõ.
- Không tách hàm một cách máy móc; ưu tiên khả năng đọc hiểu và bảo trì.
  
Bài tập thực hành:

function processOrder(price, quantity) {
    const total = price * quantity;

    if (total > 1000) {
        console.log("Large order");
    }

    console.log("Total:", total);
}
Tách hàm như sau 

functio caculateTotal(price, quantity){
    return price * quantity;
}

function checkOrderSize(total) {
    if (total > 1000) {
        console.log("Large order");
    }
}

function processOrder(price, quantity) {
    const total = calculateTotal(price, quantity);

    checkOrderSize(total);

    console.log("Total:", total);
}

processOrder(300, 4);

## 2. Hiểu nhiệm vụ từng hàm

| Hàm                | Nhiệm vụ                              | Giá trị trả về                                        |
| ------------------ | ------------------------------------- | ----------------------------------------------------- |
| `calculateTotal()` | Tính tổng tiền                        | `price * quantity`                                    |
| `checkOrderSize()` | Kiểm tra đơn hàng có trên 1.000 không | Không trả giá trị cụ thể, nên mặc định là `undefined` |
| `processOrder()`   | Điều phối quá trình xử lý đơn hàng    | Không trả giá trị cụ thể                              |

FUNCTIONS — JAVASCRIPT.INFO

1. Khai báo và gọi hàm
   function greet(name) { ... }
   greet("Martin");

2. Local variables
   - Biến khai báo trong hàm chỉ truy cập được trong phạm vi của nó.

3. Outer variables
   - Hàm có thể đọc hoặc thay đổi biến bên ngoài.
   - Biến cục bộ cùng tên sẽ che khuất biến bên ngoài.

4. Parameters và arguments
   - Parameter: tên biến trong khai báo hàm.
   - Argument: giá trị truyền khi gọi hàm.
   - Tham số nhận giá trị được truyền vào; gán lại tham số không làm đổi biến primitive bên ngoài.

5. Default values
   - Bị bỏ qua hoặc truyền undefined → dùng giá trị mặc định.
   - null, 0, false, "" → giữ nguyên.

6. return
   - Trả kết quả về nơi gọi hàm.
   - Kết thúc hàm ngay khi thực thi.
   - Không return giá trị → kết quả undefined.
   - console.log() hiển thị kết quả, không thay thế return.

7. Naming a function
   - Tên hàm mô tả đúng hành động.
   - show: hiển thị; get: lấy/trả về; calc: tính; create: tạo; check: kiểm tra.

8. Functions == Comments
   - Hàm nên ngắn gọn, có nhiệm vụ rõ ràng.
   - Tách hàm khi giúp code dễ đọc, kiểm thử hoặc tái sử dụng hơn.

Những điểm bạn cần nắm chắc
- Parameters: tham số nhận giá trị truyền vào; gán lại tham số primitive không làm đổi biến bên ngoài.
- Default values: dùng khi đối số bị bỏ qua hoặc là undefined, không áp dụng với null.
- Return: trả kết quả về nơi gọi hàm và kết thúc hàm ngay lập tức.
- console.log() khác return: một bên hiển thị, một bên trả giá trị.
- Đặt tên hàm: tên phản ánh đúng nhiệm vụ.
- Tách hàm: giúp code dễ đọc, dễ kiểm thử và bảo trì.
- Vòng lặp tính lũy thừa: khởi tạo result = 1, nhân x đúng n lần.
