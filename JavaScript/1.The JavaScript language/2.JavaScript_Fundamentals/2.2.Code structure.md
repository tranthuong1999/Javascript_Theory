* 1.1. Statement là gì?
Định nghĩa: Statement (câu lệnh) là một đơn vị chỉ thị mà chương trình JavaScript thực hiện.
alert("Hello"); // Statement 1
alert("World"); // Statement 2
Statement = 1 câu lệnh trong js 
let x = 10;
let y = 20;
console.log(x + y);
Có 3 statement
* Mục 2 — Semicolons (;)
Định nghĩa: Dấu ; được dùng để đánh dấu kết thúc một câu lệnh JavaScript.
Bài tập mục 2
Câu 1. Đoạn code nào an toàn và đúng với ý định trả về object từ hàm?

  {
    name: "Martin"

* Mục 3 — Comments (Chú thích)
3.1. Comment là gì?
Định nghĩa: Comment là phần chú thích trong code, giúp lập trình viên giải thích mục đích hoặc cách hoạt động của đoạn code. JavaScript sẽ bỏ qua comment khi thực thi.
| Nội dung      | Cần nhớ                                         |
| ------------- | ----------------------------------------------- |
| Statement     | Một câu lệnh JavaScript                         |
| Semicolon `;` | Phân tách/kết thúc câu lệnh; nên dùng nhất quán |
| ASI           | JavaScript tự chèn `;` trong một số trường hợp  |
| `//`          | Comment một dòng                                |
| `/* ... */`   | Comment nhiều dòng                              |
