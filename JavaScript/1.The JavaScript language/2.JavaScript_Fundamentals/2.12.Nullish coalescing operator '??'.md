2. Mục 1 — Toán tử ??
let result = value ?? defaultValue;
Nếu value khác null và undefined → lấy value.
Nếu value là null hoặc undefined → lấy defaultValue.
có thể tương đương 

result = (a !== null && a !== undefined) ? a : b;
console.log(0 ?? 100);       // 0
console.log(false ?? true);  // false
console.log("" ?? "Guest");  // ""
console.log(null ?? "Guest"); // "Guest"
console.log(undefined ?? 10); // 10

Bài tập thực hành 
let a = 0;
let b = null;
let c = "";

console.log(a ?? 10); 0
console.log(b ?? 20); 20
console.log(c ?? "Hello"); ""

4. Mục 2 — So sánh ?? với ||
   || : thay thế các gía trị bên trái là falthy
   ?? : thay thế các giá trị bên trái là null hoặc undefined

Bài tập :

let quantity = 0;
console.log(quantity || 10); 10
console.log(quantity ?? 10); 0

6. Mục 3 — Độ ưu tiên của ??
 Độ ưu tiên thấp hơn các phép toán số học và cao hơn phép gán =;

 Ex: 
let height = null;
let result = height ?? 100 * 2;

console.log(result); // 200
Bài tập thực hành 

let a = null;
let b = 5;

console.log(a ?? b * 2);
console.log((a ?? b) * 2);
**********************************************************************
8. Mục 4 — Kết hợp ?? với && hoặc ||
JavaScript không cho phép kết hợp trực tiếp ?? với && hoặc || nếu không có ngoặc

let a = null;
let b = 5;

let result = a ?? b || 10;

console.log(result);
Bài tập thực hành 

let a = 0;
let b = false;
let c = null;
let d = "";

console.log(a ?? 10); // 0
console.log(a || 10); // 10
console.log(b ?? true); // false
console.log(c ?? "Hello"); // "hell0"
console.log(d || "World"); // "World"
