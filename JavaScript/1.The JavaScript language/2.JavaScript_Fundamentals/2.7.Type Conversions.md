* Mục 1 — String Conversion (Chuyển đổi sang chuỗi)
1.1. String Conversion là gì?
Là quá trình chuyển 1 giá trị sang kiểu dữ liệu string

Có 2 trường hợp : chuyển chủ động và chuyển bị động 
1.2. Chuyển đổi tự động
alert tự truyên giá trị truyền vào thành chuỗi để hiển thị 
alert(123);       // Hiển thị "123"
alert(true);      // Hiển thị "true"
alert(null);      // Hiển thị "null"
1.3. Chuyển đổi chủ động bằng String()
let value = true;

console.log(typeof value); // "boolean"

value = String(value);

console.log(value);        // "true"
console.log(typeof value); // "string"

STRING CONVERSION

1. Mục đích: Chuyển giá trị sang kiểu string.

2. Chuyển đổi tự động:
   alert(123); // Hiển thị "123"

3. Chuyển đổi chủ động:
   String(value);

4. Ví dụ:
   const age = 25;
   const text = String(age);
   typeof age;  // "number"
   typeof text; // "string"

5. Nhớ:
   String(null)      → "null"
   String(undefined) → "undefined"
   String(true)      → "true"

Mục 2 — Numeric Conversion (Chuyển đổi sang số)

Chuyển đổi số có thể diễn ra tự động trong phép toán hoặc chủ động băng Number(value)
2.1. Chuyển đổi tự động
alert("6" / "2"); // 3

| Giá trị đầu vào | `Number(value)` | Giải thích                        |
| --------------- | --------------- | --------------------------------- |
| `undefined`     | `NaN`           | Không chuyển được thành số hợp lệ |
| `null`          | `0`             | Chuyển thành số 0                 |
| `true`          | `1`             | Boolean `true`                    |
| `false`         | `0`             | Boolean `false`                   |
| `""`            | `0`             | Chuỗi rỗng                        |
| `"   "`         | `0`             | Chuỗi chỉ chứa khoảng trắng       |
| `"123"`         | `123`           | Chuỗi số hợp lệ                   |
| `"123z"`        | `NaN`           | Chuỗi không phải số hợp lệ        |

NUMERIC CONVERSION

1. Chuyển đổi chủ động:
   Number(value);

2. Chuyển đổi tự động:
   "6" / "2" → 3

3. Quy tắc quan trọng:
   Number(undefined) → NaN
   Number(null)      → 0
   Number(true)      → 1
   Number(false)     → 0
   Number("")        → 0
   Number("  ")      → 0
   Number("123")     → 123
   Number("123z")    → NaN

4. Khi dùng prompt:
   const age = Number(prompt("Your age?", ""));
bài tập 
console.log(Number("")); 
console.log(Number("hello"));
console.log(Number(null));

Mục 3 — Boolean Conversion (Chuyển đổi sang Boolean)
3.1. Boolean Conversion là gì?
Là quá trình chuyển true hoặc false bằng Boolean(value) hoặc thông qua các ngữ cảnh 
console.log(Boolean(1));    // true
console.log(Boolean(0));    // false
console.log(Boolean("Hi")); // true

| Giá trị     | `Boolean(value)` |
| ----------- | ---------------- |
| `0`         | `false`          |
| `-0`        | `false`          |
| `""`        | `false`          |
| `null`      | `false`          |
| `undefined` | `false`          |
| `NaN`       | `false`          |

BOOLEAN CONVERSION

1. Chuyển đổi chủ động:
   Boolean(value);

2. Falsy values:
   false, 0, -0, "", null, undefined, NaN

3. Những giá trị đáng chú ý:
   Boolean("0")     → true
   Boolean("false") → true
   Boolean(" ")     → true
   Boolean([])      → true
   Boolean({})      → true

4. Trong if:
   if (value) { ... }
   JavaScript tự chuyển value thành Boolean.
