2. Mục 0 — Dynamic typing
Data type cho biết một giá trị thuộc loại nào 
DATA TYPES — DYNAMIC TYPING

1. Data type cho biết loại giá trị.
2. JavaScript có kiểu dữ liệu động.
3. Một biến có thể nhận giá trị thuộc các kiểu khác nhau.
Ví dụ:
let message = "Hello"; // string
message = 123;         // number
Lưu ý:
Kiểu dữ liệu của giá trị có thể thay đổi khi gán giá trị mới.

* Mục 1 — Number (Kiểu số)
  Number k chỉ bao gồm số nguyên , số thập phân mà còn : Infinity, -Infinity và NaN

* 1.2. Infinity và -Infinity
console.log(1 / 0);  // Infinity
console.log(-1 / 0); // -Infinity
* 1.3. NaN
  NaN : not a number biều thị kết quả phép tính k hợp lệ hoặc k xác định 
console.log("hello" / 2); // NaN
console.log(NaN + 1);     // NaN
console.log(3 * NaN);     // NaN
Lưu ý : dù tên NaN bản thân nó vẫn thuộc kiểu number
console.log(typeof NaN); // "number"

NUMBER — KIỂU SỐ
1. number bao gồm số nguyên và số thập phân.
2. Infinity: vô cực dương.
3. -Infinity: vô cực âm.
4. NaN: kết quả phép toán số không hợp lệ/không xác định.
5. typeof NaN === "number".
6. NaN thường lan truyền qua các phép toán:
   NaN + 1 → NaN
   3 * NaN → NaN
   NaN ** 0 → 1

Infinity  → typeof là "number"
-Infinity → typeof là "number"
NaN       → typeof là "number"

2.1. BigInt là gì?
BigInt là kiểu dữ liệu dùng để biểu diễn số nguyên có độ lớn vượt qua giới hạn của number 
Number.MAX_SAFE_INTEGER; // 9007199254740991
2.2. Cách khai báo BigInt
Thêm chữ n vào cuối 1 số nguyên

BIGINT
1. Dùng để biểu diễn số nguyên rất lớn.
2. Khai báo bằng cách thêm n vào cuối số nguyên:
   const bigNumber = 12345678901234567890n;
3. typeof BigInt → "bigint".
4. Không cộng/trừ/nhân/chia trực tiếp BigInt với number.
5. Chuyển đổi kiểu cần có chủ đích và phải cân nhắc độ chính xác.

Mục 3 — String (Chuỗi ký tự)
String là kiểu dữ liệu dùng để biểu diễn văn bản và có thể khai báo trong nháy đơn hoặc nháy kép
3.2. Backticks — dấu huyền ` `
Cho phép viết chuỗi nhiều dòng và nhúng biểu thức vào chuỗi
STRING — CHUỖI KÝ TỰ
1. Tạo chuỗi bằng:
   'Hello'
   "Hello"
   `Hello`

2. Dùng ' hoặc ":
   Phù hợp với chuỗi thông thường.

3. Dùng backticks:
   - Viết chuỗi nhiều dòng.
   - Nhúng biến/biểu thức bằng ${...}.

4. Ví dụ:
   const name = "Martin";
   const message = `Hello, ${name}!`;

5. JavaScript không có kiểu character riêng.
   "A" vẫn có kiểu string.

Ghi nhớ:
${...} nội suy biểu thức trong template literals
dùng backticks, không phải chuỗi nháy đơn/kép.

6.1. undefined là gì?
undedined là biến được khai báo nhưng chưa được gán giá trị 
UNDEFINED
1. Biến khai báo nhưng chưa gán:
   let age;
   console.log(age); // undefined

2. Đọc thuộc tính không tồn tại:
   const user = { name: "Martin" };
   console.log(user.age); // undefined

3. Hàm không return giá trị:
   function test() {}
   console.log(test()); // undefined

4. Kiểm tra kiểu:
   typeof undefined → "undefined"

5. Phân biệt:
   null      → Chủ động biểu thị không có giá trị.
   undefined → Giá trị chưa được xác định hoặc chưa có.

Mục 7 — Objects và Symbols

7.2. symbol — Định danh duy nhất
Symbol được dùng để tạo ra các định danh duy nhất thường dùng làm khoá thuộc tính của object

const id1 = Symbol("id");
const id2 = Symbol("id");
console.log(id1 === id2); // false
console.log(typeof id1);  // "symbol"

OBJECTS AND SYMBOLS

1. object:
   - Lưu tập hợp dữ liệu và các thuộc tính.
   - Ví dụ: const user = { name: "Martin", age: 27 };
   - Truy cập thuộc tính: user.name
2. symbol:
   - Tạo giá trị định danh duy nhất.
   - Symbol("id") !== Symbol("id")
   - typeof Symbol("id") → "symbol"
3. JavaScript có 7 kiểu dữ liệu nguyên thủy và
   1 kiểu dữ liệu không nguyên thủy là object.

Mục 8 — Toán tử typeof
8.1. typeof dùng để làm gì?
typeof là toán tử dùng để kiểm tra dữ liệu của một giá trị 
TYPEOF
1. Cú pháp:
   typeof value
2. typeof trả về tên kiểu dữ liệu dưới dạng string.
   typeof 42        → "number"
   typeof "Hello"   → "string"
   typeof true      → "boolean"
   typeof undefined → "undefined"
   typeof 10n       → "bigint"
   typeof Symbol()  → "symbol"
   typeof {}        → "object"
3. Hai trường hợp đặc biệt:
   typeof null      → "object"   (hành vi lịch sử)
   typeof function  → "function"
4. Kiểm tra null chính xác:
   value === null

console.log(typeof null);           // "object"
console.log(typeof function () {}); // "function"
console.log(typeof undefined);      // "undefined"

3. Những điểm quan trọng cần nhớ
Dynamic typing: Một biến có thể được gán giá trị thuộc các kiểu dữ liệu khác nhau.
Number: NaN vẫn có kiểu "number"; Infinity cũng vậy.
BigInt: Dùng hậu tố n, ví dụ 100n.
String: Dùng backtick để nội suy biến hoặc biểu thức: `Hello ${name}`.
Boolean: Chỉ có true và false; phép so sánh trả về Boolean.
null và undefined: null biểu thị không có giá trị; undefined thường xuất hiện khi giá trị chưa được xác định.
Symbol: Mỗi lần gọi Symbol() tạo một giá trị duy nhất.
Object: Lưu trữ dữ liệu dưới dạng các thuộc tính
