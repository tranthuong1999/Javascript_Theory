Mục 1 — Terms: unary, binary, operand
1.1. Operand là gì?
Operand là giá trị mà toán tử thực hiện thao tác lên.
5 + 2
5: operand bên trái.
2: operand bên phải.
+: operator (toán tử).
1.2. Unary operator — Toán tử một ngôi
let x= 1;
x= -x;
console.log(x); // -1
1.3. Binary operator — Toán tử hai ngôi
let x = 1;
let y = 3;
console.log(y - x); // 2
BASIC OPERATORS — TERMS

1. Operator: toán tử thực hiện thao tác.
2. Operand: giá trị mà toán tử tác động lên.
3. Unary operator:
   Có 1 operand.
   Ví dụ: -x
4. Binary operator:
   Có 2 operands.
   Ví dụ: y - x
5. Cùng ký hiệu có thể có cách dùng khác nhau:
   -x  → unary minus
   y-x → binary subtraction

Mục 2 — Maths (Các phép toán)
2.1. Các phép toán cơ bản
JavaScript hỗ trợ những phép toán số học quen thuộc:
| Toán tử | Ý nghĩa  | Ví dụ    | Kết quả |
| ------- | -------- | -------- | ------- |
| `+`     | Cộng     | `5 + 2`  | `7`     |
| `-`     | Trừ      | `5 - 2`  | `3`     |
| `*`     | Nhân     | `5 * 2`  | `10`    |
| `/`     | Chia     | `5 / 2`  | `2.5`   |
| `%`     | Phần dư  | `5 % 2`  | `1`     |
| `**`    | Lũy thừa | `2 ** 3` | `8`     |
MATHS OPERATORS
+   Cộng
-   Trừ
*   Nhân
/   Chia
%   Lấy phần dư
**  Lũy thừa

Ví dụ:
8 % 3   → 2
10 % 2  → 0
2 ** 3  → 8

Kiểm tra số chẵn:
number % 2 === 0

Kiểm tra số lẻ:
number % 2 !== 0

Mục 3 — String concatenation with binary +
* 3.1. Toán tử + khi làm việc với chuỗi
K chỉ dùng để cộng số mà còn nối chuỗi
* 3.2. Khi chuỗi kết hợp với số
Khi 1 trong 2 operator là chuỗi , toán từ + sẽ nối thành chuỗi thay vì cộng 
console.log("1" + 2);     // "12"
console.log(2 + "1");     // "21"
console.log("1" + 2 + 3); // "123"
console.log(2 + 3 + "1"); // "51"
* 3.3. Các toán tử khác không hoạt động giống +
 Với các toán tử như -, *, /, JavaScript thường chuyển chuỗi số thành số để tính toán.
 STRING CONCATENATION WITH +
1. + nối chuỗi:
   "hello" + " world" → "hello world"
2. Nếu một operand là string:
   "1" + 2 → "12"
   2 + "1" → "21"
3. Tính từ trái sang phải:
   "1" + 2 + 3 → "123"
   2 + 3 + "1" → "51"
4. Các toán tử khác:
   "6" - 2 → 4
   "6" * 2 → 12
   "6" / 2 → 3
5. Cẩn thận:
   + có thể cộng số hoặc nối chuỗi.
  
console.log(5 + 2 + "3");
console.log("5" + 2 + 3);
console.log("10" - 4);

Mục 4 — Numeric conversion, unary +
4.1. Unary + là gì?
Chuyển giá trị đó thành kiểu số
const str = "123";

console.log(+str); // 123
console.log(typeof +str); // "number"
console.log(+true);      // 1
console.log(+false);     // 0
console.log(+"");        // 0
console.log(+"hello");   // NaN

UNARY PLUS (+value)

1. Công dụng:
   Chuyển giá trị sang kiểu number.
2. Tương tự:
   +"123" === Number("123") // true
3. Ví dụ:
   +"25"       → 25
   +true       → 1
   +false      → 0
   +null       → 0
   +undefined  → NaN
4. Phân biệt:
   +"2" + +"3" → 5
   "2" + "3"   → "23"

Mục 5 — Operator precedence (Thứ tự ưu tiên toán tử)
5.1. Operator precedence là gì?
### 5.2. Thứ tự ưu tiên thường gặp

| Toán tử               | Ưu tiên tương đối        |
| --------------------- | ------------------------ |
| `()` — nhóm biểu thức | Cao nhất trong ví dụ này |
| `*`, `/`, `%`         | Cao                      |
| `+`, `-`              | Thấp hơn                 |
| `=` — gán             | Thấp                     |

OPERATOR PRECEDENCE

1. Thứ tự ưu tiên quyết định phép toán nào chạy trước.
2. () giúp nhóm biểu thức và thay đổi thứ tự tính.
3. *, /, % ưu tiên cao hơn +, -.
4. = có độ ưu tiên thấp.
5. Ví dụ:
   2 + 3 * 4    → 14
   (2 + 3) * 4  → 20

Mục 6 — Assignment (=)
6.1. Assignment trả về một giá trị
Phép gán  = không chỉ gán giá trị cho biến mà bản thân biểu thức gán cũng trả về giá trị vừa được gán
let x = 5;
let y = (x = 10);
console.log(x); // 10
console.log(y); // 10
6.2. Chaining assignments — Gán nối tiếp
Tức là gán cùng 1 giá trị cho nhiều biến
let a, b, c;
a = b = c = 10;
console.log(a); // 10
console.log(b); // 10
console.log(c); // 10
Thứ tự thực hiện : 
c = 10
b = c
a = b
ASSIGNMENT (=)
1. Phép gán trả về giá trị được gán:
   let x;
   let y = (x = 10);
   // x = 10, y = 10
2. Gán nối tiếp:
   a = b = c = 10;
3. Thứ tự thực hiện từ phải sang trái:
   c = 10 → b = c → a = b
4. Ưu tiên code dễ đọc:
   c = 10;
   b = c;
   a = b;

let a, b;
a = b = 7;
console.log(a);
console.log(b);
console.log(a + b);

8.2. Prefix và Postfix
Prefix — ++n: tăng trước, trả về giá trị mới.
let n = 5;
let result = ++n;

console.log(n);      // 6
console.log(result); // 6
Postfix — n++: trả về giá trị cũ, sau đó mới tăng.

let n = 5;
let result = n++;
console.log(n);      // 6
console.log(result); // 5

INCREMENT / DECREMENT
++n: tăng trước, trả về giá trị mới.
n++: trả về giá trị cũ, sau đó tăng.

--n: giảm trước, trả về giá trị mới.
n--: trả về giá trị cũ, sau đó giảm.

Ví dụ:
let n = 5;
let a = ++n; // a = 6, n = 6

let m = 5;
let b = m++; // b = 5, m = 6

let a = 3;
let b = a++;
let c = ++a;

console.log(a, b, c);

a++: lấy giá trị cũ, rồi tăng.
++a: tăng trước, rồi lấy giá trị mới.

Mục 9 — Bitwise operators (Toán tử bit)
BITWISE OPERATORS

&   AND: cả hai bit là 1
|   OR: ít nhất một bit là 1
^   XOR: hai bit khác nhau
~   NOT: đảo bit
<<  Dịch trái
>>  Dịch phải, giữ dấu
>>> Dịch phải, thêm bit 0

Ví dụ:
5 & 3 = 1
5 | 3 = 7
5 ^ 3 = 6
~5 = -6
5 << 1 = 10

Mục 10 — Comma operator (Toán tử dấu phẩy ,)
10.1. Khái niệm
Toán tử dấu phẩy , cho phép thực hiện nhiều biểu thức theo thứ tự từ trái sang phải và trả về kết quả của biểu thức cuối cùng.
let a = (1 + 2, 3 + 4);
console.log(a); // 7

COMMA OPERATOR (,)
- Thực hiện biểu thức từ trái sang phải.
- Trả về kết quả của biểu thức cuối cùng.
- Thường ít dùng vì có thể làm code khó đọc.
Ví dụ:
let a = (1 + 2, 3 + 4);
console.log(a); // 7

TYPE CONVERSIONS

1. Toán tử +
   - Nếu gặp chuỗi, có thể nối chuỗi.
   - Tính từ trái sang phải.
2. Toán tử -, *, /
   - Thường chuyển toán hạng thành số trước khi tính.
3. Boolean trong phép tính số học
   - true  → 1
   - false → 0
4. Giá trị đặc biệt
   - null      → 0 khi chuyển sang số
   - undefined → NaN khi chuyển sang số
   - Chuỗi chỉ chứa khoảng trắng → 0
   - Chuỗi không chuyển được thành số → NaN
