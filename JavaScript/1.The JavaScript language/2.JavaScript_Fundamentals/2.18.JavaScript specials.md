condition ? A : B

condition đúng  → lấy A
condition sai   → lấy B

Dùng khi cần chọn một trong hai giá trị dựa trên điều kiện.
***************************************************************

A && B
- Gặp falsy đầu tiên → trả về giá trị falsy đó.
- Nếu tất cả truthy → trả về toán hạng cuối.

A || B
- Gặp truthy đầu tiên → trả về giá trị truthy đó.
- Nếu tất cả falsy → trả về toán hạng cuối.

!A
- Đảo giá trị logic của A.

Falsy thường gặp: false, 0, "", null, undefined, NaN.

5.5. Toán tử ??
Toán tử ?? dùng để chọn giá trị mặc định khi giá trị bên trái là null hoặc undefined.
console.log(null ?? "Hello");
console.log(0 ?? 10);
console.log(0 || 10);

while: kiểm tra điều kiện trước khi chạy thân vòng lặp.
do...while: chạy thân vòng lặp ít nhất một lần, sau đó mới kiểm tra điều kiện.
let i = 10;

do {
  console.log(i); // In 10
  i++;            // i = 11
} while (i < 10); // 11 < 10 là false → dừng

1. Khởi tạo i = 1
2. Kiểm tra i <= 3
3. Đúng → chạy console.log(i)
4. Chạy i++
5. Quay lại bước 2
6. Sai → dừng
* So sánh for và while
// for
for (let i = 1; i <= 3; i++) {
  console.log(i);
}

// while
let j = 1;
while (j <= 3) {
  console.log(j);
  j++;
}
break    → Dừng toàn bộ vòng lặp hiện tại.
continue → Bỏ qua lần lặp hiện tại, tiếp tục vòng lặp.

for (let i = 1; i <= 5; i++) {
  if (i === 2) {
    continue;
  }

  if (i === 4) {
    break;
  }

  console.log(i);
}

Local variable:
- Khai báo trong hàm.
- Chỉ truy cập được trong phạm vi hàm.

Parameter:
- Biến được khai báo trong danh sách tham số.
- Nhận giá trị từ đối số khi gọi hàm.
  Mục 8.3 — Default parameters (Tham số mặc định)
1. Không sử dụng tham số mặc định
   function greet(name) {
  console.log("Hello " + name);
}

greet("Martin"); // Hello Martin
greet();         // Hello undefined
2. Sử dụng tham số mặc định
3. Có nhiều tham số mặc định
function greet(name = "Guest") {}

- Không truyền đối số → dùng giá trị mặc định.
- Truyền undefined → dùng giá trị mặc định.
- Truyền null → nhận null, không dùng giá trị mặc định.
- Giá trị truyền vào sẽ thay thế giá trị mặc định.
  function introduce(name = "Guest", age = 18) {
  console.log(name, age);
}

introduce("Martin");
introduce();
introduce("An", undefined);
introduce("Nam", null);

Mục 8.4 — Return value (Giá trị trả về)
return có hai tác dụng:
- Trả một giá trị về nơi gọi hàm.
- Kết thúc việc thực thi hàm ngay tại đó.
  
function sum(a, b) {
  return a + b;
}

let result = sum(3, 5);

console.log(result); // 8

return:
- Trả giá trị về nơi gọi hàm.
- Kết thúc hàm ngay khi được thực thi.
- Không có return → hàm trả về undefined.

console.log:
- Chỉ hiển thị giá trị.
- Không thay thế return.
