* 1.1. Định nghĩa
Stric mode giúp JS kiểm tra và áp dụng các quy tắc nghiêm ngặt hơn nhăm hạn chế 1 số lỗi lập trình 
"use strict"; đặt đầu file JS
* 1.2. Vì sao cần Strict mode?
"use strict";
age = 25;
console.log(age);

CÁCH BẬT STRICT MODE

1. Toàn file:
   Đặt "use strict"; ở đầu script.

2. Một function:
   Đặt "use strict"; ở đầu function.

3. Vị trí:
   Chỉ comment được đứng trước "use strict".
   Nếu đã có câu lệnh thực thi phía trên, directive sẽ không được kích hoạt.

4. Không thể tắt Strict mode bằng một directive khác
   trong cùng phạm vi đã bật.

* Mục 3 — Strict mode trong JavaScript hiện đại
  
*************************************************************************
* RECAP
"use strict" → bật chế độ nghiêm ngặt
age = 25     → ReferenceError nếu age chưa khai báo
ES Modules   → tự động Strict mode
Classes      → tự động Strict mode
"use client" → directive của Next.js, không phải Strict mode
