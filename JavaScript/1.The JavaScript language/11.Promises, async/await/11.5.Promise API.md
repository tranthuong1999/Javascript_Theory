1. Promise.all là gì?
Promise.all() dùng khi chúng ta muốn nhiều Promise thực thi song song và chờ đến khi tất cả hoàn thành thành công
Ví dụ thực tế:
- Gọi API người dùng
- Gọi API lấy danh sách sản phẩm.
- - Gọi API lấy danh mục sản phẩm.
Nếu cần tất cả để hiển thị trang , chúng ta có thể sử dụng Promise.all()
<!-- let promise = Promise.all(iterable); -->
Trong đó:
- iterable: Một iterable, thường là mảng Promise.
- Giá trị trả về: Một Promise mới.

<!-- [1, 2, 3] -->

3. Kết hợp map() với Promise.all()
Chuyển 1 mảng dữ liệu thành mảng Promise bằng map , sau đó truyền vào Promise.all
<!-- 
let urls = [
    'https://api.github.com/users/iliakan',
    'https://api.github.com/users/remy',
    'https://api.github.com/users/jeresig'
];

// Chuyển từng URL thành Promise
let requests = urls.map(url => fetch(url));

// Chờ tất cả request thành công
Promise.all(requests)
    .then(responses => responses.forEach(
        response => alert(`${response.url}: ${response.status}`)
    ));
 -->
1. urls.map() duyệt từng URL.
2. fetch(url) tạo một Promise cho mỗi request
3. request chứa các Promise
4. Promise.all(request) chờ tất cả các Promise fullfield
5. Khi tất cả thành công , .then() nhận mảng responses.
Ứng dụng frontend:
<!-- 
const userIds = [1, 2, 3];

const requests = userIds.map(id =>
    fetch(`/api/users/${id}`)
);

Promise.all(requests)
    .then(responses => {
        return Promise.all(
            responses.map(response => response.json())
        );
    })
    .then(users => {
        console.log(users);
    })
    .catch(error => {
        console.error(error);
    });
 -->
Ở đây có hai lần Promise.all():
- Lần đầu chờ tất cả request hoàn thành
- Lần thứ hai chờ tất cả quá trình đọc JSON hoàn thành.
4. Ví dụ lớn hơn trong tài liệu gốc
<!-- 
let names = ['iliakan', 'remy', 'jeresig'];

let requests = names.map(name =>
    fetch(`https://api.github.com/users/${name}`)
);

Promise.all(requests)
    .then(responses => {
        // Tất cả response đều thành công
        for (let response of responses) {
            alert(`${response.url}: ${response.status}`);
        }

        return responses;
    })
    // Chuyển responses thành các Promise đọc JSON
    .then(responses =>
        Promise.all(responses.map(r => r.json()))
    )
    // Tất cả JSON đã được phân tích
    .then(users => users.forEach(user => alert(user.name)));
 -->
fetch() trả về Promise chứa Response.
response.json() cũng trả về Promise chứa dữ liệu JSON đã parse
Vì vậy phải chờ cả hai giai đoạn.
5. Nếu một Promise bị reject thì sao?
Chỉ cần 1 promise bị reject , Promise.all lập tức reject theo lỗi đó
Ví dụ trong tài liệu gốc:
<!-- 
Promise.all([
    new Promise((resolve, reject) =>
        setTimeout(() => resolve(1), 1000)
    ),

    new Promise((resolve, reject) =>
        setTimeout(() => reject(new Error("Whoops!")), 2000)
    ),

    new Promise((resolve, reject) =>
        setTimeout(() => resolve(3), 3000)
    )
]).catch(alert);
 -->
Diễn biến:
Khi Promise 2 reject, .catch() chạy ngay mà không cần chờ Promise 3
Một trường hợp dễ nhầm cần nhớ:
Promise 3 vẫn tiếp tục chạy dù Promise.all() đã reject
Promise.all() k tư động huỷ những request hoặc Promise còn lại . Nó chỉ ngừng theo dõi kết quả của chúng để tạo ra kết quả chung
Muốn hủy request, cần cơ chế riêng của AbortController , không phải chức năng của Promise.all()
6. Promise.all() chấp nhận cả giá trị thông thường
Không bắt buộc tất cả phần tử truyền vào phải là Promise.
<!-- 
Promise.all([

        setTimeout(() => resolve(1), 1000);
    }),
    2,
    3
]).then(alert);
 -->
Các giá trị 2 và 3 được đưa vào mảng kết quả như bình thường.

Promise.allSettled
1. Promise.allSettled là gì?
Promise.allSettled() chờ tất cả các Promise hoàn thành , bất kể chúng fulfilled hay rejected.
Khác với Promise.all():
- Promise.all() reject ngay khi có 1 Promise reject
- Promise.allSettled() chờ tất các Promise settled rồi trả về kết quả của tưng Promise
Cú pháp:
<!-- let results = await Promise.allSettled(iterable); -->
2. Ví dụ trong tài liệu gốc
<!-- 
let urls = [
    'https://api.github.com/users/iliakan',
    'https://api.github.com/users/remy',
    'https://no-such-url'
];

let requests = urls.map(url => fetch(url));

let results = await Promise.allSettled(requests);

results.forEach((result, index) => {
    if (result.status === "fulfilled") {
        alert(`${urls[index]}: ${result.value.status}`);
    } else {
        alert(`${urls[index]}: ${result.reason}`);
    }
});
 -->
Giả sử:
- Request 1 thành công.
- Request 2 thành công.
- Request 3 thất bại.
Promise.allSettled() vẫn chờ cả 3 request hoàn thành rồi trả về mảng kết quả
Cấu trúc kết quả:
<!-- 
[
    { status: "fulfilled", value: response1 },
    { status: "fulfilled", value: response2 },
    { status: "rejected", reason: error }
]
 -->
3. Cấu trúc kết quả
Mỗi phần từ trong mảng kết quả có 1 trong 2 dạng :
Trường hợp fulfilled:
<!-- 
{
    status: "fulfilled",
    value: "Kết quả thành công"
}
 -->
Trường hợp rejected:
<!-- 
{
    status: "rejected",
    reason: new Error("Something went wrong")
}
-->
Bạn cần nhớ:
| Thuộc tính | Ý nghĩa               |
| ---------- | --------------------- |
| `status`   | Trạng thái Promise    |
| `value`    | Giá trị khi fulfilled |
| `reason`   | Lý do khi rejected    |
Không có value trong kết quả reject và không có reason trong kết quả fullfield

6. So sánh Promise.all và Promise.allSettled
| Tiêu chí              | `Promise.all()`               | `Promise.allSettled()`           |
| --------------------- | ----------------------------- | -------------------------------- |
| Chờ tất cả thành công | Có                            | Không yêu cầu                    |
| Một Promise reject    | Reject ngay                   | Vẫn chờ tất cả                   |
| Kết quả               | Mảng giá trị                  | Mảng object trạng thái           |
| Thứ tự                | Theo đầu vào                  | Theo đầu vào                     |
| Mục đích              | Cần tất cả kết quả thành công | Muốn thu thập kết quả của tất cả |

Promise.race
Ý chính: Promise.race(iterable) trả về một Promise có kết quả theo Promise đầu tiên settle ( settle có nghĩa là fullfild hoặc rejected)
 <!--
 const promise1 = new Promise(resolve => {
    setTimeout(() => resolve("One"), 1000);
});

const promise2 = new Promise(resolve => {
    setTimeout(() => resolve("Two"), 2000);
});

Promise.race([promise1, promise2])
    .then(console.log);
   -->
Kết quả sau khoảng 1 giây:
One
promise1 settle trước nên kết quả của Promise .race() là One.Nó không cần chờ promise2.
Trường hợp quan trọng: Promise đầu tiên bị reject
<!-- 
const promise1 = new Promise((resolve, reject) => {
    setTimeout(() => reject("Error"), 1000);
});

const promise2 = new Promise(resolve => {
    setTimeout(() => resolve("Success"), 2000);
});

Promise.race([promise1, promise2])
    .then(console.log)
    .catch(console.log);
 -->
Vì Promise.race() lấy kết quả của Promise settle đầu tiên, bất kể đó là fullfield hay reject
Bổ sung ngoài tài liệu gốc – dễ nhầm:
- Promise.race() không hủy các Promise còn lại.
- Promise còn lại vẫn tiếp tục chạy và có thể hoàn thành sau đó.
- race khác all: race chỉ cần trả vê Promise đầu tiên settle , còn all chờ tất cả fullfield ( hoặc reject ngay khi có 1 Promise reject )
Kiểm tra :
<!-- 
Promise.race([
    Promise.reject("A"),
    new Promise(resolve =>
        setTimeout(() => resolve("B"), 1000)
    )
]).then(console.log).catch(console.log);
 -->
Promise.race() trả về "A" vì Promise đầu tiên đã reject ngay lập tức. Nó không đợi Promise "B" hoàn thành.
Ghi nhớ: raece chọn Promise settled đầu tiên , không phân biệt fullfield hay reject

Promise.any
Promise.any(iterable) tương tự Promise.race(), nhưng có 1 điểm khác biệt quan trọng :
Promise.race() lấy Promise đầu tiên settle ( fullfield hoặc reject)
Promise.any() lấy Promise đầu tiền fullfield . Nêu promise đầu tiên reject , nó tiếp tục chờ Promise khác
Ví dụ theo tài liệu:
<!-- 
Promise.any([
    new Promise((resolve, reject) =>
        setTimeout(() => reject(new Error("Whoops!")), 1000)
    ),
    new Promise(resolve =>
        setTimeout(() => resolve(1), 2000)
    ),
    new Promise(resolve =>
        setTimeout(() => resolve(3), 3000)
    )
]).then(console.log);
 -->
1
Giải thích :
1. Sau 1 giây: Promise đầu tiên reject → bỏ qua kết quả này.
2. Sau 2 giây: Promise thứ hai fulfilled với 1 → trả về 1.
3. Promise thứ ba hoàn thành sau đó nhưng kết quả bị bỏ qua.
Trường hợp tất cả Promise đều reject
Khi tất cả Promise đều reject , Promise.any() reject với 1 lỗi đặc biệt tên là AggregateError
<!-- 
Promise.any([
    Promise.reject(new Error("Ouch!")),
    Promise.reject(new Error("Error!"))
]).catch(error => {
    console.log(error.constructor.name);
    console.log(error.errors[0]);
    console.log(error.errors[1]);
});
 -->
Điểm cần nhớ:
- AggregateError là một đối tượng lỗi đặc biệt.
- error.errors chứa danh sách các lỗi của những Promise đã reject.
Bổ sung ngoài tài liệu gốc – so sánh dễ nhầm:
| Phương thức            | Điều kiện lấy kết quả      |
| ---------------------- | -------------------------- |
| `Promise.race()`       | Promise đầu tiên settle    |
| `Promise.any()`        | Promise đầu tiên fulfilled |
| `Promise.all()`        | Tất cả fulfilled           |
| `Promise.allSettled()` | Tất cả settle              |
Kiểm tra nhanh:
<!-- 
Promise.any([
    Promise.reject("A"),
    Promise.reject("B"),
    new Promise(resolve =>
        setTimeout(() => resolve("C"), 1000)
    )
]).then(console.log).catch(console.log);
 -->
Giải thích:
- "A" reject → Promise.any() tiếp tục chờ.
- "B" reject → tiếp tục chờ.
- "C" fulfilled sau 1 giây → trả về "C".
Chỉ khi tất cả Promise đều reject thì Promise.any() mới trả về AggregateError.

*******************************************************************************************************************
Promise.resolve / Promise.reject
1. Promise.resolve(value)
Promise.resolve(value) tạo 1 promise đã fullfield với giá trị là value
<!-- 
const promise = Promise.resolve(1);

promise.then(console.log); // 1
 -->
Nó tương đương với:
<!-- 
const promise = new Promise(resolve => {
    resolve(1);
});
 -->
 Trường hợp dễ nhầm: Nếu truyền vào một Promise khác , Promise.resolve() sẽ trả về Promise đó (nếu cùng constructor Promise), thay vì tạo một Promise lồng nhau.
 <!-- 
 const original = Promise.resolve(1);
const wrapped = Promise.resolve(original);

console.log(original === wrapped); // true
  -->
2. Promise.reject(value)
Promise.reject(value) tạo một Promise đã rejected với lý do value.
<!-- 
const promise = Promise.reject(new Error("Something went wrong"));

promise.catch(error => {
    console.log(error.message);
});
 -->
Something went wrong
Tương đương với:
<!-- 
const promise = new Promise((resolve, reject) => {
    reject(new Error("Something went wrong"));
});
 -->
Bổ sung ngoài tài liệu gốc – dễ nhầm:
Promise.resolve() tiếp nhận và xử lý Promise/thenable theo cơ chế Promise assimilation; còn 
Promise.reject() không làm điều đó với giá trị truyền vào.
<!-- 
const p = Promise.reject(Promise.resolve("A"));

p.catch(value => {
    console.log(value); // Promise đã fulfilled, không phải "A"
});
 -->

Summary – Promise API
| Phương thức            | Cách hoạt động                                              |
| ---------------------- | ----------------------------------------------------------- |
| `Promise.all()`        | Chờ tất cả fulfilled; reject ngay khi có một Promise reject |
| `Promise.allSettled()` | Chờ tất cả settle, trả về trạng thái từng Promise           |
| `Promise.race()`       | Lấy kết quả của Promise settle đầu tiên                     |
| `Promise.any()`        | Lấy kết quả của Promise fulfilled đầu tiên                  |
| `Promise.resolve()`    | Tạo Promise fulfilled                                       |
| `Promise.reject()`     | Tạo Promise rejected                                        |

Những điểm cần nhớ khi áp dụng
1. Kết quả của Promise.all() và Promise.allSettled() giữ nguyên thứ tự đầu vào , k phụ thuộc vào thời gian hoàn thành
2. Promise.all() reject không có nghĩa là các Promise còn lại bị hủy.
3. Promise.race() khác Promise.any() ở việc xử lý rejection.
4. Promise.any() chỉ reject với AggregateError khi tất cả Promise đều reject.
5. Promise.resolve(promise) có thể trả lại chính Promise đó nếu cùng constructor
6. Promise.reject(promise) tạo Promise rejected với reason chính là Promise được truyền vào.
