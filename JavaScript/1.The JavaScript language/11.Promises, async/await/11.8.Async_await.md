3. Nội dung bài học
3.1. Async functions
Từ khóa async được đặt trước một function:
<!-- 
async function f() {
    return 1;
}
 -->
Điều quan trọng : 1 function có async luôn trả về Promise
Nếu function trả về 1 giá trị thông thường , JS tự động bọc giá trị của nó trong Promise fullfield
Ví dụ theo tài liệu :
<!-- 
async function f() {
    return 1;
}

f().then(alert); // 1
 -->
Hai cách trên đều trả về Promise fulfilled với kết quả 1.
Bổ sung ngoài tài liệu gốc – Case dễ nhầm
1. async không làm function trả về trực tiếp gía trị thông thường
 <!--
 async function getValue() {
    return 10;
}

const result = getValue();

console.log(result);
-->
result là Promise, không phải số 10.
Muốn lấy giá trị :
<!-- 
getValue().then(value => {
    console.log(value); // 10
});
 -->
2. Phân biệt return value và return Promise.resolve(value).
Trong 1 async ffucntion , hai cách này đều cho kết quả Prommise fullfield với giá trị tương ứng
<!-- 
async function a() {
    return 10;
}

async function b() {
    return Promise.resolve(10);
}
 -->
3.2. Await
Theo tài liệu gốc, await chỉ hoạt động bên trong async function (ngoại lệ top-level await trong module sẽ nói ở phần dưới).
Cú pháp:
<!-- let value = await promise; -->
await khiến JS chờ Promise settled và trả vê kết quả của Promise
1. Cách hoạt động của await
Ví dụ trong tài liệu:
<!-- 
async function f() {
    let promise = new Promise((resolve, reject) => {
        setTimeout(() => resolve("done!"), 1000);
    });

    let result = await promise;

    alert(result); // "done!"
}

f();
 -->
1. Gọi f().
2. Tạo Promise có thời gian hoàn thành sau 1s
3. Gặp await promise , function f() tạm dừng tại đó
4. Sau 1 giây, Promise fulfilled với giá trị "done!"
5. Function tiếp tục chạy và result nhận kết quả "done";
Điểm quan trọng: await chỉ dùng việc thực thi của async function hiện tại , . Nó k chặn toàn bộ JS
Trong thời gian chờ, JavaScript engine vẫn có thể thực hiện các công việc khác như chạy script và xử lý event.
await là cách viết đễ đọc hơn Promise.then()
 
2. Không thể sử dụng await trong regular function
<!-- 
function f() {
    let promise = Promise.resolve(1);

    let result = await promise; // Syntax Error
}
 -->
Lỗi cú pháp vì fucntion trên không có async
Cách sửa:
<!-- 
async function f() {
    let promise = Promise.resolve(1);

    let result = await promise;
}
 -->
3. Viết lại ví dụ showAvatar() bằng async/await
Cách chuyển đổi:
- Thay .then() bằng await.
- Thêm async trước function.
- Các câu lệnh có thể viết tuần tự, dễ theo dõi hơn.

4. Top-level await trong modules
Các trinhf duyệt cho phép sử dụng await ở cấp cao nhất khi code nằm trong 1 module
<!-- 
// Code chạy ở top level bên trong module
let response = await fetch('/article/promise-chaining/user.json');
let user = await response.json();

console.log(user);
 -->
Nếu không sử dụng module hoặc cần hỗ trợ trình duyệt cũ, tài liệu đưa ra cách sử dụng một async function ẩn danh:
<!-- 
(async () => {
    let response = await fetch('/article/promise-chaining/user.json');
    let user = await response.json();

    console.log(user);
})();
 -->
5. Await chấp nhận Thenables
Giống như Promise.then() , await cũng chấp nhận các object có phương thức then có thể gọi được 
Tài liệu đưa ra ví dụ:
<!-- 
class Thenable {
    constructor(num) {
        this.num = num;
    }

    then(resolve, reject) {
        alert(resolve);

        setTimeout(() => resolve(this.num * 2), 1000);
    }
}

async function f() {
    let result = await new Thenable(1);

    alert(result); // 2
}

f();
 -->
Giải thích:
- Thenable không phải Promise.
- Nhưng nó có phương thức then(resolve, reject).
- Khi await nhận object này, JS gọi phương thức then , truyền vào 2 hàm resolve và reject
- await tiếp tục chờ cho đến khi 1 trong hai hàm được gọi 
- Trong ví dụ, sau 1 giây resolve(2) được gọi, nên result nhận giá trị 2.

6. Async class methods
Để khai báo 1 phương thức  async trong class, chỉ cần thêm async trước phương thức
<!-- 
class Waiter {
    async wait() {
        return await Promise.resolve(1);
    }
}

new Waiter()
    .wait()
    .then(alert); // 1
 -->
Ý nghĩa giống async function thông thường:
- Phương thức luôn trả về Prmomise
- Cho phép sử dụng await bên trong phương thức
Bổ sung ngoài tài liệu gốc – Những case dễ nhầm
Case 1: await không làm chương trình đứng im.
<!-- 
async function test() {
    console.log("A");

    await new Promise(resolve => setTimeout(resolve, 1000));

    console.log("B");
}

test();

console.log("C"); -->
Vì khi gặp await, function test() tạm dừng, nhưng code bên ngoài vẫn tiếp tục chạy.
Case 2: await trả về giá trị, không trả về Promise.
<!-- 
async function test() {
    const result = await Promise.resolve(100);

    console.log(result); // 100
}
-->
await lấy kết quả của Promise để gán vào result
Case 3: await với giá trị thông thường không phải Promise
<!-- 
async function test() {
    const result = await 100;

    console.log(result); // 100
}
 -->
Điểu này vẫn hợp lệ . Giá trị thông thường được xử lý như một giá trị đã fullfield
Câu 1. Kết quả của đoạn code sau là gì?
<!-- 
async function test() {
    console.log("A");

    await Promise.resolve();

    console.log("B");
}

test();
console.log("C");
 -->
1. Gọi test() → in A.
2. Gặp await Promise.resolve() => function test() tạm dừng
3. Code bên ngoài tiếp tục → in C.
4. Promise đã fulfilled, phần tiếp theo của async funtion được đưa vào microtask quene
5. Sau khi code đồng bộ hoàn tất , in B

3.3. Error handling
KHi Promise bị reject , await sẽ ném lỗi tại vị trí nó đang được sử dụng 
Điều này tương tự như câu lệnh throw.
1. Ví dụ Promise reject với await
<!-- 
async function f() {
    await Promise.reject(new Error("Whoops!"));
}
 -->
Đoạn code trên tương đương với :
<!-- 
async function f() {
    throw new Error("Whoops!");
}
 -->
Vì vậy, có thể sử dụng try...catch để xử lý lỗi.
2. Sử dụng try...catch
<!-- 
async function f() {
    try {
        let response = await fetch('/no-user-here');
        let user = await response.json();
    } catch (err) {
        alert(err);
    }
}

f();
 -->
Giải thích:
- Nếu fetch() reject , lỗi được ném ra tại await fetch(...).
- Nếu response.json() reject , lỗi được ném ra tại await esponse.json().
- Cả 2 lỗi đều được xử lý trong catch

3. Sử dụng try...catch với nhiều await
Bạn có thể sử dụng nhiểu câu lệnh await trong cùng 1 khối try
<!-- 
async function f() {
    try {
        let response = await fetch('/article/promise-chaining/user.json');
        let user = await response.json();
        let githubResponse = await fetch(`https://api.github.com/users/${user.name}`);
        let githubUser = await githubResponse.json();
    } catch (err) {
        alert(err);
    }
}

f();
 -->
Nếu bất kỳ Promise nào bị reject , chương trình sẽ chuyển đến catch

4. Sử dụng .catch()
Nếu k muốn dùng try...catch bên trong async function , bạn có thể thêm catch khi gọi function
<!-- 
async function f() {
    let response = await fetch('http://no-such-url');
}

f().catch(alert); -->
Vì async function luôn trả về Promise nên có thể sử dụng .catch() như với 1 Promise thông thường

5. Re-throwing
Bạn có thể bắt lỗi, kiểm tra lỗi và ném lại lỗi nếu không xử lý được.
<!-- 
async function f() {
    try {
        let response = await fetch('/no-user-here');
        let user = await response.json();
    } catch (err) {
        if (err instanceof SyntaxError) {
            alert("JSON Error");
        } else {
            throw err;
        }
    }
}

f().catch(alert);
 -->
Ở đây:
- Nếu lỗi là SyntaxError, xử lý ngay trong catch.
- Nếu là loại lỗi khác, throw err ném lỗi ra ngoài.
- Promise được trả về từ f() sẽ reject với lỗi đó.
-  .catch(alert) bên ngoài sẽ nhận lỗi.

6. Async/await và Promise.all
Khi cần chờ nhiều Promise cùng lúc , có thể kết hợp await với Promise.all()
<!-- 
async function load() {
    let results = await Promise.all([
        fetch('/article/promise-chaining/user.json'),
        fetch('/article/promise-chaining/guest.json')
    ]);

    console.log(results);
}

load();
 -->
Promise.all() trả về 1 Promise . await chờ Promise đó hoàn thành
Nếu 1 Promise trong danh sách bị reject , Promise đưuojc trả về bởi Promise.all() cũng reject
Bổ sung ngoài tài liệu gốc – Các trường hợp dễ nhầm
Case 1: Không có try...catch hoặc .catch()
<!-- 
async function test() {
    await Promise.reject("Error");
}

test();
 -->
Async function trả về một Promise rejected . Nếu không có handler xử lý , có thể phát sinh unhandled rejection
Case 2 : try...catch chỉ bắt lỗi trong phạm vi thực thi của nó
<!-- 
async function test() {
    try {
        await Promise.reject("Error");
    } catch (err) {
        console.log("Caught:", err);
    }
}

test();
 -->
Case 3: await tuần tự khác Promise.all
<!-- 
const a = await fetch("/api/a");
const b = await fetch("/api/b");
 -->
Hai request được khởi tạo tuần tự : request B chỉ bắt dầu khi request A hoàn thành
Trong khi đó:
<!-- 
const [a, b] = await Promise.all([
    fetch("/api/a"),
    fetch("/api/b")
]);
 -->
Hai request được khỏi tạo trước khi chờ kết quả , nên có thể chạy đồng thời
Kiểm tra hiểu bài:
<!-- 
async function test() {
    try {
        await Promise.reject("Error");
        console.log("A");
    } catch (err) {
        console.log("B:", err);
    }

    console.log("C");
}

test();
 -->
B: Error
C
1. await Promise.reject("Error") ném lỗi.
2. JavaScript bỏ qua console.log("A").
3. Chuyển vào catch, in B: Error.
4. Sau khi xử lý lỗi xong, chương trình tiếp tục và in C.

3.4. Summary
Tóm tắt đúng các ý chính của bài:
- Từ khóa async trước function khiến function luôn trả về Promise.
- await khiến async function tạm dừng cho đến khi Promise settle.
- Khi Promise fulfilled, await trả về giá trị kết quả.
- Khi Promise rejected, await ném lỗi để có thể xử lý bằng try...catch.
- Có thể sử dụng await ở top-level trong JavaScript modules.
- await chấp nhận cả Promise và Thenable.
- Async methods có thể được khai báo trong class.
- - Promise.all() có thể kết hợp với await để chờ nhiều Promise.
