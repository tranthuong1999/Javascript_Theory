*******************************************************************************************************************
1. Promise là gì?
1.1. Producing code và Consuming code
Trước khi tìm hiểu promise , chúng ta cần phân biệt 2 loại code.
Producing code ( Code tạo ra kết quả )
Là phần code thực hiện 1 công việc và tạo ra kết quả sau 1 khoảng thời gian
Ví dụ:
- Gọi API lấy thông tin người dùng.
- Đọc dữ liệu từ database.
- Tải một file từ server.
Consuming code (Code sử dụng kết quả)
Là phần code nhận kết quả từ Producing code để tiếp tục xử lý
Ví dụ:
- Hiển thị thông tin người dùng
- Render danh sách bài viết
- Thông báo khi tải dữ liệu thất bại 
1. Ví dụ thực tế
Producing code
Lấy dữ liệu tin nhắn từ API
Gửi request lên server và chờ dữ liệu trả về.
Consuming code
Hiển thị danh sách tin nhắn
Nhận dữ liệu và render giao diện chat.
2. Liên hệ với Callback đã học
<!-- 
function getUser(callback) {
    setTimeout(() => {
        const user = {
            id: 1,
            name: "Martin"
        };

        callback(null, user);
    }, 1000);
}

getUser(function (error, user) {
    if (error) {
        console.log(error);
        return;
    }

    console.log(user);
});
 -->
 getUser() thực hiện công việc lấy dữ liệu → Producing code.
 Callback nhận và xử lý dữ liệu → Consuming code.
 Promise cung cấp 1 cách khác để kết nối 2 phần này
 Điểm cần nhớ:
- Producing code : tạo ra kết quả 
- Consuming code: sử dụng kết quả 
- Promise : kết nối Producing code và Consuming code

C. Hàm xử lý sự kiện click.

1.2. Promise là gì?
1. Định nghĩa
Promise là 1 đối tượng JS đại diện cho 1 quả của tác vụ bất đồng bộ , có thể thành công hoặc thất bại trong tương lai
Hiểu đơn giản:
KHi bạn gọi API lấy thông tin user , kết quả chưa có ngay lập tức . Promise giống như 1 lời hứa rằng :
Nếu thành công → trả về dữ liệu.
Nếu thất bại → trả về lỗi.
2. Ví dụ thực tế
Giả sử ứng dụng chat cần lấy danh sách tin nhắn:
<!-- 
const promise = fetch("/api/messages");

console.log(promise);
 -->
 fetch() trả về 1 Promise ngay lập tức , trong khi request vẫn đang được xử lý
 Sau đó Promise sẽ có kết quả:
- Thành công: nhận được Response.
- Thất bại: Promise bị reject.

3. Promise giải quyết vấn đề gì?
Ở bài Callback, chúng ta viết:
<!-- 
getUser(function (error, user) {
    if (error) {
        console.log(error);
        return;
    }

    getPosts(user.id, function (error, posts) {
        if (error) {
            console.log(error);
            return;
        }

        console.log(posts);
    });
});
 -->
Khi có nhiều task vụ phụ thuộc nhau , callback dễ bị lồng sâu
Với Promise, chúng ta có thể viết:
<!-- 
getUser()
    .then(user => getPosts(user.id))
    .then(posts => console.log(posts))
    .catch(error => console.log(error));
 -->
Lợi ích:
- Giảm lồng callback
- Tách xử lý thành công và thất bại.
- Dễ nối nhiều tác vụ bất đồng bộ.

Lưu ý : Promise không làm cho tác vụ bất đồng bộ tự chạy nhanh hơn . Nó cung cấp cách tổ chức và quản lý kết quả tốt hơn
4. Điều quan trọng cần hiểu
Promise không phải là dữ liệu thực tế.
 <!--const promise = fetch("/api/user");  -->
 Ở đây:
- promise : đại diện cho 1 kết quả trong tương lai
- Response : kết quả nhận được khi request hoàn thành.
Lưu ý: Promise không chứa trực tiếp dữ liệu kết quả ngay khi được tạo. Nó đại diện cho kết quả sẽ có sau này.
1.3. Cú pháp new Promise()
1. Cú pháp cơ bản
Để tạo một Promise, JS cung cấp constructor Promise
Cú pháp:
<!-- 
const promise = new Promise(function (resolve, reject) {
    // Producing code
});
 -->
Trong đó:
- new Promise() : tạo một Promise object
- function(resolve, reject): excutor function
- resolve : hàm thông báo task vụ thành công
- reject : hàm thông báo task vụ thất bại 
2. Ví dụ đơn giản
<!-- 
const promise = new Promise(function (resolve, reject) {
    setTimeout(() => {
        resolve("Success!");
    }, 1000);
});
 -->
Giải thích:
1. new Promise() tạo Promise.
2. Executor function được thực thi ngay lập tức.
3. setTimeout() lên lịch thực thi sau 1 giây.
4. resolve("Success!") thông báo Promise hoàn thành thành công

Lưu ý: resolve() không trực tiếp in kết quả ra console . Nó chuyển promise sang trạng thái thành công và cung 
cấp phần kết quả cho phần xử lý Promise
3. Ví dụ có cả thành công và thất bại
<!-- 
const promise = new Promise(function (resolve, reject) {
    const isSuccess = true;

    if (isSuccess) {
        resolve("Get user successfully");
    } else {
        reject(new Error("Get user failed"));
    }
});
-->
isSuccess === true → gọi resolve().
isSuccess === false → gọi reject().
4. Liên hệ với Callback
Callback trước đây:
<!-- 
function getUser(callback) {
    setTimeout(() => {
        const user = { id: 1, name: "Martin" };
        callback(null, user);
    }, 1000);
}
-->
Chuyển sang Promise:
<!-- 
function getUser() {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            const user = { id: 1, name: "Martin" };
            resolve(user);
        }, 1000);
    });
}
 -->
Điểm khác biệt:
- Callback: truyền hàm xử lý vào getUser().
- Promise: getUser() trả về một Promise để bên ngoài xử lý kết quả.

5. Điểm cần nhớ
| Thành phần       | Ý nghĩa                                |
| ---------------- | -------------------------------------- |
| `new Promise()`  | Tạo Promise object                     |
| Executor         | Hàm thực thi ngay khi Promise được tạo |
| `resolve()`      | Thông báo thành công                   |
| `reject()`       | Thông báo thất bại                     |
| `return promise` | Trả Promise cho bên gọi xử lý          |
Kiểm tra kiến thức :
<!-- 
const promise = new Promise((resolve, reject) => {
    console.log("Executor");
});
console.log("After Promise");
 -->
Giải thích:
1. new Promise() được thực thi.
2. Executor function chạy ngay lập tức (synchronous).
3. In "Executor".
4. Chạy câu lệnh tiếp theo và in "After Promise".

Điểm rất quan trọng:Promise xử lý kết quả bất đồng bộ, nhưng bản thân Executor function không tự động 
chạy bất đồng bộ
Ngoài ra, Promise trong ví dụ vẫn ở trạng thái pending vì chưa gọi resolve() hoặc reject().

1.4. Executor, resolve và reject
1. Executor là gì?
Executor là hàm được truyền vào constructor new Promise()
Ví dụ:
<!-- 
const promise = new Promise((resolve, reject) => {
    console.log("Executor running");

    setTimeout(() => {
        resolve("Success");
    }, 1000);
});
-->
Trong ví dụ này:
- Executor là (resolve, reject) => { ... }.
- Executor chạy ngay khi Promise được tạo.
- setTimeout() thực hiện công việc bất đồng bộ 
- Sau 1 giây, resolve("Success") được gọi.
Lưu ý: Executor không phải callback xử lý kết quả Promise . Nó là hàm thực hiện công việc để tạo ra kết quả đó 

2. resolve là gì?
resolve(value) là hàm được JS cung cấp cho Executor để thông báo Promise hoàn thành thành công
Ví dụ:
<!-- 
const promise = new Promise((resolve, reject) => {
    resolve("User found");
});
 -->
Promise sẽ chuyển sang trạng thái fulfilled và có kết quả "User found".
3. reject là gì?
reject(error) dùng để thông báo Promise hoàn thành thất bại.
<!-- 
const promise = new Promise((resolve, reject) => {
    reject(new Error("User not found"));
});
 -->
Promise sẽ chuyển sang trạng thái rejected.
Thông thường, chúng ta sử dụng đối tượng Error để biểu diễn lỗi.
4. So sánh resolve và reject
5. Ví dụ thực tế với getUser()
<!-- 
function getUser() {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            const user = {
                id: 1,
                name: "Martin"
            };

            if (user.id === 1) {
                resolve(user);
                return;
            }

            reject(new Error("User not found"));
        }, 1000);
    });
}
-->
Phân tích:
1. getUser() tạo và trả về Promise.
2. Executor chạy ngay lập tức
3. setTimeout() mô phỏng việc lấy dữ liệu 
4. Nếu tìm thấy user → gọi resolve(user)
5. Nếu không tìm thấy → gọi reject(error).
Chú ý: resolve() và reject() k phải cú pháp đặc biệt của JS . Chúng là các hàm được Promise constructor truyền vào Executor
<!-- 
const promise = new Promise((resolve, reject) => {
    console.log("Start");

    reject(new Error("Failed"));

    console.log("End");
});
 -->
Diễn biến:
1. In Start.
2. Gọi reject() → Promise chuyển sang trạng thái rejected.
3. Executor vẫn tiếp tục chạy.
4. In End.
Điểm quan trọng cần nhớ:
resolve() và reject() k làm Executor dừng thực thi . Nếu muốn dừng các câu lệnh tiếp theo , bạn phải sử dụng return 
<!-- 
reject(new Error("Failed"));
return;
 -->

*******************************************************************************************************************
2.1. Ba trạng thái của Promise
1 Promise trong JS có 3 trạng thái
1. Pending
Pending là trạng thái ban đầu của Promise , khi tác vụ chưa hoàn thành
<!-- 
const promise = new Promise((resolve, reject) => {
    setTimeout(() => {
        resolve("Success");
    }, 3000);
});
 -->
Trong 3 giây chờ đợi, Promise ở trạng thái pending.
2. Fulfilled
Fulfilled là trạng thái Promise hoàn thành thành công
Khi gọi resolve(value), Promise chuyển sang fulfilled.
<!-- 
const promise = new Promise((resolve, reject) => {
    resolve("User found");
});
 -->
Kết quả:
- State: fulfilled
- Result: "User found"
3. Rejected
Rejected là trạng thái Promise hoàn thành thất bại 
Khi gọi reject(error) , Promise chuyển sang rejected
4. Vòng đời của Promise
5. Điều quan trọng cần nhớ
Promise chỉ chuyển trạng thái theo một chiều:
- pending → fulfilled
- pending → rejected
Không thể chuyển ngược từ fulfilled hoặc rejected về pending.
