*******************************************************************************************************************
1. Promisification
Promisification là gì?
Promisification là quá trình chuyển đổi 1 function nhận callback thành 1 function trả về 1 Promise
Ví dụ chúng ta có function loadScript(src  , callback)
<!-- 
function loadScript(src, callback) {
    let script = document.createElement("script");
    script.src = src;

    script.onload = () => callback(null, script);
    script.onerror = () =>
        callback(new Error(`Script load error for ${src}`));

    document.head.append(script);
}
-->
Function này có cách hoạt động :
Nếu tải script thành công: gọi callback(null, script).
Nếu tải thất bại: gọi callback(error).
Đây là quy ước thường gặp trong JS  : tham số đầu tiên là error , tham số thứ 2 là kết qủa

* Chuyển callback thành Promise
<!-- 
let loadScriptPromise = function (src) {
    return new Promise((resolve, reject) => {
        loadScript(src, (err, script) => {
            if (err) {
                reject(err);
            } else {
                resolve(script);
            }
        });
    });
};
 -->
Sử dụng :
<!-- 
loadScriptPromise("path/script.js")
    .then(script => {
        console.log(script);
    })
    .catch(error => {
        console.log(error);
    });
-->
Giải thích cách chuyển đổi:
| Callback cũ               | Promise mới                |
| ------------------------- | -------------------------- |
| `callback(null, script)`  | `resolve(script)`          |
| `callback(error)`         | `reject(error)`            |
| Nhận kết quả qua callback | Nhận kết quả qua `.then()` |
| Xử lý lỗi trong callback  | Xử lý lỗi qua `.catch()`   |

Bản chất chúng ta tạo function mới bao quanh function cũ
Funcion mới tự cung cấp callback cho function cũ , sau đó chuyển két quả callback thành resolve() hoặc reject().
* Bổ sung ngoài tài liệu gốc – trường hợp dễ nhầm
Cách chuyển đổi này giả định callback có dạng:
<!-- callback(error, result); -->
Nếu callback có cấu trúc khác chẳng hạn 
<!-- callback(result); -->
thì phải viết cách chuyển đổi phù hợp với cấu trúc đó.

*******************************************************************************************************************
Promisification – Helper promisify(f)
Ở phần trước, chúng ta đã tự chuyển loadScript() sang Promise.
Nhưng nếu có nhiều funcion sử dụng callback , việc viết lại wrapper cho từng function sẽ lặp code.
Tài liệu gốc đề xuất tạo một helper dùng chung: promisify(f).
1. Cách viết helper
<!-- 
function promisify(f) {
    return function (...args) {
        return new Promise((resolve, reject) => {
            function callback(err, result) {
                if (err) {
                    reject(err);
                } else {
                    resolve(result);
                }
            }

            args.push(callback);

            f.call(this, ...args);
        });
    };
}
-->
2. Giải thích từng phần
Bước 1: Nhận function cần chuyển đổi
<!-- function promisify(f) -->
f là function callback based mà chúng ta muốn chuyển thành Promise
Bước 2: Trả về wrapper function
<!-- return function (...args) { -->
Wrapper nhận các đối số của function ban đầu.
Ví dụ:
<!-- loadScriptPromise("script.js"); -->
Thì args ban đầu là:
<!-- ["script.js"] -->
Bước 3: Tạo Promise và callback riêng
<!-- 
return new Promise((resolve, reject) => {
    function callback(err, result) {
        if (err) {
            reject(err);
        } else {
            resolve(result);
        }
    }
});
-->
Callack này chuyển kết quả từ callback cũ sang Promise
- Có lỗi → reject(err).
- Không có lỗi → resolve(result).
Bước 4: Thêm callback vào cuối danh sách tham số
<!-- args.push(callback); -->
Bước 5: Gọi function ban đầu
<!-- f.call(this, ...args); -->
Đây là cách gọi function ban đầu với:
- this : giữ lại context của wrapper
- ...args: truyền toàn bộ tham số , bao gồm callback vừa thêm

3. Sử dụng helper
<!-- 
let loadScriptPromise = promisify(loadScript);

loadScriptPromise("path/script.js")
    .then(script => console.log(script))
    .catch(error => console.log(error));
 -->
Bây giờ có thể tái sử dụng promisify() cho những function khác có cùng quy ước callback ( err , result)
Bổ sung ngoài tài liệu gốc – những điểm dễ nhầm
1. Tại sao dùng f.call(this, ...args) thay vì f(...args)?

Vì function ban đầu có thể phụ thuộc vào this.

call() giúp truyền context hiện tại vào function ban đầu.

2. Tại sao callback phải được thêm vào cuối?

Vì helper này giả định function ban đầu nhận callback ở vị trí cuối cùng:
<!-- f(arg1, arg2, callback); -->

Nếu API đặt callback ở vị trí khác, helper này không hoạt động đúng.

3. promisify() không tự động hỗ trợ mọi kiểu callback.

Nó giả định callback có dạng:
<!-- callback(err, result); -->

Đây là giới hạn quan trọng của helper trong tài liệu.

*******************************************************************************************************************

* Promisify with many arguments
  Ở helper trước, callback chỉ nhận một kết quả:
  <!-- callback(err, result); -->
  Nhưng đôi khi callback trả về nhiều kêts quả
  <!-- callback(null, result1, result2); -->
Helper cũ chỉ lấy result đầu tiên nên bỏ qua các kết quả còn lại 
Tài liệu đưa ra cách sửa callback để thu thập nhiều kết quả:
<!-- 
function promisify(f, manyArgs = false) {
    return function (...args) {
        return new Promise((resolve, reject) => {
            function callback(err, ...results) {
                if (err) {
                    reject(err);
                } else {
                    resolve(manyArgs ? results : results[0]);
                }
            }

            args.push(callback);
            f.call(this, ...args);
        });
    };
}
 -->
Điểm thay đổi so với helpper trước 
<!-- function callback(err, ...results) -->
Thay vì chỉ nhận 1 result , callback nhận kết quả còn lại vào mảng result
 <!-- resolve(manyArgs ? results : results[0]); -->
manyArgs = false: chỉ trả về kết quả đầu tiên
manyArgs = true: trả về toàn bộ kết quả dưới dạng mảng
Ví dụ:
<!-- 
function getData(callback) {
    callback(null, "Martin", 25);
}

const getDataPromise = promisify(getData, true);

getDataPromise().then(console.log);
 -->
Bổ sung ngoài tài liệu gốc – dễ nhầm:
manyArgs không làm thay đổi cách callback xử lý lỗi . Nếu err có giá trị truethy thì vẫn reject
Notes – Tổng kết bài Promisification
Có 3 ý chính cần nhớ:
1. Promisification: Chuyển function sử dụng callback thành function trả về Promise.
2. promisify(f): Tạo helper để tái sử dụng việc chuyển đổi, thay vì viết wrapper cho từng function.
3. Many arguments: Khi callback trả về nhiều kết quả, có thể dùng manyArgs = true để nhận tất cả dưới dạng mảng.
Những điểm dễ nhầm:
### Những điểm dễ nhầm

| Trường hợp                                    | Kết quả           |
| --------------------------------------------- | ----------------- |
| `callback(null, result)`                      | `resolve(result)` |
| `callback(error)`                             | `reject(error)`   |
| `callback(null, a, b)` với `manyArgs = false` | `resolve(a)`      |
| `callback(null, a, b)` với `manyArgs = true`  | `resolve([a, b])` |

Lưu ý : Helper trong bài giả định callback theo quy ước ( err , ...result) và callback được truyền ở cuối danh sách
tham số .Không phải mọi API đều tương thích trực tiếp
