Mục 1 — Transpilers
1. Transpiler là gì?
Là công cụ chuyển mã nguồn từ cú pháp này sang cú pháp khác
2. Transpiler hoạt động khi nào?
transpiler trên máy phát triển trong quá trình build
Một công cụ tiêu biểu là Babel . Babel được tích hợp trong quá trình build
3. Ghi nhớ để lưu vào VS Code

Mục 1 — Transpilers

- Transpiler: chuyển đổi mã nguồn sang cú pháp khác.
- Mục đích: giúp môi trường cũ hiểu cú pháp JavaScript hiện đại.
- Ví dụ: chuyển toán tử ?? thành biểu thức tương đương.
- Babel: công cụ transpiler phổ biến.

Phân biệt:
Transpiler → xử lý cú pháp / cấu trúc code.
Polyfill   → bổ sung chức năng còn thiếu.

Mục 2 — Polyfills
Polyfill là đoạn code bổ sung cách triển khai 1 tính năng JS
Transpiler: chuyển cú pháp JavaScript mới sang cú pháp cũ.
Polyfill: bổ sung hàm hoặc tính năng còn thiếu.
2. Ví dụ trong bài gốc
Math.trunc(n) loại bỏ phần thập phân của một số
Math.trunc(1.23);  // 1
Math.trunc(5.8);   // 5
Math.trunc(-1.23); // -1
Nếu một số JS engineer cũ chưa có Math.trunc() ta có thể bổ sung polyfill
if (!Math.trunc) {
  Math.trunc = function (number) {
    return number < 0
      ? Math.ceil(number)
      : Math.floor(number);
  };
}

if (!Math.trunc): chỉ bổ sung khi hàm chưa tồn tại.
Số dương: dùng Math.floor() để lấy phần nguyên phía dưới.
Số âm: dùng Math.ceil() để lấy phần nguyên phía trên.

3. Polyfill được dùng ở đâu?
Bổ sung những api mà trình duyệt chưa hỗ trợ 

Mục 2 — Polyfills

- Polyfill: bổ sung implementation cho tính năng còn thiếu.
- Ví dụ: bổ sung Math.trunc() cho môi trường cũ.
- Chỉ thêm khi tính năng chưa tồn tại.
- core-js: thư viện polyfill phổ biến.

Phân biệt:
Transpiler → chuyển đổi cú pháp.
Polyfill   → bổ sung chức năng.
