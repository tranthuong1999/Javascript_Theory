3. F.prototype
3.1. Constructor function và new F()
Trước tiên , nhắc lại cách tạo object bằng constructor function
<!-- 
function User(name) {
    this.name = name;
}

let user = new User("John");

console.log(user.name); // John
 -->
Khi gọi new User("John") , JS thực hiện các bước
1. Tạo một object mới.
2. Gán this bên trong constructor vào object đó
3. Chạy nội dung constructor
4. Trả về object mới ( trừ trường hợp constructor chủ động trả về moojt object khác)

Đây là kiến thức nền để hiểu F.prototype.
3.2. F.prototype là gì?
F.prototype là 1 object , toán tử new sẽ sử dụng object đó để thiết lập [[Prototype]] cho object mới được tạo 
<!-- 
let animal = {
    eats: true
};

function Rabbit(name) {
    this.name = name;
}

Rabbit.prototype = animal;

let rabbit = new Rabbit("White Rabbit");

console.log(rabbit.eats); // true
 -->
Bước 1. Gán prototype cho constructor:
Rabbit.prototype = animal;
Lúc này , Rabbit.prototype tham chiếu đến object animal
Bước 2. Tạo object mới:
let rabbit = new Rabbit("White Rabbit");
JS thiết lập quan hệ : Object.getPrototypeOf(rabbit) === animal; // true
Bước 3. Truy cập property: console.log(rabbit.eats); // true
rabbit không có property eats , nên JS tìm trong prototype animal và tìm thấy giá trị true

3.3. Phân biệt F.prototype và [[Prototype]]

| Tiêu chí  | `Rabbit.prototype`                 | `rabbit.[[Prototype]]`          |
| --------- | ---------------------------------- | ------------------------------- |
| Bản chất  | Property trên constructor function | Internal property của object    |
| Vai trò   | Được `new Rabbit()` sử dụng        | Xác định prototype của `rabbit` |
| Thời điểm | Có thể thay đổi                    | Được thiết lập khi tạo object   |

3.4. F.prototype chỉ được sử dụng tại thời điểm new F()
<!-- 
function Rabbit() {}

let animal = {
    eats: true
};

let plant = {
    grows: true
};

Rabbit.prototype = animal;

let rabbit = new Rabbit();

Rabbit.prototype = plant;

let rabbit2 = new Rabbit();

console.log(rabbit.eats);  // true
console.log(rabbit.grows); // undefined

console.log(rabbit2.eats);  // undefined
console.log(rabbit2.grows); // true -->
Tại sao?
- rabbit được tạo khi Rabbit.prototype đang tham chiếu đến animal
- Sau đó ,Rabbit.prototype được đổi sang plant
- rabiit vẫn giữ prototype cũ là animal
- rabbit2 được tạo sau đó nên có prototype là plant.

Quy tắc: thay đổi F.prototype không làm thay đổi prototype của những object đã đươc tạo trước đó

Bài tập :
<!--
let first = { a: 1 };
let second = { b: 2 };

function User() {}

User.prototype = first;

let user1 = new User();

User.prototype = second;

let user2 = new User();

console.log(user1.a);
console.log(user1.b);

console.log(user2.a);
console.log(user2.b);
 -->
console.log(user1.a); // 1
console.log(user1.b); // undefined

console.log(user2.a); // undefined
console.log(user2.b); // 2

Giải thích
Lần 1:
User.prototype = first;
let user1 = new User();
Khi tạo user1 , prototype của nó được thiết lập là first
Lần 2:
User.prototype = second;
let user2 = new User();
Khi tạo user2, prototype của nó được thiết lập là second.

4. Default F.prototype, constructor property
4.1. Prototype mặc định của function
Theo JS , mỗi function có property prototype mặc đinh là 1 object chứa property constructor
Ví dụ :
<!--
function Rabbit() {}
console.log(Rabbit.prototype.constructor === Rabbit); // true
 -->
Nói cách khác:
<!-- 
Rabbit.prototype = {
    constructor: Rabbit
};
 -->

Đây là cách biểu diễn khái niệm , JS tự tạo object object prototype mặc định cho function này

4.2. Sử dụng constructor để tạo object mới
Vì prôttype có propety constructor tham chiếu về function ban đầu , chúng ta có thể sử dụng nó để tạo object mới
Ví dụ trong bài gốc:
<!-- 
function Rabbit() {}

let rabbit = new Rabbit();

let rabbit2 = new rabbit.constructor();

console.log(rabbit2 instanceof Rabbit); // true
 -->
1. rabbit được tạo từ Rabbit
2. rabbit kế thừa constructor từ Rabbit.prototype
3. rabbit.constructor tham chiếu đến function Rabbit
4. new rabbit.constructor() tạo 1 object mới bằng constructor đó
Lưu ý: constructor chỉ là một property thông thường, không phải cơ chế đặc biệt đảm bảo object được tạo bởi constructor nào.


<!-- 
function User() {}

let user = new User();

console.log(user.constructor === User); 
// true

console.log(User.prototype.constructor === User);
// true

 -->
 Tại sao?

Khi khai báo:
function User(){} JS tự tạo prototype mặc định tương đương
User.prototype = {
    constructor: User
};
Object user kế thừa constructor tư User.prototype.
Vì vậy: user.constructor === User; // true
Điểm cần nhớ: user.constructor không phải property riêng của user , mà được kế thừa từ prototype

4.3. Nếu ghi đè F.prototype thì sao?
Đây là phần tiếp theo trong bài gốc.
<!-- 
function Rabbit() {}

Rabbit.prototype = {
    jumps: true
};

let rabbit = new Rabbit();

console.log(rabbit.jumps); // true
console.log(rabbit.constructor === Rabbit); // false
 -->
Rabbit.prototype = {
    jumps: true
};
Bạn đã thay đổi toàn bộ object prototype mặc định.
<!-- 
{
    jumps: true
}
 -->
 Nó không còn property constructor;
 Khi đó, rabbit.constructor tiếp tục tìm trong prototype chain và có thể tìm thấy Object.prototype.constructor, tức Object, chứ không phải Rabbit.
 <!-- console.log(rabbit.constructor === Object); // true -->

 4.4. Cách giữ lại constructor
Nếu muốn ghi đè prototype nhưng vẫn giữ constructor , hãy khai báo property này :
<!-- 
function Rabbit() {}

Rabbit.prototype = {
    jumps: true,
    constructor: Rabbit
};

let rabbit = new Rabbit();

console.log(rabbit.jumps); // true
console.log(rabbit.constructor === Rabbit); // true
 -->
 Hoặc tó thể thay đổi property jump trên prototype mặc định mà không the thay thế toàn bộ objec
 <!-- 
 function Rabbit() {}

Rabbit.prototype.jumps = true;

let rabbit = new Rabbit();

console.log(rabbit.constructor === Rabbit); // true
  -->
| Cách viết                            | Kết quả                                        |
| ------------------------------------ | ---------------------------------------------- |
| `Rabbit.prototype.jumps = true`      | Giữ prototype mặc định và `constructor`        |
| `Rabbit.prototype = { jumps: true }` | Thay thế prototype, mất `constructor` mặc định |

5. Summary – Tổng kết F.prototype
Theo bài gốc, cần ghi nhớ:
1. F.prototype là property của function, không phải internal [[Prototype]] của object.
2. Khi sử dụng new F(), JavaScript thiết lập [[Prototype]] của object mới theo F.prototype tại thời điểm tạo.
3. Thay đổi F.prototype sau đó không ảnh hưởng đến những object đã được tạo.
4. Prototype mặc định của function có property constructor tham chiếu về function đó.
5. Nếu thay thế toàn bộ F.prototype, property constructor mặc định sẽ mất.
6. Có thể giữ lại constructor bằng cách khai báo lại trong prototype mới.
