2. Other built-in prototypes — Function.prototype
Tương tự Array và Date, các function trong JS cũng có prototype riêng là Function.prototype
<!--

    console.log("Hi!");
}

Chuỗi prototype:
sayHi
  │
  ▼
Function.prototype
  │
  ▼
Object.prototype
  │
  ▼
null
Function.prototype cung cấp những phương thức mà function có thể sử dụng , ví dụ :
call , bind , apply
<!--

    console.log(this.name);
}

 -->

<!--

console.log(test.__proto__ === Function.prototype);

true , true , false
Tại sao?
- test là 1 function nên prototype trực tiếp của nó là Function.prototype
- Function.prototype kế thừa từ Object.prototype
- test.__proto__ không trỏ trực tiếp đến Object.prototype

- test.__proto__ → Function.prototype
- Function.prototype.__proto__ → Object.prototype

2. Tìm thấy ngay trong rabbit.eat()

Đây gọi là shadowing: thuộc tính ở cấp dưới che khuất thuộc tính cùng tên ở cấp trên.

4. Changing native prototypes
4.1. Thêm method vào native prototype
JS cho phép thêm method vào prototype có sẵn của các built-in objects.
Ví dụ, thêm một method của String.prototype
<!-- 
String.prototype.show = function() {
    console.log(this);
};

"Hello".show(); // Hello
 -->
Giải thích:
1. String.prototype.show tạo một method mới.
2. Các string có thể truy cập method này thông qua prototype chain.
3. Khi gọi "Hello".show() , JS tìm show() trong String.prototype
4. this bên trong method tham chiếu đến wrapper object tương ứng với string đang gọi method

Lưu ý: việc chỉnh sửa native prototypes có thể ảnh hưởng đến toàn bộ chương trình và thư viện khác

4.2. Rủi ro khi chỉnh sửa native prototypes
Việc thêm mehtod vào native prototype có thể gây ra xung đột với code của thư viện khác
<!-- 
String.prototype.show = function() {
    console.log(this);
};
 -->
Giả sử 1 thư viện khác cũng định nghĩa String.prototype.show() nhưng với mục đích khác
Khi đó , 2 code có thể ghi đè lẫn nhau
Vấn đề chính:
- Ảnh hưởng đến tất cả object cùng kế thừa prototype đó
- Có thể xung đột với thư viện bên thứ 3
- Có thể ghi đè method có sẵn hoặc method được thêm trong tương lai

Vì vậy k nên chỉnh sủa native prôttype trong dự án

4.3. Polyfilling
Polyfill là code bổ sung 1 tính năng mà JS chưa hỗ trợ 
Ví dụ, giả sử môi trường chưa hỗ trợ String.prototype.repeat():

<!-- 
if (!String.prototype.repeat) {
    String.prototype.repeat = function(n) {
        return new Array(n + 1).join(this);
    };
}

console.log("Ha".repeat(3)); // HaHaHa
 -->
Giải thích:
1. Kiểm tra String.prototype.repeat đã tồn tại chưa.
2. Nếu chưa tồn tại , mới bổ sung method
3. Nếu đã tồn tại , giữ nguyên implement hiện có

Điểm cần nhớ: Polyfill giúp các môi trường cũ sử dụng tính năng mới nhưng cần triển khai thêm để tránh xung đột

5. Borrowing from prototypes
5.1. Method borrowing
Method borrowing là kĩ thuật mượn method từ object khác để sử dụng mà không cần kế thừa prototype
Ví dụ :
<!-- 
let obj = {
    0: "Hello",
    1: "World",
    length: 2
};

console.log(obj.join); // undefined
 -->
obj không phải array  nên không có method join();
Nhưng chúng ta có thể mượng join từ Array.prototype:
<!-- 
let obj = {
    0: "Hello",
    1: "World",
    length: 2
};
let result = Array.prototype.join.call(obj, ", ");
console.log(result); // Hello, World
Giải thích từng phần:
- Array.prototype.join: lấy method join của Array.
- .call(obj, ", "): gọi method với this là obj , dấu phân cách là " , "
- join() sử dụng length và các phần tử theo index của obj
- Lưu ý: obj không trở thành Array và prototype của nó cũng k thay đổi
 -->
5.2. Mượn method từ Array.prototype
Một số method của Array có thể sử dụng với object không phải Array, miễn là object có cấu trúc phù hợp.
Ví dụ với slice():
<!-- 
let obj = {
    0: "a",
    1: "b",
    2: "c",
    length: 3
};

let arr = Array.prototype.slice.call(obj, 1);

console.log(arr); // ["b", "c"]
console.log(Array.isArray(arr)); // true
 -->
 Ở đây:
1. slice() đọc các phần tử theo index.
2. Dựa vào length để xác định phạm vi.
3. Trả về một Array mới.
4. Object ban đầu không bị thay đổi.

Điểm cần nhớ: Method borrowing không làm object trở thành Array .Nó chỉ tận dụng method có sẵn bằng cách truyền this phù hợp

5.3. Array-like objects
Array-like objects là những object có cấu trúc giống Array , thường có :
Các property được đánh index : 0, 1,2 , ...
Một propety length
Tuy nhiên chúng k phải array
<!-- 
let obj = {
    0: "Hello",
    1: "World",
    length: 2
};

console.log(obj.length); // 2
console.log(Array.isArray(obj)); // false
 -->
Một số ví dụ phổ biến về Array-like objects:
- arguments trong function
- Các phần tử DOM được trả về từ 1 số API như document.querySelectorAll().

So sánh Array và Array-like object:
| Đặc điểm          | Array  | Array-like     |
| ----------------- | ------ | -------------- |
| Có index          | Có     | Có             |
| Có `length`       | Có     | Có             |
| Có `map()`        | Có     | Không mặc định |
| Có `push()`       | Có     | Không mặc định |
| `Array.isArray()` | `true` | `false`        |

Ví dụ chuyển Array-like object thành Array:
<!-- 
let obj = {
    0: "A",
    1: "B",
    2: "C",
    length: 3
};

let arr = Array.from(obj);

console.log(arr); // ["A", "B", "C"]
console.log(Array.isArray(arr)); // true
 -->
Điểm cần nhớ: Array.from() có thể tạo ra 1 array mới từ Array-like object hoặc iterable

5.4. Borrowing vs inheritance
Hai khái niệm này khác nhau :
Inheritance (kế thừa):
Object sử dụng method thông qua prototype chain:
<!-- 
let animal = {
    eat() {
        console.log("Eating");
    }
};

let rabbit = {
    __proto__: animal
};

rabbit.eat(); // Eating
 -->
Borrowing (mượn method):
Gọi method cua object khác bằng cách truyền this thông qua call() hoặc apply()
<!-- 
let obj = {
    0: "A",
    1: "B",
    length: 2
};

let result = Array.prototype.join.call(obj, "-");

console.log(result); // A-B
 -->
 | Tiêu chí            | Inheritance                     | Borrowing                                     |
 | ------------------- | ------------------------------- | --------------------------------------------- |
 | Cách hoạt động      | Dựa vào prototype chain         | Gọi method trực tiếp                          |
 | Quan hệ kế thừa     | Có quan hệ kế thừa              | Không cần quan hệ kế thừa                     |
 | Cách sử dụng method | Object tìm method qua prototype | Dùng `call()` hoặc `apply()` để truyền `this` |

* 7.1. Add method "f.defer(ms)" to functions
Đề bài yêu cầu thêm method defer(ms) vào Function.prototype.

Method này cho phép trì hoãn việc thực thi function trong ms milliseconds.
<!-- 
function f() {
    console.log("Hello!");
}

Function.prototype.defer = function (ms) {
    let func = this;
    setTimeout(() => {
        func();
    }, ms)
}
 -->
 B1 :
 Function.prototype.defer = function (ms) {} 
 Thêm method defer() vào prototype của tất cả function.
 B2 :
 let func = this;
 Khi gọi f.defer(1000), this chính là function f
 Bước 3:
 <!-- 
 setTimeout(() => {
    func();
}, ms);
  -->
Sau ms milliseconds, function gốc được thực thi
* 7.2. Add the decorating "defer()" to functions
 Bài tiếp theo yêu cầu mở rộng defer() để hỗ trợ truyền tham số cho function this
 <!-- 
 function f(a, b) {
    console.log(a + b);
}

f.defer(1000)(1, 2); // Sau 1 giây: 3
  -->
Yêu cầu:
- defer(1000) trả về một function mới.
- Function mới nhận các arguments.
- Sau 1000 milliseconds, function gốc được gọi với các arguments đó.
