1. Modern methods to get/set prototype
JS cung cấp các phương thức hiện đại để lấy và thiết lập prototype:
| Method                              | Chức năng                              |
| ----------------------------------- | -------------------------------------- |
| `Object.getPrototypeOf(obj)`        | Lấy prototype của object               |
| `Object.setPrototypeOf(obj, proto)` | Thiết lập prototype                    |
| `Object.create(proto)`              | Tạo object với prototype được chỉ định |
Trước đấy chúng ta thường sử dụng obj.__proto__ để truy cập prototype
Tuy nhiên , cách này đã lỗi thời và không được khuyến khích trong code hiện tại 

1.1. Object.getPrototypeOf(obj)
Định nghĩa: Object.getPrototypeOf() trả về prototype trực tiếp ([[Prototype]]) của một object
Cú pháp:
<!-- Object.getPrototypeOf(obj); -->
Ví dụ theo ví dụ nội dung bài gốc :
<!-- 
let animal = {
    eats: true
};

let rabbit = {
    __proto__: animal
};

console.log(rabbit.eats); // true

console.log(Object.getPrototypeOf(rabbit) === animal);
// true
 -->
Giải thích:
1. animal là object chứa thuộc tính eats
2. rabbit được tạo với aniamal làm prototype
3. Object.getPrototypeOf(rabbit) lấy prototype trực tiếp của rabbit
4. Kết quả chính là object animal.

Hình dung:
rabbit
   │
   │ [[Prototype]]
   ▼
animal
   │
   └── eats: true
Điểm cần nhớ:
<!-- 
Object.getPrototypeOf(rabbit) === animal; // true
rabbit.__proto__ === animal;              // true
 -->
2 biểu thức cho kết quả giống nhau , nhưng Object.getPrototypeOf() là cách sử dụng trong code hiện đại 
<!-- 
let animal = {
    eats: true
};

let rabbit = Object.create(animal);

console.log(Object.getPrototypeOf(rabbit) === animal);
console.log(rabbit.__proto__ === animal);
console.log(rabbit === animal);
 -->
1.2. Object.setPrototypeOf(obj, proto)
Định nghĩa: Object.setPrototypeOf() thiết lập prototype cho một object có sẵn.
<!-- Object.setPrototypeOf(obj, prototype); -->
<!-- 
let animal = {
    eats: true
};

let rabbit = {
    jumps: true
};

Object.setPrototypeOf(rabbit, animal);

console.log(rabbit.eats);  // true
console.log(rabbit.jumps); // true

console.log(Object.getPrototypeOf(rabbit) === animal);
// true
 -->
Bước 1: Ban đầu có hai object độc lập:
<!-- 
rabbit                 animal
jumps: true            eats: true
 -->
Bước 2: Thực hiện:
<!-- Object.setPrototypeOf(rabbit, animal); -->
Thiết lập animal là prototype của rabbit
Bước 3: Chuỗi prototype
rabbit
  │
  ▼
animal
  │
  ▼
Object.prototype
  │
  ▼
null
Bước 4: Khi gọi
rabbit.eats;
JS không tìm thấy eat trong rabbit , nên tiếp tục tìm trong animal và tìm thấy
| Method                              | Chức năng          |
| ----------------------------------- | ------------------ |
| `Object.getPrototypeOf(obj)`        | Lấy prototype      |
| `Object.setPrototypeOf(obj, proto)` | Thay đổi prototype |

1.3. Object.create(proto[, descriptors])
Định nghĩa:Object.create() tạo 1 object mới và thiết lập prototype cho object đsó ngay khi khởi tạo
Cú pháp :
<!-- Object.create(proto, [descriptors]); -->
Trong đó:
- proto: prototype của object mới.
- - descriptors: các property descriptors muốn định nghĩa thêm (tham số tùy chọn).

Ví dụ 1: Tạo object với prototype
<!-- 
let animal = {
    eats: true
};

let rabbit = Object.create(animal);

console.log(rabbit.eats); // true

console.log(Object.getPrototypeOf(rabbit) === animal);
// true
 -->

Khác với Object.setPrototypeOf():
- Object.create() tạo object mới với prototype được chỉ định
- Object.setPrototypeOf() thay đổi prototype của object hiện tại 
Ví dụ 2: Sử dụng descriptors
Bạn có thể truyền tham số thứ hai để định nghĩa property và descriptor ngay khi tạo object.
<!-- 
let animal = {
    eats: true
};

let rabbit = Object.create(animal, {
    jumps: {
        value: true
    }
});

console.log(rabbit.eats);  // true
console.log(rabbit.jumps); // true
 -->
Ở đây:
- eats được kế thừa từ animal.
- jumps là property riêng của rabbit.
- jumps được tạo bằng property descriptor.
Lưu ý: Khi chỉ truyền value, các thuộc tính writable, enumerable, configurable mặc định là false.
So sánh 3 phương thức:
| Phương thức               | Chức năng                             |
| ------------------------- | ------------------------------------- |
| `Object.getPrototypeOf()` | Lấy prototype                         |
| `Object.setPrototypeOf()` | Thay đổi prototype                    |
| `Object.create()`         | Tạo object mới với prototype chỉ định |

1.4. Cloning objects with prototypes and descriptors
Trong JavaScript, nếu muốn clone một object mà vẫn giữ nguyên:
- Prototype của object.
- Các property riêng.
- Các property descriptors như writable, enumerable, configurable.
- Getter và setter.
Chúng ta có thể kết hợp Object.create() với hai method:
- Object.getPrototypeOf()
- Object.getOwnPropertyDescriptors()
<!-- 

let animal = {
    eats: true
};

let rabbit = Object.create(animal, {
    jumps: {
        value: true,
        writable: true,
        enumerable: true,
        configurable: true
    }
});

// Clone rabbit
let clone = Object.create(
    Object.getPrototypeOf(rabbit),
    Object.getOwnPropertyDescriptors(rabbit)
);
 -->
 Kiểm tra :

 console.log(clone !== rabbit); 
// true

console.log(Object.getPrototypeOf(clone) === animal);
// true

console.log(clone.jumps);
// true

console.log(Object.getOwnPropertyDescriptor(clone, "jumps"));

2. Brief history
Phần này giải thích lịch sử các cách JavaScript hỗ trợ truy cập và thiết lập prototype. Mục tiêu là hiểu vì sao hiện nay nên ưu tiên các phương thức hiện đại thay vì sử dụng __proto__.
2.1. F.prototype
Trong JS , mọi function thông thường đều có thuộc tính prototype
Khi sử dụng new để tạo object, JavaScript sẽ lấy F.prototype làm [[Prototype]] của object mới.
<!-- 
function Animal(name) {
  this.name = name;
}

Animal.prototype.eat = function () {
  console.log(`${this.name} is eating`);
};

let rabbit = new Animal("Rabbit");

rabbit.eat();

console.log(
  Object.getPrototypeOf(rabbit) === Animal.prototype
); // true
 -->
 Giải thích:
1. Animal.prototype là object chứa phương thức eat.
2. new Animal("Rabbit") tạo object rabbit.
3. rabbit có [[Prototype]] trỏ đến Animal.prototype.
4. Khi gọi rabbit.eat(), JavaScript tìm eat trên rabbit; không thấy thì tìm tiếp trong prototype.

2.2. Object.create()
Khác với new F(), Object.create() cho phép tạo một object mới và chỉ định trực tiếp prototype mà không cần constructor function.
<!-- Cú pháp : Object.create(proto[, descriptors]) -->
proto: object sẽ trở thành [[Prototype]] của object mới.
descriptors : các property và descriptor tuỳ chọn 
<!-- 
let animal = {
  eats: true
};

let rabbit = Object.create(animal);

console.log(rabbit.eats); // true
console.log(Object.getPrototypeOf(rabbit) === animal); // true
 -->
Giải thích:
1. animal là object gốc.
2. Object.create(animal) tạo object rabbit.
3. rabbit.[[Prototype]] trỏ đến animal.
4. rabbit có thể truy cập eats thông qua prototype chain dù không tự sở hữu property này.
Ví dụ :
<!-- 
let animal = { eats: true };
let rabbit = Object.create(animal);

console.log(rabbit.hasOwnProperty("eats"));
console.log(Object.getPrototypeOf(rabbit) === animal);
 -->
rabbit.hasOwnProperty("eats") → false: eats không phải property trực tiếp của rabbit, mà thuộc animal.
Object.getPrototypeOf(rabbit) === animal → true: prototype của rabbit chính là animal.
2.3. __proto__
__proto__ là getter/setter đặc biệt cho phép truy cập hoặc thiết lập [[Prototype]] của object.
<!-- 
let animal = {
  eats: true
};

let rabbit = {
  jumps: true
};

rabbit.__proto__ = animal;

console.log(rabbit.eats); // true
console.log(rabbit.jumps); // true

console.log(Object.getPrototypeOf(rabbit) === animal); // true
 -->
Lưu ý: __proto__ là cách truy cập cũ. Hiện nay nên ưu tiên:
<!-- 
Object.getPrototypeOf(rabbit);
Object.setPrototypeOf(rabbit, animal);
 -->

 Bài tập :
 <!--  
 let parent = { name: "Parent" };
let child = {};

child.__proto__ = parent;

console.log(child.name);
console.log(child.hasOwnProperty("name"));
 -->
2.4. Object.getPrototypeOf() và Object.setPrototypeOf()
Hai phương thức này được bổ sung để cung cấp cách truy cập và thay đổi prototype thông qua API chính thức.
Object.getPrototypeOf(obj)
Lấy prototype trực tiếp của object.
<!-- 
let animal = { eats: true };
let rabbit = Object.create(animal);

console.log(Object.getPrototypeOf(rabbit) === animal);
// true
 -->
Object.setPrototypeOf(obj, proto)
Thiết lập prototype cho object đã tồn tại.
### So sánh các cách đã học

| Cách                      | Chức năng                                            |
| ------------------------- | ---------------------------------------------------- |
| `F.prototype`             | Prototype được sử dụng khi tạo object bằng `new F()` |
| `Object.create()`         | Tạo object mới với prototype chỉ định                |
| `__proto__`               | Getter/setter truy cập prototype kiểu cũ             |
| `Object.getPrototypeOf()` | Lấy prototype                                        |
| `Object.setPrototypeOf()` | Thay đổi prototype                                   |
Điểm quan trọng: Object.getPrototypeOf() và Object.setPrototypeOf() là cách hiện đại thay thế việc sử dụng __proto__ để truy cập và thay đổi prototype.
Bài tập :
<!-- 
let parent = { name: "Parent" };
let child = { age: 20 };

Object.setPrototypeOf(child, parent);

console.log(Object.getPrototypeOf(child) === parent);
console.log(child.name);
console.log(child.hasOwnProperty("name"));
 -->

3. Don't change [[Prototype]] on existing objects
3.1. Ảnh hưởng đến hiệu năng
Một nguyên tắc quan trọng trong JavaScript: không nên thay đổi prototype của object sau khi object đã được tạo, đặc biệt trong code cần tối ưu hiệu năng.

Lý do: JavaScript engine tối ưu việc truy cập property dựa trên cấu trúc object và prototype chain. Khi thay đổi prototype, engine có thể phải vô hiệu hóa hoặc xây dựng lại một số cơ chế tối ưu.
<!-- 
let animal = {
  eats: true
};

let rabbit = {
  jumps: true
};

// Thay đổi prototype sau khi object đã được tạo
Object.setPrototypeOf(rabbit, animal);
 -->
Nên làm: xác định prototype ngay khi tạo object:
<!-- 
let rabbit = Object.create(animal);
rabbit.jumps = true;
 -->
Thay vì tạo object rồi thay đổi prototype nhiều lần.

4. "Very plain" objects
Phần này tìm hiểu những object đơn giản, không kế thừa từ Object.prototype, và lý do chúng hữu ích khi cần tạo dictionary (từ điển key/value).
4.1. Vấn đề khi sử dụng key "__proto__"
Thông thường, object trong JavaScript kế thừa từ Object.prototype.
Một vấn đề đặc biệt xuất hiện khi sử dụng "__proto__" làm key:
<!-- 
let obj = {};

obj["__proto__"] = "value";

console.log(obj["__proto__"]); // Object.prototype
 -->
Lưu ý: Không phải mọi object đều có vấn đề này. Vấn đề xuất phát từ việc object kế thừa setter đặc biệt "__proto__".
4.2. Sử dụng Map để lưu key/value.
Map được thiết kế để lưu trữ các cặp key/value và không gặp vấn đề đặc biệt với key "__proto__".
<!-- 
let map = new Map();

map.set("__proto__", "Martin");

console.log(map.get("__proto__")); // "Martin"
 -->
 Khác với object thông thường:
- Map không có key đặc biệt "__proto__".
- Key có thể thuộc bất kỳ kiểu dữ liệu nào.
- Dùng set() để thêm và get() để lấy giá trị.
- Dùng has() để kiểm tra key tồn tại.
So sánh nhanh:
| Đặc điểm         | Object                                  | Map                                   |
| ---------------- | --------------------------------------- | ------------------------------------- |
| Kiểu key         | Key thường là string hoặc Symbol        | Key có thể là bất kỳ kiểu dữ liệu nào |
| Key `__proto__`  | Có thể gặp vấn đề với key `"__proto__"` | Không có vấn đề này                   |
| Lấy số lượng key | `Object.keys(obj).length`               | `map.size`                            |

4.3. Object.create(null)
Một cách khác để tạo dictionary an toàn là sử dụng:
<!-- let obj = Object.create(null); -->
Khác với {}, object này không có prototype.
<!-- 
let dictionary = Object.create(null);

dictionary["__proto__"] = "Martin";

console.log(dictionary["__proto__"]); // "Martin"
console.log(Object.getPrototypeOf(dictionary)); // null
 -->
Tại sao cách này giải quyết được vấn đề?
- {} kế thừa từ Object.prototype.
- Object.create(null) không kế thừa từ bất kỳ object nào.
- Vì vậy, nó không có getter/setter đặc biệt "__proto__" được kế thừa.
- "__proto__" trở thành key thông thường.

<!-- 
let obj = Object.create(null);

obj.name = "Martin";

console.log(obj.name);
console.log(Object.getPrototypeOf(obj));
console.log(obj.hasOwnProperty("name"));
 -->

Giải thích:
1. obj.name → "Martin": property vẫn được lưu bình thường.
2. Object.getPrototypeOf(obj) → null: object không có prototype.
3. obj.hasOwnProperty("name") → gây lỗi: object không kế thừa phương thức hasOwnProperty().
   
4.4. Object không có prototype
<!-- let obj = Object.create(null); -->
Đây là object không có prototype ([[Prototype]] bằng null).
Đặc điểm
Object này không kế thừa các phương thức từ Object.prototype, chẳng hạn:
<!--
let obj = Object.create(null);

console.log(obj.toString);       // undefined
console.log(obj.hasOwnProperty);  // undefined
console.log(Object.getPrototypeOf(obj)); // null
  -->
So sánh hai loại object:
| Đặc điểm                                           | `{}`          | `Object.create(null)` |
| -------------------------------------------------- | ------------- | --------------------- |
| Có prototype                                       | Có            | Không                 |
| Kế thừa `toString()`                               | Có            | Không                 |
| Kế thừa `hasOwnProperty()`                         | Có            | Không                 |
| Có thể dùng key `"__proto__"` như key thông thường | Không an toàn | Có                    |

Khi nào sử dụng?
Object.create(null) phù hợp khi cần một dictionary thuần túy, lưu các cặp key/value mà không muốn kế thừa những property từ Object.prototype.

Lưu ý: Không có prototype không có nghĩa là object không có property. Nó chỉ không kế thừa property từ prototype chain.
<!-- 
let dictionary = Object.create(null);

dictionary.name = "Martin";

console.log(dictionary.name);
console.log("toString" in dictionary);
console.log(Object.getPrototypeOf(dictionary));
 -->
Giải thích:
- dictionary.name → "Martin": property được lưu trực tiếp trên object.
- "toString" in dictionary → false: object không kế thừa toString() từ Object.prototype.
- Object.getPrototypeOf(dictionary) → null: object không có prototype.
Điểm cần nhớ: Toán tử in kiểm tra property trên cả object và prototype chain. Vì dictionary không có prototype nên chỉ kiểm tra các property của chính nó.

4.5. Pure dictionary objects
Trong JavaScript, object thông thường có thể được dùng để lưu các cặp key/value. Tuy nhiên, nếu muốn sử dụng object như một dictionary thuần túy, ta có thể tạo object không có prototype:
<!-- 
let dictionary = Object.create(null);

dictionary.apple = "Apple";
dictionary.orange = "Orange";

console.log(dictionary.apple);  // "Apple"
console.log(dictionary.orange); // "Orange"
 -->
 Object được tạo bằng Object.create(null) thường được gọi là pure dictionary object (object từ điển thuần túy).
 Đặc điểm cần nhớ
- Không có prototype ([[Prototype]] là null).
- Không kế thừa các property từ Object.prototype.
- Không bị ảnh hưởng bởi key đặc biệt "__proto__".
- Có thể lưu các key/value tùy ý.
  Nhược điểm: object này không có các built-in methods như toString().
 <!-- 
 
 let dictionary = Object.create(null);

dictionary.apple = "Apple";

console.log(dictionary.toString); // undefined
console.log(dictionary); // Không thể tự chuyển thành chuỗi bằng toString()
 -->
Tuy nhiên, các phương thức tĩnh của Object vẫn hoạt động bình thường:
<!-- Object.keys(dictionary); // ["apple"] -->
Vì Object.keys() không phụ thuộc vào prototype của object.

5. Summary
Tổng kết bài Prototype methods, objects without __proto__:
5.1. Các phương thức prototype
| Phương thức                         | Chức năng                         |
| ----------------------------------- | --------------------------------- |
| `Object.getPrototypeOf(obj)`        | Lấy prototype                     |
| `Object.setPrototypeOf(obj, proto)` | Thay đổi prototype                |
| `Object.create(proto)`              | Tạo object với prototype chỉ định |
| `Object.create(null)`               | Tạo object không có prototype     |
5.2. Các khái niệm quan trọng
| Khái niệm             | Ý nghĩa                                           |
| --------------------- | ------------------------------------------------- |
| `F.prototype`         | Prototype được dùng khi tạo object bằng `new F()` |
| `[[Prototype]]`       | Internal property lưu prototype của object        |
| `__proto__`           | Getter/setter truy cập prototype kiểu cũ          |
| `Object.create(null)` | Tạo object không kế thừa `Object.prototype`       |
| `Pure dictionary`     | Object thuần túy dùng để lưu key/value            |
5.3. Những điều cần ghi nhớ
1. Ưu tiên Object.getPrototypeOf() và Object.setPrototypeOf() thay cho __proto__.
2. Không nên thường xuyên thay đổi prototype của object đang tồn tại vì ảnh hưởng hiệu năng.
3. Map phù hợp để lưu trữ key/value với nhiều kiểu key.
4. Object.create(null) phù hợp khi cần dictionary không có prototype.
5. Object không có prototype không kế thừa toString() và hasOwnProperty().
