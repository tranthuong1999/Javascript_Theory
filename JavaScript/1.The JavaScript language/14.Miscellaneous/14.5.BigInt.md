3.1. BigInt
BigInt là gì?
JS có kiêu Number để biểu diễn số
Tuy nhiên, Number không thể biểu diễn chính xác mọi số nguyên có độ lớn tùy ý.
<!-- 
const number = 9007199254740993;

console.log(number);
// 9007199254740992
 -->
Giá trị bị sai lệch vì vượt quá giới hạn số nguyên an toàn của Number
JS cung cấp kiểu dữ liệu BigInt để hỗ trợ biểu diễn các số nguyên có độ dài tuỳ ý

* Cách tạo BigInt
Cách 1: Thêm hậu tố n vào cuối số nguyên
<!-- const bigint = 1234567890123456789012345678901234567890n; -->
Chữ n cho biết đây là 1 giá trị BigInt
Cách 2: Sử dụng hàm BigInt()
<!-- const sameBigint = BigInt("1234567890123456789012345678901234567890"); -->

3. Khi nào thực sự cần BigInt?
- Cần tính toán số nguyên có giá trị vượt giới hạn an toàn của Number.
- Cần xử lý dữ liệu số nguyên lớn từ hệ thống hoặc database
- Cần giữ độ chính xác khi thực hiện các phép toán trên số nguyên lớn
Tổng kết 3.2
- BigInt hỗ trợ +, -, *, /, % và các phép toán số học khác.

- Chuyển BigInt lớn sang Number có thể mất độ chính xác.

3.3. Comparisons
Theo tài liệu gốc, BigInt có thể so sánh với cả BigInt và Number bằng các toán tử so sánh thông thường.
So sánh BigInt với BigInt
<!-- 
console.log(5n > 3n);  // true
console.log(5n < 3n);  // false
console.log(5n >= 5n); // true
 -->
So sánh BigInt với Number
Khác với phép toán số học, phép so sánh cho phép kết hợp hai kiểu dữ liệu:
<!-- 
console.log(5n > 3);  // true
console.log(5n < 10); // true
console.log(5n == 5); // true
console.log(5n === 5); // false
 -->
Điểm quan trọng: == và ===
- ==: so sánh giá trị sau khi áp dụng quy tắc chuyển đổi kiểu.
- ===: so sánh cả giá trị và kiểu dữ liệu, không chuyển đổi kiểu.
Tổng kết 3.3
- BigInt so sánh được với BigInt và Number.
- == có thể trả về true khi hai giá trị khác kiểu.
- === trả về false khi một bên là BigInt, bên còn lại là Number.
- Cẩn thận với Number vượt Number.MAX_SAFE_INTEGER

3.5. Polyfills
Polyfill cho BigInt khá phức tạp vì BigInt có cách hoạt động khác với Number, đặc biệt ở các phép toán. 
javascript.info
Polyfill là đoạn code bổ sung để hỗ trợ một tính năng JavaScript trên những môi trường chưa hỗ trợ tính năng đó.

Tổng kết 3.5
- BigInt khó Polyfill vì cách hoạt động của các toán tử khác Number.
- JSBI cung cấp các phương thức để thực hiện phép toán số nguyên lớn.
- Babel plugin có thể chuyển đổi JSBI sang BigInt native trong môi trường hỗ trợ.
