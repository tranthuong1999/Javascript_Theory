3.1. Introduction
Một method được gọi thông qua biểu thức động có thể bị mất this
<!-- 
let user = {
  name: "John",

  hi() {
    alert(this.name);
  },

  bye() {
    alert("Bye");
  }
};

user.hi(); // works

// now let's call user.hi or user.bye depending on the name
(user.name == "John" ? user.hi : user.bye)(); // Error!
 -->
 this phụ thuộc vào cách gọi function . Reference Type chính là cơ chế nội bộ giúp JS giữ thông tin object trong trường hợp 
 gọi method trực tiếp

3.2. Reference type explained
1. obj.method() thực hiện hai thao tác
<!-- user.hi(); -->
Theo tài liệu, JS thực hiện 2 thao tác :
1. Dấu . truy cập property user.hi
2. Dấu () gọi function vừa truy cập.
Câu hỏi đặt ra: Làm thế nào JavaScript biết phải truyền user vào this khi gọi hi()?
2. Nếu tách việc lấy method và gọi method
Tài liệu đưa ra ví dụ:
<!-- 
let user = {
  name: "John",

  hi() {
    alert(this.name);
  }
};

// Tách việc lấy method và gọi method
let hi = user.hi;

hi(); // Error: this is undefined
 -->
Bước 1:
<!-- let hi = user.hi; -->
Lấy function từ property hi của object user rồi gán vào biến độc lập
Bước 2:
<!-- hi(); -->
Gọi function độc lập , không còn gọi thông qua user
Trong strict mode:
<!-- this === undefined -->
So sánh hai cách gọi
Có this
<!-- user.hi() -->
Gọi trực tiếp qua object user → this là user.
Mất this
<!-- let hi = user.hi; hi() -->
Function được lấy ra và gọi độc lập → this là undefined trong strict mode.
3. JavaScript sử dụng Reference Type
Để giải thích tại sao user.hi() hoạt động, tài liệu giới thiệu một cơ chế nội bộ: Reference Type.
Theo tài liệu, khi truy cập:
<!--  user.hi-->
Reference Type là một specification type:
- Không phải dữ liệu mà chúng ta có thể khai báo trực tiếp
- Không thể lưu nó vào 1 biến như một giá trị JavaScript thông thường.
- - Được ngôn ngữ sử dụng nội bộ để giữ thông tin cần thiết.
Trong strict mode, có thể hình dung Reference Type là:
<!-- (user, "hi", true) -->
Trong đó:
- user: object chứa method
- "hi": tên property.
- true: strict mode đang có hiệu lực 

4. Reference Type truyền thông tin this như thế nào?
Khi JavaScript thực hiện:
<!-- user.hi(); -->
Reference Type giữ lại thông tin về object user và propety hi
Khi tiếp tục thực hiện (), JavaScript có thông tin cần thiết để xác định:
<!-- this === user; -->
Đó là lý do method có thể truy cập :

5. Khi nào Reference Type bị mất?
Ngoài gọi việc method trực tiếp sẽ chuyển Reference Type thành giá trị property thông thường
6. Truy cập bằng dấu . và []
 Tài liệu kết luận rằng cả 2 cách gọi trực tiếp đều có thể truyền đúng this:
 <!-- 
 user.hi(); 
 user["hi"]();
-->
2 cách này tương đương về cơ chế gọi method trong trường hợp trên
<!-- 
user["hi"](); // this là user
const hi = user["hi"];
hi(); // this là undefined trong strict mode
 -->
Dấu [] không tự động làm mất this . Điều quyết đinh là function có thê gọi trực tiếp thông qua object hay không.
<!-- 
"use strict";

const user = {
  name: "John",

  sayHi() {
    console.log(this.name);
  }
};

const method = user.sayHi;

method();
 -->
Điểm cần nhớ: this phụ thuộc vào cách gọi fucntion , không phụ thuộc vào nơi function được khai báo

3.3. Summary
Theo phần tổng kết của tài liệu gốc, có ba ý quan trọng:
1. Reference Type là một kiểu nội bộ đặc biệt của JavaScript, được sử dụng để giải thích cách hoạt động của method call.
2. Reference Type gồm base, name và strict.
3. Khi gọi method trực tiếp bằng obj.method(), Reference Type giúp JavaScript xác định object làm this. Nếu Reference Type bị mất, function được gọi độc lập và không còn this gắn với object ban đầu.


Function được gọi độc lập nên trong non-strict mode, this là global object. this.name không tồn tại nên kết quả là undefined.
