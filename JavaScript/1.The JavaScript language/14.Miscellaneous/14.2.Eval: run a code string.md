4.1. eval
Hàm built-in eval() cho phép thực thi 1 chuỗi dưới dạng mã JS
Cú pháp:
<!-- let result = eval(code); -->
Ví dụ trong tài liệu gốc:
<!-- 
let code = 'alert("Hello")';

eval(code); // Hello
 -->
Giải thích:
- code : chuỗi chưa mã JS
- eval(code): thực thi đoạn code trong chuỗi
- result : nhận kết quả trả về từ biểu thức hoặc câu lệnh cuối cùng

Ví dụ 2 – Giá trị trả về
<!-- let value = eval('1 + 1');

console.log(value); // 2 -->
Ví dụ :
<!--
let value = eval('let i = 0; ++i');

console.log(value); // 1
  -->
1. let i = 0 khai báo biến.
2. ++i tăng i lên 1.
3. Kết quả của câu lệnh cuối cùng là 1
4. eval() trả về 1

Ví dụ 3 – Truy cập biến bên ngoài
<!-- 
let a = 1;

function f() {
    let a = 2;

    eval('console.log(a)'); // 2
}

f();
 -->
Ví dụ 4 – Thay đổi biến bên ngoài
<!-- 
let x = 5;

eval("x = 10");

console.log(x); // 10
 -->
eval() không chỉ đọc mà còn có thể thay đổi biến bên ngoài
Phân biệt hai cách:
<!-- console.log(eval('1 + 2')); // 3 -->
<!-- console.log('1 + 2'); // "1 + 2" -->
eval() thực thi chuỗi như JavaScript.
console.log() chỉ in nội dung chuỗi , không thực thi 

4.2. Using “eval”
Phần này tìm hiểu cách sử dụng eval() và những điểm quan trọng cần luu ý:
4.2.1. Strict mode
Trong stric mode , eval() có phạm vi riêng đối với các khai báo biến trong nó
Ví dụ:
<!-- 
"use strict";

eval("let x = 10;");

console.log(x); // ReferenceError: x is not defined
 -->
Tại sao?
Biến x được khai báo bên trong đoạn code của eval(), nên không trở thành biến bên ngoài 
So sánh với non-strict mode:
<!-- eval("var x = 10;");

console.log(x); // 10 -->
Trong non-strict mode, khai báo var bên trong direct eval() có thể tạo biến trong phạm vi bên ngoài.

4.2.2. Indirect eval
Phân biệt phân biệt direct eval và indirect eval.
Direct eval:
<!-- 
let x = 10;
eval("console.log(x)"); // 10
 -->
Indirect eval:
<!-- 
let x = 10;

(0, eval)("console.log(x)");
// ReferenceError: x is not defined
 -->
Tại sao có sự khác biệt?
- Direct eval: thực thi trong lexical environment nơi eval() được gọi.
- Indirect eval : thực thi trong global scope , không truy cập được biến local của nơi gọi 
Một cách khác để gọi indirect eval:
<!-- 
let x = 10;

let indirectEval = eval;

indirectEval("console.log(x)");
 -->
Ở đây indirectEval cũng là indirect eval.
4.2.3. Vì sao cần phân biệt?
Xét ví dụ:
<!-- 
function test() {
    let secret = "Hello";

    eval("console.log(secret)");
}

test();
 -->
Direct eval đọc được secret
Nhưng nếu đổi thành:
<!-- 
function test() {
    let secret = "Hello";

    (0, eval)("console.log(secret)");
}

test();
 -->
Indirect eval không truy cập được biến secret trong function.
