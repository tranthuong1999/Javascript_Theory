4.1. Currying
4.1.1. Currying là gì?
Currying là kỹ thuật biến đổi function có thể gọi nhiều bằng argument cùng lúc thành function có thể gọi lần lượt từng argument
Ví dụ:
<!-- 
// Cách gọi thông thường
f(a, b, c);

// Sau khi currying
f(a)(b)(c);
 -->
Điểm quan trọng: Currying không goi function ngay lập tức mà biến đổi cách function được gọi 
4.1.2. Ví dụ trong tài liệu gốc
Giả sử chúng ta có function cộng hai số:
<!-- 
function sum(a, b) {
    return a + b;
}

console.log(sum(1, 2)); // 3
 -->
Thông thường, sum nhận hai argument trong một lần gọi:
<!-- sum(1, 2); -->
Bây giờ chúng ta viết helper curry():
<!-- 
function curry(f) {
    return function(a) {
        return function(b) {
            return f(a, b);
        };
    };
}
function sum(a, b) {
    return a + b;
}

let curriedSum = curry(sum);

console.log(curriedSum(1)(2)); // 3
 -->

4.1.3. Phân tích cách hoạt động
Đây là phần quan trọng nhất cần hiểu :
Bước 1:
<!-- let curriedSum = curry(sum); -->
curry(sum) trả về function
<!-- 
function(a) {
    return function(b) {
        return sum(a, b);
    };
}
 -->
Lúc này sum chưa được thực thi 
Bước 2:
<!-- let step1 = curriedSum(1); -->
Argument 1 được lưu trong Lexical Environment thông qua Closure
Kết quả trả về là:
<!-- 
function(b) {
    return sum(1, b);
}
 -->
Bước 3:
<!-- let result = step1(2); -->
Lúc này:
- a=1 được lưu từ lần gọi trước 
- b = 2 được truyền vào lần gọi hiện tại 
- Function ban đầu được gọi: sum(1, 2)
Kết quả:

4.2. Currying? What for?
Ở phần trước, ta đã biết cách chuyển một hàm:
<!-- f(a, b, c) -->
thành 
<!-- f(a)(b)(c) -->
Vậy Currying có lợi ích gì trong thực tế?
Ví dụ về 1 hàm ghi log để giải thích cách tạo ra những hàm nhỏ hơn có sẵn 1 tham số
Ví dụ trong tài liệu gốc
Giả sử ta có hàm log() nhận 3 tham số :
<!-- 
function log(date, importance, message) {
  alert(`[${date.getHours()}:${date.getMinutes()}] [${importance}] ${message}`);
}
-->
Ý nghĩa:
- date : thời gian ghi log
- importance : mức độ quan trọng ,ví dụ DEBUG, INFO.
- message: nội dung log.
Thông thường, ta gọi hàm như sau:
<!-- log(new Date(), "DEBUG", "some debug"); -->
Sử dụng Currying
Tài liệu sử dụng thư viện Lodash để chuyển hàm log thành hàm curried:
<!-- log = _.curry(log); -->
Lưu ý: _.curry() là hàm của thư viện lodassh , không phải hàm có sẵn của JS
Sau khi currying, ta vẫn có thể gọi theo cách thông thường :
<!-- log(new Date(), "DEBUG", "some debug"); -->
Hoặc gọi lần lượt từng tham số:
<!-- log(new Date())("DEBUG")("some debug"); -->
Cả 2 cách đều thực hiện cùng 1 công việc :

Tạo Partial Functions
1. Cố định tham số đầu tiên
Giải thích:
- log(new Date()) đã truyền sẵn tham số date.
- logNow là một hàm mới, chỉ cần nhận importance và message.
- Ta không cần truyền lại thời gian mỗi lần ghi log.
2. Cố định thêm tham số thứ hai
<!-- 
let debugNow = logNow("DEBUG");

debugNow("message");
 -->
Lúc này:
- date đã được cố định bởi logNow
- importance đã được cố định là "DEBUG".
-  debugNow chỉ còn chờ message.
| Khái niệm           | Ý nghĩa                                                                      |
| ------------------- | ---------------------------------------------------------------------------- |
| Currying            | Chuyển hàm nhiều tham số thành chuỗi hàm nhận từng tham số                   |
| Partial application | Cố định trước một hoặc nhiều tham số để tạo hàm mới nhận các tham số còn lại |
Trong ví dụ trên, Currying giúp ta gọi hàm từng bước; từ đó có thể tạo ra các partial functions như logNow và debugNow

4.3. Advanced curry implementation
<!-- 
function curry(func) {
  return function curried(...args) {
    if (args.length >= func.length) {
      return func.apply(this, args);
    } else {
      return function(...args2) {
        return curried.apply(this, args.concat(args2));
      };
    }
  };
}

function sum(a, b, c) {
  return a + b + c;
}

let curriedSum = curry(sum);

alert(curriedSum(1, 2, 3)); // 6, still callable normally
alert(curriedSum(1)(2, 3)); // 6, currying of 1st arg
alert(curriedSum(1)(2)(3)); // 6, full currying
 -->
Các ý chính cần nhớ:
1. Currying chuyển hàm nhiều tham số thành chuỗi hàm nhận tham số.
2. Có thể tạo các hàm trung gian khi chưa truyền đủ đối số.
3. func.length được dùng để xác định số tham số cần thiết.
4. apply() gọi hàm với this và danh sách đối số.
5. Cách triển khai trong bài yêu cầu hàm có số lượng tham số cố định
